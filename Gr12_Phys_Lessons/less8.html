Work, Power and Energy

Force Applied at an Angle & Incline Plane

📚Lesson 2
📐Incline Plane
⏱️~60 minutes

Lesson Overview

In this lesson, we explore how to calculate work when a force is applied at an angle to the direction of motion. We'll learn to resolve forces into components, apply the Work-Energy Theorem, and solve problems involving inclined planes.

Learning Objectives

  • 1Calculate work done using W = Fd cos θ when force is at an angle
  • 2Resolve forces into horizontal and vertical components
  • 3Draw force diagrams for objects on inclined planes
  • 4State and apply the Work-Energy Theorem
  • 5Solve problems using W = ΔEₖ = Eₖf - Eₖi

Force Components

When a force is applied at an angle θ to the horizontal, we resolve it into perpendicular components:

Horizontal Component
Fx = F cos θ
Vertical Component
Fy = F sin θ
Force Component Visualization

🎯 Key Insight

  • Only the component of force parallel to motion does work
  • For horizontal motion: use Fhorizontal = F cos θ
  • The perpendicular component does no work on that motion

Work Formula for Angled Forces

W = F · d · cos θ

W = Work (Joules) | F = Force (Newtons) | d = Displacement (metres) | θ = Angle between F and motion

θ = 0°

Force parallel to motion
cos 0° = 1
W = Fd (Maximum)

θ = 90°

Force perpendicular
cos 90° = 0
W = 0

0° < θ < 90°

Force has parallel component
0 < cos θ < 1
Positive work

θ = 180°

Force opposes motion
cos 180° = -1
Negative work

The Work-Energy Theorem

📜 Work-Energy Theorem
"The net work done on an object equals the change in its kinetic energy."
Wnet = ΔEk = ½mvf² - ½mvi²
Kinetic Energy
Ek = ½mv²
Net Work
Wnet = Fnet · d

Forces on an Inclined Plane

On an incline at angle θ, the weight component parallel to the slope causes motion:

Parallel to slope
F// = mg sin θ
Perpendicular to slope
F⊥ = mg cos θ
Inclined Plane Force Diagram

Worked Examples

📝 Example 1: Pulling at an Angle

Problem: A man pulls a sledge with 200 N at 30° to horizontal for 20 m. Find the work done.

1Given: F = 200 N, θ = 30°, d = 20 m
2Apply formula: W = Fd cos θ = 200 × 20 × cos 30°
3Calculate: W = 200 × 20 × 0.866 = 3464 J
📝 Example 2: Car on Incline

Problem: A 1020.41 kg car moves at constant speed up a 60° incline. Friction is 1000 N. Find the applied force.

1Weight: Fg = mg = 1020.41 × 9.8 = 10,000 N
2Parallel component: F// = 10,000 × sin 60° = 8,660 N
3At constant speed (Fnet = 0):
Fapplied = F// + Ffriction = 8,660 + 1,000 = 9,660 N
📝 Example 3: Work-Energy Theorem

Problem: A 60 kg box slides down a rough 25° slope (10 m long) with acceleration 2 m/s². Find work done by friction.

1Final velocity: vf² = 0 + 2(2)(10) = 40 m²/s²
2ΔEk: = ½(60)(40) = 1,200 J
3Work by gravity: Wg = 60 × 9.8 × sin 25° × 10 = 2,485 J
4Work-Energy: Wnet = Wg + Wf
1,200 = 2,485 + Wf
Wf = -1,285 J

Lesson Summary

📌 Key Points

  • Work at an angle: W = Fd cos θ
  • Only the parallel force component does work
  • Fhorizontal = F cos θ, Fvertical = F sin θ
  • On inclines: F// = mg sin θ, F⊥ = mg cos θ
  • Work-Energy Theorem: Wnet = ΔEk
  • Friction always does negative work
