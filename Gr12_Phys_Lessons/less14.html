Overview

+

Motion can be described in different ways: through words, diagrams, and graphs. For projectile motion, we use three main types of graphs:

Key Graph Relationships

Position-time graph: Slope = Velocity

Velocity-time graph: Slope = Acceleration

Velocity-time graph: Area under curve = Displacement

Acceleration-time graph: Area under curve = Change in velocity

For vertical projectile motion:

  • Acceleration is constant at -9.8 m/s² (when upward is positive)
  • Velocity changes linearly with time
  • Position follows a parabolic path
  • At maximum height, velocity is zero

Velocity vs Time

Main Body

+

Understanding Motion Graphs

Motion graphs provide a visual representation of how position, velocity, and acceleration change over time for a projectile.

Worked Example: Object Dropped from Ascending Balloon

An object is dropped from a hot air balloon ascending at 2 m/s. Calculate how far below the release point the object will be after 4 seconds, and draw the velocity-time and acceleration-time graphs.

Solution:

Take upward as positive: g = -9.8 m/s², vᵢ = 2 m/s, Δt = 4 s

Δy = vᵢΔt + ½gΔt² = (2)(4) + ½(-9.8)(4)² = 8 - 78.4 = -70.4 m

The object is 70.4 m below the release point.
