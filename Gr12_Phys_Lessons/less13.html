📐 Equations of Motion

Projectiles can have their motion described by a single set of equations for both upward and downward motion:

vf = vi + gt
Final velocity
y = vit + ½gt²
Displacement
vf² = vi² + 2gy
Velocity-displacement
y = (vf + vi)t / 2
Average velocity

Variable Definitions

Symbol Meaning Unit
vi Initial velocity m·s⁻¹
vf Final velocity m·s⁻¹
g Gravitational acceleration 9,8 m·s⁻² (always!)
y Vertical displacement m
t Time s

💡 Problem-Solving Tips

Follow these steps when solving projectile motion problems:

  1. Choose a direction as positive. Usually, we take UP as positive and DOWN as negative.
  2. Write down known values: vf, vi, g, y, and t. Identify what you need to find.
  3. Remember: If an object is released from a moving person, the initial velocity equals the velocity of that person.
  4. Identify which formula to use based on the known and unknown values.
  5. Substitute values into the equation. Be careful with signs!
  6. Interpret the answer. Check if it makes physical sense.

⚠️ Sign Convention - Critical!

When taking UP as positive:

  • Upward velocity → positive
  • Downward velocity → negative
  • g = -9,8 m·s⁻² (acceleration is downward)
  • Displacement upward → positive
  • Displacement downward → negative

✏️ Worked Example 1

📝 Bullet Fired Vertically Upward

A bullet is fired vertically upwards with a velocity of 200 m·s⁻¹ to reach its maximum height. Ignore the effects of air resistance and calculate:

a) The maximum height reached

b) At what height will it be moving at 100 m·s⁻¹ upwards?

Part (a): Maximum Height

1 Choose direction: Take UP as positive
2 List known values:
vi = +200 m·s⁻¹
vf = 0 m·s⁻¹ (at max height)
g = -9,8 m·s⁻²
y = ? (unknown)
3 Choose equation: We have vf, vi, g, need y → use vf² = vi² + 2gy
4 Substitute and solve:
vf² = vi² + 2gy
0² = (200)² + 2(-9,8)y
0 = 40000 - 19,6y
19,6y = 40000
y = 2040,82 m

Part (b): Height at 100 m·s⁻¹

1 List known values:
vi = +200 m·s⁻¹
vf = +100 m·s⁻¹
g = -9,8 m·s⁻²
y = ? (unknown)
2 Substitute and solve:
vf² = vi² + 2gy
(100)² = (200)² + 2(-9,8)y
10000 = 40000 - 19,6y
19,6y = 30000
y = 1530,61 m

✏️ Worked Example 2

📝 Ball Thrown and Caught

A ball is thrown vertically upwards and returns to the thrower's hand 4 s later. Calculate:

a) The height reached by the ball

b) The velocity with which the ball left the thrower's hand

c) The velocity with which the ball returned to the thrower's hand

💡 Key Insight

Total time = 4 s, so time to reach maximum height = 4 ÷ 2 = 2 s

At maximum height, vf = 0 m·s⁻¹

Part (a): Height reached

Using downward motion from max height (easier because vi = 0 at top):

vi = 0 m·s⁻¹ (at top)
t = 2 s (fall time)
g = +9,8 m·s⁻² (taking down as +)
y = vit + ½gt²
y = 0(2) + ½(9,8)(2)²
y = 0 + ½(9,8)(4)
y = 19,6 m

Part (b): Initial velocity

Using upward motion (up = positive):

vf = 0 m·s⁻¹ (at top)
y = +19,6 m
g = -9,8 m·s⁻²
vf² = vi² + 2gy
0² = vi² + 2(-9,8)(19,6)
0 = vi² - 384,16
vi² = 384,16
vi = 19,6 m·s⁻¹ upward

Part (c): Return velocity

Using downward motion from max height:

vi = 0 m·s⁻¹ (at top)
g = +9,8 m·s⁻² (down +)
t = 2 s
vf = vi + gt
vf = 0 + (9,8)(2)
vf = 19,6 m·s⁻¹ downward

✅ Important Observation

The ball leaves and returns with the same speed (19,6 m·s⁻¹), but in opposite directions!
