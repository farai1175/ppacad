Overview

+

Vertical projectile motion deals with objects that fall straight down, objects thrown straight up, and objects moving up and then down under gravity.

g = 9.8 m/s² (on Earth)

Gravitational acceleration is constant and always directed downward

Key characteristics of vertical projectile motion:

  • Acceleration is constant at 9.8 m/s² downward
  • Velocity is zero at the maximum height
  • Time upward = Time downward (for same height)
  • Motion can be described using equations of motion

Main Body

Understanding Vertical Projectile Motion

An object is in free fall when the only force acting on it is gravity. The acceleration due to gravity (g) is approximately 9.8 m/s² on Earth and is always directed downward.

Equations of Motion for Vertical Projectiles

vf = vi + g·t

Δy = vi·t + ½·g·t²

vf² = vi² + 2·g·Δy

Note: g is negative (-9.8 m/s²) when upward is positive

Key Concepts:

  • Objects falling from rest: Initial velocity is 0 m/s, acceleration is 9.8 m/s² downward
  • Objects projected upward: Initial velocity is upward, acceleration is 9.8 m/s² downward
  • At maximum height: Velocity is 0 m/s, acceleration is still 9.8 m/s² downward
  • Time symmetry: Time to reach maximum height = Time to fall back to launch point
Worked Example 1: Object Falling from Rest

An object is dropped from the top of a 80 m tall building. Calculate:

a) The time it takes to hit the ground

b) Its velocity just before impact

Solution:

Given: vi = 0 m/s, Δy = -80 m, g = -9.8 m/s²

a) Using Δy = vi·t + ½·g·t²

-80 = 0 + ½·(-9.8)·t²

t² = 80/4.9 ≈ 16.33

t ≈ 4.04 s

b) Using vf = vi + g·t

vf = 0 + (-9.8)·4.04 ≈ -39.6 m/s

The negative sign indicates downward direction.

Worked Example 2: Object Projected Upward

A stone is thrown vertically upward with an initial velocity of 24 m/s.

a) Calculate the maximum height reached

b) Determine the time taken to reach maximum height

c) Find the total time until it returns to the thrower's hand

Solution:

Given: vi = 24 m/s, vf = 0 m/s (at max height), g = -9.8 m/s²

a) Using vf² = vi² + 2·g·Δy

0 = (24)² + 2·(-9.8)·Δy

Δy = 576 / 19.6 ≈ 29.4 m

b) Using vf = vi + g·t

0 = 24 + (-9.8)·t

t = 24 / 9.8 ≈ 2.45 s

c) Total time = 2 × 2.45 = 4.9 s (time up = time down)
