Lesson Overview

This lesson focuses on determining the resultant of vectors using the component method. You will learn how to break down vectors into their horizontal and vertical components, calculate the net components, and determine the final resultant vector.

Learning Objectives

  • Define and identify resultant vectors, co-linear vectors, and vector components
  • Resolve a vector into its horizontal and vertical components
  • Calculate the net horizontal and vertical components of multiple vectors
  • Determine the magnitude and direction of the resultant vector using Pythagoras' theorem and trigonometry
  • Apply the component method to solve vector problems in two dimensions

Key Concept

The resultant vector is a single vector that has the same effect as all the other vectors acting together. The component method allows us to find this resultant by breaking vectors into perpendicular components and then combining them.

Main Body

Introduction to Vector Components

In Grade 10, the study of vectors focused mainly on vectors acting in one dimension (co-linear vectors). Vector addition was performed algebraically in one dimension. Now, we extend these concepts to vectors in two dimensions, often represented on a Cartesian plane consisting of perpendicular x- and y-axes.

The resultant vector (R) is always defined as the single vector that produces the same effect as the multiple vectors acting together. When vectors are not parallel or perpendicular to each other, determining the resultant requires a methodical approach, which is the component method.

Any vector (F) can be resolved into horizontal and vertical components:

\[ F_x = F \cos \theta \]

\[ F_y = F \sin \theta \]

Where θ is the angle between the vector and the positive x-axis.

Steps for the Component Method

1

Resolve All Vectors into Components

For each vector, calculate its horizontal and vertical components using trigonometric functions. Remember to assign appropriate signs (+ or -) based on direction.

2

Determine the Net Horizontal Component (Rx)

Add all horizontal components algebraically:

\[ R_x = \Sigma F_x = F_{x1} + F_{x2} + \dots \]

3

Determine the Net Vertical Component (Ry)

Add all vertical components algebraically:

\[ R_y = \Sigma F_y = F_{y1} + F_{y2} + \dots \]

4

Calculate the Magnitude of the Resultant (R)

Use the Pythagorean theorem:

\[ R = \sqrt{R_x^2 + R_y^2} \]

5

Calculate the Direction of the Resultant (θ)

Use trigonometric ratios to find the angle relative to the x-axis:

\[ \theta = \tan^{-1} \left( \frac{R_y}{R_x} \right) \]
