Trigonometric Functions

Grade: 12
Week: Term 1 Week 4
Time: 60 minutes
Topic: Functions - Sine, Cosine & Tangent

Master trigonometric functions: sketch sine, cosine, and tangent graphs. Understand how parameters (a, b, p, q) transform these graphs and affect amplitude, period, and shifts.

🎯 Lesson Objectives

▼

This lesson focuses on trigonometric functions and their transformations. By the end of this lesson, you will be able to:

  • Sketch the basic graphs of f(x) = sin x, f(x) = cos x, and f(x) = tan x
  • Identify key features: maximum/minimum values, range, amplitude, and period
  • Understand the effects of changing amplitude (parameter a)
  • Calculate and apply changes to the period (parameter b)
  • Recognize horizontal shifts (parameter p) and vertical shifts (parameter q)
  • Sketch transformed trigonometric functions from equations
  • Determine equations from given trigonometric graphs

🧠 Pre-Knowledge Required

▼

Before starting this lesson, you should be familiar with:

  • Basic trigonometric ratios (sin, cos, tan)
  • Cartesian coordinate system and graphing
  • Angles measured in degrees (0° to 360°)
  • The unit circle concept
  • Function notation f(x)
  • Basic graph transformations (shifts and stretches)

General Form of Trigonometric Functions
y = a·sin(b(x + p)) + q
y = a·cos(b(x + p)) + q
y = a·tan(b(x + p)) + q
where: a = amplitude, b affects period, p = horizontal shift, q = vertical shift
Feature f(x) = sin x g(x) = cos x h(x) = tan x
Maximum Value y = 1 y = 1 N/A (undefined)
Minimum Value y = -1 y = -1 N/A (undefined)
Range y ∈ [-1; 1] y ∈ [-1; 1] y ∈ ℝ (all real numbers)
Amplitude 1 1 N/A
Period 360° 360° 180°
X-intercepts 0°, 180°, 360° 90°, 270° 0°, 180°, 360°

💡 Key Definitions

Amplitude: Half the distance between maximum and minimum values.

Period: The horizontal length of one complete cycle.

Range: All possible y-values of the function.

Visualizing the Basic Graphs

Sine Graph (f(x) = sin x): Starts at origin (0,0), goes up to maximum at 90°, back to zero at 180°, down to minimum at 270°, returns to zero at 360°.

Cosine Graph (g(x) = cos x): Starts at maximum (0,1), goes to zero at 90°, down to minimum at 180°, back to zero at 270°, up to maximum at 360°.

Tangent Graph (h(x) = tan x): Has vertical asymptotes at 90° and 270°. Passes through origin, increases to infinity at 90°, reappears from negative infinity at 90°.

📈 Amplitude Changes (Parameter a)

▼

Effect of Changing Amplitude: y = a·sin x and y = a·cos x

The parameter a affects the amplitude (height) of sine and cosine graphs:

📌 Amplitude Formula

Amplitude = |a| (absolute value of a)

• If |a| > 1: Graph stretches vertically

• If 0 < |a| < 1: Graph compresses vertically

• If a < 0: Graph reflects in x-axis

Example 1: Comparing Different Amplitude Values
  • f(x) = 2 sin x:
    • Amplitude = |2| = 2
    • Maximum value = 2
    • Minimum value = -2
    • Range: y ∈ [-2; 2]
  • f(x) = ½ sin x:
    • Amplitude = |½| = 0.5
    • Maximum value = 0.5
    • Minimum value = -0.5
    • Range: y ∈ [-0.5; 0.5]
  • f(x) = -sin x:
    • Amplitude = |-1| = 1
    • Graph is reflected in x-axis
    • Maximum becomes minimum, and vice versa
For Tangent Functions: y = a·tan x
• All y-values are multiplied by a
• No amplitude concept (no maximum/minimum)
• If a < 0, graph reflects in x-axis

💡 Important Note

The parameter a only affects the vertical stretch/compression. It does NOT change:

• The period of the function

• The x-intercepts (for sine and cosine when a ≠ 0)

• The location of asymptotes (for tangent)

🔄 Period Changes (Parameter b)

▼

Effect of Changing Period: y = sin(bx), y = cos(bx), y = tan(bx)

The parameter b affects the period (horizontal length of one cycle):

Period Formulas
For sine and cosine: New Period = 360° / |b|
For tangent: New Period = 180° / |b|
Always use |b| (absolute value) for period calculations
Example 2: Period Changes
  • f(x) = sin(2x):
    • b = 2
    • New period = 360° / 2 = 180°
    • Complete cycle in 180° instead of 360°
    • Graph compresses horizontally
  • f(x) = cos(½x):
    • b = ½
    • New period = 360° / (½) = 720°
    • Complete cycle in 720° instead of 360°
    • Graph stretches horizontally
  • h(x) = tan(3x):
    • b = 3
    • New period = 180° / 3 = 60°
    • Complete cycle in 60° instead of 180°
    • Asymptotes occur every 60°

📌 Finding X-axis Divisions

To sketch graphs with changed periods:

1. Calculate new period: P = (original period) / |b|

2. Divide new period by 4 to find quarter points

3. Mark these divisions on x-axis

Example: For sin(2x), period = 180°, quarter points: 0°, 45°, 90°, 135°, 180°

⚠️ Important: Direction of Change

• If |b| > 1: Period decreases (graph compresses horizontally)

• If 0 < |b| < 1: Period increases (graph stretches horizontally)

• If b < 0: Graph reflects in y-axis (but period formula still uses |b|)

↔️ Horizontal & Vertical Shifts (Parameters p & q)

▼

Horizontal Shifts: y = sin(x + p), y = cos(x + p), y = tan(x + p)

The parameter p causes horizontal (left-right) shifts:

Horizontal Shift Rules
• y = f(x + p): Shift p units LEFT
• y = f(x - p): Shift p units RIGHT
Note: Opposite direction to what you might expect!
Example 3: Horizontal Shifts
  • f(x) = sin(x + 30°):
    • p = +30°
    • Shift 30° LEFT
    • Original sine graph moves left by 30°
  • g(x) = cos(x - 60°):
    • p = -60°
    • Shift 60° RIGHT
    • Original cosine graph moves right by 60°
  • h(x) = tan(x + 45°):
    • p = +45°
    • Shift 45° LEFT
    • Asymptotes also shift left by 45°

Vertical Shifts: y = sin x + q, y = cos x + q, y = tan x + q

The parameter q causes vertical (up-down) shifts:

Vertical Shift Rules
• y = f(x) + q: Shift q units UP if q > 0
• y = f(x) + q: Shift |q| units DOWN if q < 0
Note: This works as expected!
Example 4: Vertical Shifts
  • f(x) = sin x + 2:
    • q = +2
    • Shift 2 units UP
    • Range becomes y ∈ [1; 3] (original: [-1; 1])
  • g(x) = cos x - 1:
    • q = -1
    • Shift 1 unit DOWN
    • Range becomes y ∈ [-2; 0] (original: [-1; 1])
  • h(x) = tan x + 0.5:
    • q = +0.5
    • Shift 0.5 units UP
    • Asymptotes remain vertical lines

💡 Combined Transformations

Functions can have multiple transformations simultaneously:

y = 2 sin(3(x - 30°)) + 1

• Amplitude = 2 (vertical stretch)

• Period = 360°/3 = 120° (horizontal compression)

• Shift 30° RIGHT (horizontal shift)

• Shift 1 unit UP (vertical shift)

✓ Comprehensive Quiz (12 Questions)

▼

Test your understanding of trigonometric functions. Select an option and get instant feedback.

Question 1: What is the period of the basic sine function, f(x) = sin x?

A) 180°
B) 360°
C) 90°
D) 720°
Explanation: The basic sine function completes one full cycle every 360°.

Question 2: What is the range of f(x) = cos x?

A) y ∈ [0; 1]
B) y ∈ [-1; 1]
C) y ∈ ℝ (all real numbers)
D) y ∈ [-∞; ∞]
Explanation: Cosine oscillates between -1 and 1, so its range is y ∈ [-1; 1].

Question 3: What is the amplitude of f(x) = 3 sin x?

A) 1
B) 3
C) 6
D) 1.5
Explanation: Amplitude = |a| = |3| = 3. It's the vertical stretch factor.

Question 4: What is the period of f(x) = sin(2x)?

A) 180°
B) 360°
C) 90°
D) 720°
Explanation: Period = 360°/|b| = 360°/2 = 180°. The graph completes faster.

Question 5: How does y = sin(x + 30°) transform from y = sin x?

A) Shift 30° left
B) Shift 30° right
C) Shift 30° up
D) Shift 30° down
Explanation: y = f(x + p) shifts p units LEFT. So +30° means shift 30° left.

Question 6: What is the period of the basic tangent function, h(x) = tan x?

A) 360°
B) 180°
C) 90°
D) 270°
Explanation: The tangent function repeats every 180°, unlike sine and cosine which repeat every 360°.

Question 7: If f(x) = -2 cos x, what is its amplitude?

A) -2
B) 2
C) 1
D) 4
Explanation: Amplitude = |a| = |-2| = 2. The negative sign causes reflection, not amplitude change.

Question 8: Where are the vertical asymptotes for h(x) = tan x?

A) 0° and 180°
B) 90° and 270°
C) 45° and 225°
D) 30° and 210°
Explanation: tan x = sin x/cos x. When cos x = 0 (at 90° and 270°), tan x is undefined, creating asymptotes.

Question 9: What is the range of f(x) = sin x + 2?

A) y ∈ [-1; 1]
B) y ∈ [1; 3]
C) y ∈ [0; 2]
D) y ∈ [-2; 2]
Explanation: Original range [-1; 1] shifts up 2 units → [-1+2; 1+2] = [1; 3].

Question 10: What is the period of f(x) = tan(3x)?

A) 60°
B) 180°
C) 120°
D) 540°
Explanation: For tangent: Period = 180°/|b| = 180°/3 = 60°.

Question 11: How does y = cos(x - 45°) transform from y = cos x?

A) Shift 45° left
B) Shift 45° right
C) Shift 45° up
D) Shift 45° down
Explanation: y = f(x - p) shifts p units RIGHT. So -45° means shift 45° right.

Question 12: What is the amplitude of f(x) = ½ cos x?

A) 0.5
B) 1
C) 2
D) 0.25
Explanation: Amplitude = |a| = |½| = 0.5. The graph is compressed vertically.
