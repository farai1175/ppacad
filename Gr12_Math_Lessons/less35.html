Trigonometric Equations (Lesson 4 - Double Angles)

Grade: 12
Week: Term 1 Week 11
Time: 60 minutes
Topic: Double Angle Identities

Solving trigonometric equations using double angle identities: General solutions & interval solutions

🎯 Lesson Objectives

▼

This lesson focuses on solving trigonometric equations using double angle identities. By the end of this lesson, you will be able to:

  • Solve trigonometric equations using double angle identities
  • Express solutions as general solutions (all possible angles)
  • Find solutions within a given interval (e.g., [-270°; 180°])
  • Choose the correct form of cos 2x based on the equation structure
  • Factorize trigonometric expressions and solve using general solution formulas

📋 General Solutions Reference

▼

When solving trigonometric equations, we use general solutions to express ALL possible angles that satisfy the equation. Here are the three forms you need to memorize:

sin
Sine General Solution
If sin θ = a

θ = sin⁻¹(a) + k·360°

OR

θ = (180° - sin⁻¹(a)) + k·360°

where k is any integer (..., -2, -1, 0, 1, 2, ...)
cos
Cosine General Solution
If cos θ = a

θ = ± cos⁻¹(a) + k·360°

where k is any integer (the ± gives both solutions)
tan
Tangent General Solution
If tan θ = a

θ = tan⁻¹(a) + k·180°

where k is any integer (period is 180°, not 360°)
💡
Why k·360° for sine and cosine, but k·180° for tangent?
Sine and cosine have a period of 360° (they repeat every 360°), while tangent has a period of 180° (it repeats every 180°).

💡 Problem-Solving Strategy

▼
🎯 Steps for Solving Trig Equations with Double Angles
  1. Replace the double angle with an appropriate identity (choose wisely!)
  2. Rearrange into standard form (= 0)
  3. Factorize the expression
  4. Solve each factor using general solution formulas
  5. If an interval is given, substitute k = 0, ±1, ±2, ... to find specific solutions
  6. Check which solutions fall within the given interval
⚠️
Critical Step: When you have cos 2x in an equation with sin x or cos x, choose the form of cos 2x that gives you only ONE trig function. This allows you to factorize!
Three Forms of cos 2x:

• Form 1: cos 2x = cos²x - sin²x
• Form 2: cos 2x = 2cos²x - 1
• Form 3: cos 2x = 1 - 2sin²x

Choose based on equation: Use Form 3 if equation has sin x, Form 2 if equation has cos x.

✏️ Worked Example

▼
Example 1 Complete Solution with General & Interval

Problem: For the equation cos 2x + 3 sin x = 2, find:

a) The general solution

b) The solution for x in the interval [-270°; 180°]

Part (a): General Solution
1
Choose the right identity for cos 2x. Since the equation has sin x, use: cos 2x = 1 - 2sin²x

(1 - 2sin²x) + 3 sin x = 2

2
Rearrange to standard form (= 0)

1 - 2sin²x + 3 sin x = 2

-2sin²x + 3 sin x + 1 - 2 = 0

-2sin²x + 3 sin x - 1 = 0

3
Multiply by -1 to make leading coefficient positive (easier to factor)

2sin²x - 3 sin x + 1 = 0

4
Factorize (treat sin x as a variable, like factoring 2m² - 3m + 1)

(2 sin x - 1)(sin x - 1) = 0

5
Solve each factor

From (2 sin x - 1) = 0:

sin x = ½

x = sin⁻¹(½) + k·360° = 30° + k·360°

or x = 180° - 30° + k·360° = 150° + k·360°


From (sin x - 1) = 0:

sin x = 1

x = sin⁻¹(1) + k·360° = 90° + k·360°

General Solution:
x = 30° + k·360°   or   x = 150° + k·360°   or   x = 90° + k·360°, where k ∈ ℤ
Part (b): Solutions in [-270°; 180°]
6
Substitute different values of k into each general solution formula
k value x = 30° + k·360° x = 150° + k·360° x = 90° + k·360°
k = 1 390° (> 180°) 510° (> 180°) 450° (> 180°)
k = 0 30° ✓ 150° ✓ 90° ✓
k = -1 -330° (< -270°) -210° ✓ -270° ✓
7
List all valid solutions within [-270°; 180°]
Solutions in [-270°; 180°]:
x ∈ {-270°; -210°; 30°; 90°; 150°}
📝
Tip: When listing solutions in an interval, write them in ascending order and use set notation { } or list them with semicolons.

Question 1: What is the general solution for sin θ = ½?

A) θ = 30° + k·180°
B) θ = 30° + k·360° or θ = 150° + k·360°
C) θ = ±30° + k·360°
D) θ = 30° + k·360° only
Explanation: For sin θ = a, the general solution is θ = sin⁻¹(a) + k·360° OR θ = (180° - sin⁻¹(a)) + k·360°. So sin θ = ½ gives θ = 30° + k·360° or θ = 150° + k·360°.

Question 2: Why does tan θ use k·180° instead of k·360° in its general solution?

A) Because tan is always positive
B) Because tan has a period of 180°
C) Because tan is undefined at 90°
D) Because tan equals sin/cos
Explanation: The tangent function has a period of 180° (it repeats every 180°), unlike sine and cosine which have periods of 360°.

Question 3: To solve cos 2x + 3 sin x = 2, which identity should you use for cos 2x?

A) cos²x - sin²x
B) 2cos²x - 1
C) 1 - 2sin²x
D) Any of the above
Explanation: Since the equation contains sin x, use cos 2x = 1 - 2sin²x to get an equation with only sin x, which can then be factored.

Question 4: Solve 2sin²x - 3sin x + 1 = 0. What are the values of sin x?

A) sin x = 1 or sin x = 2
B) sin x = ½ or sin x = 1
C) sin x = -½ or sin x = -1
D) sin x = ½ or sin x = -1
Explanation: Factoring: (2sin x - 1)(sin x - 1) = 0, so sin x = ½ or sin x = 1.

Question 5: How do you solve sin 2x = cos x?

A) Replace sin 2x with 1 - 2cos²x
B) Replace sin 2x with 2sin x cos x, then factor
C) Divide both sides by cos x
D) Square both sides
Explanation: Replace sin 2x with 2sin x cos x to get 2sin x cos x = cos x. Then rearrange: 2sin x cos x - cos x = 0, factor: cos x(2sin x - 1) = 0.

Question 6: If sin x = -1, what is x in the interval [0°; 360°]?

A) 90°
B) 180°
C) 270°
D) 360°
Explanation: sin x = -1 at x = 270° (or -90° + k·360°). In [0°; 360°], the only solution is 270°.

Question 7: For a quadratic sequence, what must be constant?

A) First difference
B) Second difference
C) Ratio between terms
D) All differences
Explanation: Quadratic sequences have constant second difference. Linear have constant first difference.

Question 8: To solve cos 2x - 3cos x = -2, after using cos 2x = 2cos²x - 1, what quadratic do you get?

A) 2cos²x - 3cos x - 1 = 0
B) 2cos²x - 3cos x + 1 = 0
C) 2cos²x + 3cos x - 1 = 0
D) cos²x - 3cos x + 2 = 0
Explanation: cos 2x - 3cos x = -2 becomes (2cos²x - 1) - 3cos x = -2. Simplify: 2cos²x - 3cos x - 1 + 2 = 0, so 2cos²x - 3cos x + 1 = 0.

Question 9: What is the general solution for cos θ = -½?

A) θ = 120° + k·360° or θ = 240° + k·360°
B) θ = -60° + k·360°
C) θ = ±120° + k·360°
D) θ = 60° + k·180°
Explanation: For cos θ = a, the general solution is θ = ±cos⁻¹(a) + k·360°. Since cos⁻¹(-½) = 120°, we get θ = ±120° + k·360°.

Question 10: What are all solutions of cos x = 0 in the interval [-360°; 360°]?

A) {-270°; -90°; 90°; 270°}
B) {-90°; 90°}
C) {0°; 180°; 360°}
D) {-180°; 0°; 180°}
Explanation: cos x = 0 when x = ±90° + k·360°. In [-360°; 360°]: -270°, -90°, 90°, 270° all satisfy this.
