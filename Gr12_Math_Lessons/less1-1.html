📚 Key Theory & Definitions

▼

Overview

This lesson focuses on two fundamental types of sequences: Linear (Arithmetic) Sequences and Quadratic Sequences. Mastery of these patterns is essential for understanding more complex mathematical concepts.

Concept 1: Linear (Arithmetic) Sequences

An arithmetic sequence is any sequence where the difference between consecutive terms is constant. This constant is called the common difference (d).

Tn = a + (n – 1)d
where: a = first term, d = common difference, n = term number
Worked Example 1: Finding T₁₁ in the sequence 4; 7; 10; …

Step 1: Identify a and d

  • First term: a = 4
  • Common difference: d = 7 – 4 = 3

Step 2: Use the formula with n = 11

T₁₁ = 4 + (11 – 1)(3) = 4 + 30 = 34

Concept 2: Quadratic Sequences

A quadratic sequence is one where the first differences are not constant, but the second differences are constant.

Tn = an² + bn + c
where the second difference = 2a
Worked Example 2: Find the formula for 5; 18; 37; 58; …

Step 1: Calculate differences

Terms 5 18 37 58
1st Difference — 13 19 21
2nd Difference — — 6 6

Step 2: Solve for a, b, c

  • From 2a = 6: a = 3
  • From 3a + b = 13: 9 + b = 13, so b = 4
  • From a + b + c = T₁: 3 + 4 + c = 5, so c = –2

Formula: Tn = 3n² + 4n – 2

Key Takeaways

  • Arithmetic sequences have a constant first difference (d).
  • Quadratic sequences have a constant second difference (2a).
  • Always calculate differences to identify sequence type.
  • Use the appropriate formula to find any term without listing the entire sequence.

Question 1: Which equation represents a quadratic sequence?

A) Tn = 4n – 19
B) Tn = a + (n – 1)d
C) Tn = an² + bn + c
D) Tn = arn–1
Explanation: Quadratic sequences follow the general form Tn = an² + bn + c. Option A is linear, B is the arithmetic formula, and D is geometric.

Question 2: Find T₅₅ in the sequence 2; 6; 10; 14; …

A) 218
B) 222
C) 438
D) 385
Explanation: a = 2, d = 4. T₅₅ = 2 + (55 – 1)(4) = 2 + 216 = 218. Always identify a and d first!

Question 3: What is the defining characteristic of a linear sequence?

A) A constant ratio (r) between consecutive terms.
B) A constant sum (Sn) of terms.
C) A constant second difference (d₂).
D) A constant difference (d) between consecutive terms.
Explanation: Linear (arithmetic) sequences are defined by having a constant first difference. This is what makes them "linear."
