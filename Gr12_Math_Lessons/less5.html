Arithmetic Series

Advanced Sum Calculations & Problem Solving

Learning Objectives

  • 1
    Find the sum of an arithmetic series when the number of terms is not initially known
  • 2
    Determine the value of n when the sum of a series is given
  • 3
    Solve problems when a variety of information about the sequence is provided

Lesson Overview

In this lesson, we'll tackle more complex problems involving arithmetic series. You'll learn to work backwards from sums to find the number of terms, and solve problems where multiple pieces of information are given simultaneously. These skills are essential for exam success and form the foundation for more advanced mathematical concepts.

Key Formulas for This Lesson

Tₙ = a + (n-1)d   |   Sₙ = n/2[2a + (n-1)d]   |   Sₙ = n/2(a + l)

Symbol Meaning
a First term of the sequence
d Common difference
n Number of terms (position)
Tₙ The nth term (general term)
l Last term of the series
Sₙ Sum of the first n terms
📚

Main Concepts & Worked Examples

Concept 1: Finding Sum When Last Term is Known

When given a series with a known last term, first find how many terms there are, then calculate the sum.

📝 Worked Example 1

Problem: Consider the arithmetic series 3 + 5 + 7 + .... + 111. Determine how many terms are in the series and find the sum.

Step 1: Identify the values

a = 3, d = 5 - 3 = 2, Tₙ = 111

Step 2: Find n using the general term formula

Tₙ = a + (n-1)d

111 = 3 + (n-1)(2)

111 = 3 + 2n - 2

111 = 2n + 1

110 = 2n

n = 55

Step 3: Calculate the sum using Sₙ = n/2(a + l)

S₅₅ = 55/2(3 + 111)

S₅₅ = 55/2 × 114

S₅₅ = 55 × 57

There are 55 terms and the sum is S₅₅ = 3135

Concept 2: Finding n When Sum is Given

When the sum is given and you need to find how many terms, substitute into the sum formula and solve the resulting quadratic equation.

📝 Worked Example 2

Problem: How many terms of the arithmetic sequence 4; 7; 10; 13;.... will add up to 175?

Step 1: Identify the values

a = 4, d = 7 - 4 = 3, Sₙ = 175

Step 2: Substitute into the sum formula

Sₙ = n/2[2a + (n-1)d]

175 = n/2[2(4) + (n-1)(3)]

175 = n/2[8 + 3n - 3]

175 = n/2[3n + 5]

Step 3: Solve the quadratic equation

350 = n(3n + 5)

350 = 3n² + 5n

3n² + 5n - 350 = 0

(3n + 35)(n - 10) = 0

n = -35/3 or n = 10

Step 4: Select valid answer

Since n must be a positive integer (number of terms), n = -35/3 is rejected.

n = 10 terms

📝 Worked Example 3

Problem: The sum of (-8) + (-2) + 4 + ...... is 1600. How many terms are there?

Step 1: Identify the values

a = -8, d = -2 - (-8) = 6, Sₙ = 1600

Step 2: Substitute into the sum formula

1600 = n/2[2(-8) + (n-1)(6)]

1600 = n/2[-16 + 6n - 6]

1600 = n/2[6n - 22]

3200 = n(6n - 22)

Step 3: Solve the quadratic

3200 = 6n² - 22n

6n² - 22n - 3200 = 0

3n² - 11n - 1600 = 0

(3n + 64)(n - 25) = 0

n = 25 terms

Concept 3: Using Simultaneous Equations

When given multiple pieces of information (like a specific term and a sum), create equations and solve them simultaneously.

📝 Worked Example 4

Problem: The sum of the first 12 terms of an arithmetic series is 96. The 3rd and 6th terms add up to 12. Determine the first term and common difference.

Step 1: Create equation from sum information

S₁₂ = 96

96 = 12/2[2a + (12-1)d]

96 = 6[2a + 11d]

16 = 2a + 11d .......(A)

Step 2: Create equation from terms information

T₃ + T₆ = 12

[a + 2d] + [a + 5d] = 12

2a + 7d = 12 .......(B)

Step 3: Solve simultaneously

Equation (A): 2a + 11d = 16

Equation (B): 2a + 7d = 12

(A) - (B): 4d = 4

d = 1

Step 4: Substitute back to find a

2a + 7(1) = 12

2a = 5

a = 5/2 = 2.5

First term a = 5/2 and common difference d = 1

📝 Worked Example 5

Problem: The 8th term of an arithmetic series is 16 and the sum of the first 10 terms is 210. Calculate the sum of the first 15 terms.

Step 1: Create equation from T₈ = 16

a + 7d = 16 .......(A)

Step 2: Create equation from S₁₀ = 210

210 = 10/2[2a + 9d]

210 = 5[2a + 9d]

42 = 2a + 9d .......(B)

Step 3: Solve simultaneously

From (A): a = 16 - 7d

Substitute into (B): 42 = 2(16 - 7d) + 9d

42 = 32 - 14d + 9d

10 = -5d

d = -2

a = 16 - 7(-2) = 16 + 14 = 30

Step 4: Calculate S₁₅

S₁₅ = 15/2[2(30) + (15-1)(-2)]

S₁₅ = 15/2[60 - 28]

S₁₅ = 15/2 × 32

S₁₅ = 240
