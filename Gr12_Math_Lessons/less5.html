Advanced Arithmetic Series (Lesson 5)

Grade: 12
Week: Term 1 Week 1
Time: 30 minutes
Topic: Series (5)
Lesson: 5

Advanced problems: Finding sum when n is unknown, finding n from sum, and solving with mixed information

🎯 Lesson Objectives

▼

This lesson tackles advanced arithmetic series problems. By the end of this lesson, you will be able to:

  • Find the sum of a series when the number of terms is not known initially
  • Determine the number of terms (n) when the sum (Sₙ) is given
  • Solve complex problems with mixed information using simultaneous equations
  • Handle quadratic equations that arise from Sₙ formulas
  • Reject invalid solutions (like negative n values)

Key Formula 1

Tₙ = a + (n-1)d
Find n when last term is known

Key Formula 2

Sₙ = n/2 [2a + (n-1)d]
Solve for n when Sₙ is known

Key Formula 3

Sₙ = n/2 (a + l)
When first and last terms are known

🧠 Pre-Knowledge Required

▼

Before starting this lesson, you should be comfortable with:

  • What an arithmetic series is
  • Proving the formula for the sum of the first n terms
  • Calculating Sₙ when all parameters are known
  • Solving linear equations
  • Solving quadratic equations
  • Working with simultaneous equations

🔍 Type 1: Find n first, then Sₙ

▼

When last term is known but n is unknown

Problem: Consider the arithmetic series 3 + 5 + 7 + ... + 111. Determine: a) How many terms are in the series? b) What is the sum of the series?
  • Step 1: Identify known values
    First term: a = 3
    Common difference: d = 5 - 3 = 2
    Last term: Tₙ = 111
  • Step 2: Find n using Tₙ formula
    Tₙ = a + (n-1)d
    111 = 3 + (n-1)2
    111 = 3 + 2n - 2
    111 = 2n + 1
    110 = 2n
    n = 55
  • Step 3: Find Sₙ using formula with known last term
    Sₙ = n/2 (a + l)
    S₅₅ = 55/2 (3 + 111)
    S₅₅ = 27.5 × 114
    S₅₅ = 3135
  • Alternative: Use Sₙ = n/2 [2a + (n-1)d]
    S₅₅ = 55/2 [2(3) + (55-1)2]
    S₅₅ = 27.5 [6 + 108]
    S₅₅ = 27.5 × 114 = 3135

    • Answer: n = 55 terms, S₅₅ = 3135

    📝 Strategy Summary

    When given: First term, common difference, and last term

    Step 1: Use Tₙ = a + (n-1)d to find n

    Step 2: Use Sₙ = n/2 (a + l) to find sum (most efficient)

    Step 3: Verify with Sₙ = n/2 [2a + (n-1)d] if needed

    🔢 Type 2: Find n from Sₙ

    ▼

    When sum is known but n is unknown

    Problem: How many terms (n) of the arithmetic sequence 4; 7; 10; 13; ... will add up to 175?
  • Step 1: Identify known values
    First term: a = 4
    Common difference: d = 7 - 4 = 3
    Sum: Sₙ = 175
  • Step 2: Apply Sₙ formula
    Sₙ = n/2 [2a + (n-1)d]
    175 = n/2 [2(4) + (n-1)3]
    175 = n/2 [8 + 3n - 3]
    175 = n/2 [3n + 5]
  • Step 3: Clear fraction and simplify
    175 × 2 = n(3n + 5)
    350 = 3n² + 5n
    3n² + 5n - 350 = 0
  • Step 4: Solve quadratic equation
    Using quadratic formula or factorization:
    3n² + 5n - 350 = 0
    (3n + 35)(n - 10) = 0
    n = -35/3 or n = 10
  • Step 5: Reject invalid solution
    n = -35/3 is not valid (number of terms cannot be negative or fractional)
    n = 10 is valid
  • Step 6: Verify
    S₁₀ = 10/2 [2(4) + (10-1)3] = 5[8 + 27] = 5 × 35 = 175 ✓

    • Answer: n = 10 terms

    Quadratic Solution Method:
    3n² + 5n - 350 = 0

    Using quadratic formula: n = [-b ± √(b² - 4ac)] / 2a
    Where a = 3, b = 5, c = -350

    n = [-5 ± √(25 - 4×3×-350)] / (2×3)
    n = [-5 ± √(25 + 4200)] / 6
    n = [-5 ± √4225] / 6
    n = [-5 ± 65] / 6
    n = 60/6 = 10 or n = -70/6 = -35/3

    🧩 Type 3: Mixed Information Problems

    ▼

    When multiple pieces of information are given

    Problem: The sum of the first 12 terms of an arithmetic series is 96. The 3rd and 6th terms add up to 12. Determine the first term and common difference.
  • Step 1: Write what we know
    S₁₂ = 96
    T₃ + T₆ = 12
  • Step 2: Write formulas
    Sₙ = n/2 [2a + (n-1)d]
    Tₙ = a + (n-1)d
  • Step 3: Create equations
    For S₁₂ = 96:
    96 = 12/2 [2a + (12-1)d]
    96 = 6[2a + 11d]
    16 = 2a + 11d ...(Equation A)
  • Step 4: Second equation from T₃ + T₆ = 12
    T₃ = a + (3-1)d = a + 2d
    T₆ = a + (6-1)d = a + 5d
    (a + 2d) + (a + 5d) = 12
    2a + 7d = 12 ...(Equation B)
  • Step 5: Solve simultaneous equations
    Equation A: 2a + 11d = 16
    Equation B: 2a + 7d = 12

    Subtract B from A:
    (2a + 11d) - (2a + 7d) = 16 - 12
    4d = 4
    d = 1
  • Step 6: Find a
    Substitute d = 1 into Equation B:
    2a + 7(1) = 12
    2a + 7 = 12
    2a = 5
    a = 2.5
  • Step 7: Verify
    Check S₁₂: S₁₂ = 12/2 [2(2.5) + 11(1)] = 6[5 + 11] = 6 × 16 = 96 ✓
    Check T₃ + T₆: T₃ = 2.5 + 2(1) = 4.5, T₆ = 2.5 + 5(1) = 7.5, Sum = 12 ✓

    • Answer: a = 2.5, d = 1

    Equation A: 2a + 11d = 16
    Equation B: 2a + 7d = 12
    Subtract B from A: 4d = 4
    Therefore: d = 1, a = 2.5

    ✏️ Class Work & Practice

    ▼

    📝 Informal Assessment 2.1

    Problem: The sum of (-8) + (-2) + 4 + ... is 1600. How many terms are there?

    Hint: a = -8, d = 6, Sₙ = 1600. Solve quadratic for n.

    Answer: n = 25

    Solution to Informal Assessment 2.1

    Series: (-8) + (-2) + 4 + ...

  • a = -8
  • d = (-2) - (-8) = 6
  • Sₙ = 1600
  • Sₙ = n/2 [2a + (n-1)d]
  • 1600 = n/2 [2(-8) + (n-1)6]
  • 1600 = n/2 [-16 + 6n - 6]
  • 1600 = n/2 [6n - 22]
  • 3200 = n(6n - 22)
  • 3200 = 6n² - 22n
  • 6n² - 22n - 3200 = 0
  • Divide by 2: 3n² - 11n - 1600 = 0
  • Solve: (3n + 64)(n - 25) = 0
  • n = -64/3 or n = 25
  • n = 25 (reject negative/fractional)

    • 📝 Class Work 2.2

    Problem: The 8th term of an arithmetic series is 16 and the sum of the first 10 terms is 210. Calculate the sum of the first 15 terms.

    Hint: Use T₈ = 16 and S₁₀ = 210 to create equations, solve for a and d, then find S₁₅.

    Answer: S₁₅ = 240

    Solution to Class Work 2.2
  • Step 1: Create equations
    T₈ = a + 7d = 16 ...(1)
    S₁₀ = 10/2 [2a + 9d] = 210
    5[2a + 9d] = 210
    2a + 9d = 42 ...(2)
  • Step 2: Solve simultaneously
    From (1): a = 16 - 7d
    Substitute into (2): 2(16 - 7d) + 9d = 42
    32 - 14d + 9d = 42
    32 - 5d = 42
    -5d = 10
    d = -2
  • Step 3: Find a
    a = 16 - 7(-2) = 16 + 14 = 30
  • Step 4: Find S₁₅
    S₁₅ = 15/2 [2(30) + (15-1)(-2)]
    S₁₅ = 7.5 [60 + 14(-2)]
    S₁₅ = 7.5 [60 - 28]
    S₁₅ = 7.5 × 32 = 240

    ✓ Comprehensive Quiz (12 Questions)

    ▼

    Test your understanding of advanced arithmetic series problems with these 12 questions.

    Question 1: For 3 + 5 + 7 + ... + 111, what is n?

    A) 53
    B) 54
    C) 55
    D) 56
    Explanation: Using Tₙ = a + (n-1)d: 111 = 3 + (n-1)2 → 111 = 2n + 1 → 110 = 2n → n = 55.

    Question 2: For 3 + 5 + 7 + ... + 111, what is Sₙ?

    A) 3110
    B) 3120
    C) 3135
    D) 3140
    Explanation: S₅₅ = 55/2 (3 + 111) = 27.5 × 114 = 3135.

    Question 3: For 4 + 7 + 10 + ... with Sₙ = 175, what is n?

    A) 8
    B) 9
    C) 10
    D) 11
    Explanation: 175 = n/2 [8 + (n-1)3] → 350 = n(3n+5) → 3n²+5n-350=0 → (3n+35)(n-10)=0 → n=10.

    Question 4: Why is n = -35/3 rejected in the previous problem?

    A) Number of terms must be positive integer
    B) It gives negative sum
    C) It's too small
    D) It's not a perfect square
    Explanation: The number of terms in a series (n) must be a positive integer. Negative or fractional values are not valid.

    Question 5: For (-8) + (-2) + 4 + ... with Sₙ = 1600, what is n?

    A) 20
    B) 22
    C) 24
    D) 25
    Explanation: 1600 = n/2 [-16 + (n-1)6] → 3200 = n(6n-22) → 6n²-22n-3200=0 → (3n+64)(n-25)=0 → n=25.

    Question 6: If S₁₂ = 96 and T₃ + T₆ = 12, what is d?

    A) 0.5
    B) 1
    C) 1.5
    D) 2
    Explanation: Equations: 2a+11d=16 and 2a+7d=12. Subtract: 4d=4 → d=1.

    Question 7: If S₁₂ = 96 and T₃ + T₆ = 12, what is a?

    A) 2
    B) 2.5
    C) 3
    D) 3.5
    Explanation: With d=1: 2a+7(1)=12 → 2a=5 → a=2.5.

    Question 8: If T₈ = 16 and S₁₀ = 210, what is d?

    A) -3
    B) -2
    C) -1
    D) 2
    Explanation: Equations: a+7d=16 and 2a+9d=42. Solve: a=16-7d → 2(16-7d)+9d=42 → 32-14d+9d=42 → -5d=10 → d=-2.

    Question 9: If T₈ = 16 and S₁₀ = 210, what is S₁₅?

    A) 220
    B) 230
    C) 240
    D) 250
    Explanation: With a=30, d=-2: S₁₅ = 15/2 [60 + 14(-2)] = 7.5[60-28] = 7.5×32 = 240.

    Question 10: Which formula is best when you know first and last terms?

    A) Sₙ = n/2 [2a + (n-1)d]
    B) Sₙ = n/2 (a + l)
    C) Tₙ = a + (n-1)d
    D) Sₙ = a(1-rⁿ)/(1-r)
    Explanation: Sₙ = n/2 (a + l) is most efficient when you know the first term (a) and last term (l).

    Question 11: When solving for n from Sₙ, what type of equation do you get?

    A) Linear
    B) Quadratic
    C) Cubic
    D) Exponential
    Explanation: Sₙ = n/2 [2a + (n-1)d] becomes n[2a + (n-1)d] = 2Sₙ, which expands to a quadratic in n.

    Question 12: What's the first step when given mixed information?

    A) Guess values for a and d
    B) Write equations using Sₙ and Tₙ formulas
    C) Assume n = 10
    D) Use quadratic formula immediately
    Explanation: The first step is to translate the given information into equations using the formulas Sₙ = n/2 [2a + (n-1)d] and Tₙ = a + (n-1)d.
