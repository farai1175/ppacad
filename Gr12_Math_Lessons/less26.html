Definition of Logarithms & Form Conversion

Understanding what logarithms are and how to convert between forms

📚 Learning Objectives

  • Demonstrate an understanding of the definition of a logarithm
  • Use and describe the definition of a logarithm correctly
  • Convert from logarithmic form to exponential form
  • Convert from exponential form to logarithmic form
  • Solve problems involving logarithms of various types
  • Apply logarithm concepts to solve real-life problems

📋 Overview

Logarithms are one of the most powerful tools in mathematics. They allow us to solve equations where the unknown is in the exponent - something that would otherwise be very difficult. In this introductory lesson, we'll learn what a logarithm actually is, understand its connection to exponents, and practice converting between logarithmic and exponential forms.

🎯 Key Insight

A logarithm answers the question: "What power do I need to raise this base to, in order to get this number?"

📐 Main Concepts & Principles

1. What is a Logarithm?

Definition of Logarithm

If a number is written in exponential form, then the exponent is called the logarithm of the number.

For example, the number 8 can be written in exponential form as:

8 = 2³

Here, the exponent is 3 and the base is 2. We can say that the logarithm of 8 to base 2 is 3.

This is written as:

log₂8 = 3

The Relationship Between Exponents and Logarithms

EXPONENTIAL FORM
baseexponent = number
2³ = 8
⟷
LOGARITHMIC FORM
logbase(number) = exponent
log₂(8) = 3

The logarithm IS the exponent!

2. General Definition

Formal Definition

y = logax if and only if x = aʸ

Where: a > 0, a ≠ 1, and x ∈ ℝ⁺ (x must be positive)

🔑 Understanding the Parts

  • a = the base (must be positive and not equal to 1)
  • x = the number (must be positive)
  • y = the logarithm (the exponent/power)

3. Converting from Exponential to Logarithmic Form

Examples: Exponential → Logarithmic

Exponential Form Logarithmic Form Explanation
49½ = 7 log₄₉7 = ½ Log of 7 to base 49 equals ½
2⁻² = ¼ log₂(¼) = -2 Log of ¼ to base 2 equals -2
43/2 = 8 log₄8 = 3/2 Log of 8 to base 4 equals 3/2
10³ = 1000 log₁₀1000 = 3 Log of 1000 to base 10 equals 3
5⁰ = 1 log₅1 = 0 Log of 1 to any base equals 0

4. Converting from Logarithmic to Exponential Form

Examples: Logarithmic → Exponential

Logarithmic Form Exponential Form Explanation
log₂₅5 = ½ 25½ = 5 25 to the power ½ equals 5
log₂(¼) = -2 2⁻² = ¼ 2 to the power -2 equals ¼
log₇2401 = 4 7⁴ = 2401 7 to the power 4 equals 2401
log₁₀0.01 = -2 10⁻² = 0.01 10 to the power -2 equals 0.01
log₃81 = 4 3⁴ = 81 3 to the power 4 equals 81
⚠️ Important: It is essential to convert fluently between these two forms. This skill is fundamental to solving logarithmic equations!

5. Solving Logarithmic Equations

Type 1: Evaluating Logarithms

Problem: Evaluate log(0.01)

1 Let log(0.01) = x

2 Convert to exponential form: 0.01 = 10ˣ

3 Write 0.01 as a power of 10: 10⁻² = 10ˣ

4 Since bases are equal, exponents are equal: x = -2

∴ log(0.01) = -2

Type 2: Finding the Exponent (x)

Problem: Solve log₁₆4 = x

1 Convert to exponential form: 16ˣ = 4

2 Write with common base: (4²)ˣ = 4¹

3 Simplify: 4²ˣ = 4¹

4 Equate exponents: 2x = 1

5 Solve: x = ½

∴ log₁₆4 = ½

Type 3: Finding the Argument (x)

Problem: Solve log¼x = -1

1 Convert to exponential form: (¼)⁻¹ = x

2 Evaluate: x = 4

∴ x = 4

Type 4: Finding the Base (x)

Problem: Solve logₓ2 = -1

1 Convert to exponential form: x⁻¹ = 2

2 Rewrite: 1/x = 2

3 Solve: x = ½

∴ x = ½
