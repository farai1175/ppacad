Inverse Functions

Grade: 12
Week: Term 1 Week 5
Time: 60 minutes
Topic: Inverses of Functions

Learn how to find and sketch inverse functions, determine when an inverse is also a function, and understand symmetry over the line y = x.

✓ Lesson Objectives

▼

By the end of this lesson, you will be able to:

  • Define a function as a special type of relation
  • Use the vertical line test and horizontal line test correctly
  • Find the inverse of a function algebraically: swap x and y, solve for y
  • Sketch the graph of an inverse and recognize symmetry about y = x
  • Determine whether the inverse of a given function is also a function
  • Understand the relationship between domain/range of f and f⁻¹

📚 Core Concepts

▼

1. Relation vs Function

Relation: Any set of ordered pairs (x, y)

Function: A relation where each x-value is paired with only one y-value.

Vertical Line Test: If any vertical line cuts the graph more than once → NOT a function.

2. One-to-One vs Many-to-One

Horizontal Line Test:

  • If every horizontal line cuts the graph once → one-to-one
  • If any horizontal line cuts it more than once → many-to-one

Only one-to-one functions have inverses that are also functions.

3. Finding the Inverse

Steps to find f⁻¹(x):

1. Replace f(x) with y
2. Swap x and y
3. Solve for y
4. Replace y with f⁻¹(x)

4. Graphical Properties

  • The graph of f⁻¹ is the reflection of f over the line y = x
  • Domain of f = Range of f⁻¹
  • Range of f = Domain of f⁻¹
  • x-intercept of f = y-intercept of f⁻¹ (and vice versa)

💡 Worked Examples

▼

Example 1: Linear Function

f(x) = 2x + 4. Find f⁻¹(x).
  • y = 2x + 4
  • Swap: x = 2y + 4
  • Solve: 2y = x – 4 → y = (x – 4)/2
  • f⁻¹(x) = (x – 4)/2

Since f is one-to-one (linear with a ≠ 0), f⁻¹ is a function.

Example 2: Quadratic Function

f(x) = x². Find f⁻¹(x).
  • y = x²
  • Swap: x = y²
  • Solve: y = ±√x

f⁻¹(x) = ±√x → not a function (fails vertical line test).
Quadratic is many-to-one → inverse is a relation, not a function.

Example 3: Domain Restriction

f(x) = x², with domain x ≥ 0. Now find f⁻¹.

f is one-to-one on this domain.

  • y = x², x ≥ 0
  • x = y² → y = √x (only positive root!)
  • f⁻¹(x) = √x → now a function!

💡 Key Insight

Inverses are functions ONLY if the original is one-to-one.
Use the horizontal line test first!

❓ Quick Quiz (6 Questions)

▼

Test your understanding of inverse functions.

Q1: Which test determines if a graph is a function?

A) Vertical Line Test
B) Horizontal Line Test
C) Diagonal Test
D) Swap Test
Answer: Vertical line test checks if any x has multiple y's.

Q2: f(x) = 3x – 6. What is f⁻¹(x)?

A) (x + 6)/3
B) (x + 6)/3
C) 3x + 6
D) x/3 – 6
Answer: Swap: x = 3y – 6 → y = (x+6)/3

Q3: Is the inverse of f(x) = x² a function?

A) Yes
B) No
C) Only if x ≥ 0
D) Always
Answer: f(x)=x² is many-to-one → inverse is not a function.

Q4: What line are f and f⁻¹ symmetric about?

A) x-axis
B) y-axis
C) y = x
D) y = 0
Answer: Reflection over y = x.

Q5: If f(2) = 5, what is f⁻¹(5)?

A) 2
B) 5
C) -2
D) 1/5
Answer: Inverse reverses input and output.

Q6: Domain of f = [0, ∞). What is range of f⁻¹?

A) [0, ∞)
B) (–∞, ∞)
C) (–∞, 0]
D) Cannot tell
Answer: Range of f⁻¹ = Domain of f = [0, ∞).
