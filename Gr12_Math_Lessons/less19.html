Inverse Functions

Understanding and Finding Inverse Relations

🎯

Learning Objectives

  • Revise mathematical relations and define a function as a special relation
  • Understand the meaning and concept of an inverse function
  • Find the inverse of functions algebraically by interchanging x and y
  • Investigate graphs of inverse relations for linear, quadratic, and exponential functions
  • Determine which inverses are functions using the horizontal line test
🔄

Revision: Relations & Functions

📌 Relation

A relation is a rule that associates each element of the first set (domain) with at least one element of the second set (range). Any set of ordered pairs is a relation.

📌 Function

A function is a special relation where each element of the domain is associated with exactly one element of the range. Each x-value has only ONE y-value.

✅ One-to-One Function
  • Each x → exactly one y
  • Each y ← exactly one x
  • Passes BOTH vertical and horizontal line tests
  • Example: y = 2x + 3
✅ Many-to-One Function
  • Each x → exactly one y
  • Some y ← multiple x values
  • Passes vertical BUT NOT horizontal test
  • Example: y = x²

Remember the Tests!

Vertical Line Test: Determines if a graph is a function (each vertical line must cut the graph at most once)

Horizontal Line Test: Determines if a function is one-to-one (each horizontal line must cut the graph at most once)

What is an Inverse Function?

An inverse function reverses the action of the original function. If f transforms x into y, then f⁻¹ transforms y back into x.

x = 2
Input
→
f(x) = 2x + 3
y = 7
Output
x = 7
Input
→
f⁻¹(x) = (x-3)/2
y = 2
Output

📌 Inverse Function (f⁻¹)

The inverse function f⁻¹ "undoes" what f does. If f(a) = b, then f⁻¹(b) = a.

Note: The notation f⁻¹ does NOT mean 1/f(x). The -1 is not an exponent!

Key Insight: Reflection in y = x

The graph of a function and its inverse are reflections of each other in the line y = x.

This is because swapping x and y (which is how we find inverses) is equivalent to reflecting in y = x!

🔍

Finding the Inverse of a Function

Steps to Find f⁻¹(x)

1. Replace f(x) with y
2. Swap (interchange) x and y
3. Solve for y
4. Replace y with f⁻¹(x)

Example 1: Find the inverse of f(x) = 2x - 3

1 Write as y = 2x - 3
2 Swap x and y: x = 2y - 3
3 Solve for y: x + 3 = 2y → y = (x + 3)/2
4 Write as inverse: f⁻¹(x) = (x + 3)/2
f⁻¹(x) = (x + 3)/2

Example 2: Find the inverse of f(x) = 2x + 4

1 y = 2x + 4
2 Swap: x = 2y + 4
3 Solve: x - 4 = 2y → y = (x - 4)/2
f⁻¹(x) = (x - 4)/2 or f⁻¹(x) = ½x - 2

Intercepts Swap!

Notice that the x-intercept of f becomes the y-intercept of f⁻¹, and vice versa.

Similarly, the domain of f becomes the range of f⁻¹, and the range of f becomes the domain of f⁻¹.

❓

When is an Inverse a Function?

The Key Rule

The inverse of a function is also a function only if the original function is ONE-TO-ONE.

Original Function Type Inverse is a Function?
y = 2x + 3 One-to-one ✅ Yes
y = x² Many-to-one ❌ No (unless domain restricted)
y = 2ˣ One-to-one ✅ Yes
y = 1/x One-to-one ✅ Yes

Why doesn't y = x² have a function inverse?

Because y = x² is many-to-one: both x = 2 and x = -2 give y = 4.

When we find the inverse, we get y = ±√x, which gives TWO y-values for each x.

Solution: Restrict the domain! If x ≥ 0, then the inverse y = √x IS a function.

Lesson Summary

📝 Key Takeaways

  1. An inverse function f⁻¹ reverses the action of f: if f(a) = b, then f⁻¹(b) = a
  2. To find an inverse: swap x and y, then solve for y
  3. The graphs of f and f⁻¹ are reflections in the line y = x
  4. The domain of f becomes the range of f⁻¹ (and vice versa)
  5. An inverse is a function only if the original function is one-to-one
  6. Many-to-one functions require domain restriction for their inverses to be functions
