Quick Revision: Arithmetic Sequences

💡 Remember from Previous Lessons

Before we explore geometric sequences, let's recall the key concepts from arithmetic sequences:

  • First term = a
  • Common difference = d (calculated by subtracting a term from the next term)
  • In an arithmetic sequence, each term is calculated by adding the same number to the previous term
Formula Name Usage
Tₙ = a + (n-1)d General Term Find any term in the sequence
Sₙ = n/2[2a + (n-1)d] Sum Formula Find sum of first n terms
Sₙ = n/2(a + l) Sum with Last Term When last term (l) is known
AM = (a + b)/2 Arithmetic Mean Middle term between two numbers
📚

Introduction to Geometric Sequences

A Geometric Sequence is a sequence where each term is found by multiplying the previous term by a constant value called the common ratio (r).

🔑 Key Difference
Arithmetic Sequence Geometric Sequence
Add a constant (common difference d) Multiply by a constant (common ratio r)
Example: 2, 5, 8, 11, ... (d = 3) Example: 2, 6, 18, 54, ... (r = 3)
d = Tₖ₊₁ - Tₖ r = Tₖ₊₁ ÷ Tₖ

📝
Key Observation: In each sequence above, we multiply each term by the same number (the common ratio r) to get the next term. This is what makes them geometric sequences!
📐

Geometric Sequence Formulas

Common Ratio Formula

r = Tk+1 ÷ Tk

The common ratio is found by dividing any term by the previous term

General Term Formula

Tn = a · rn-1

Where: a = first term, r = common ratio, n = term position

Understanding the Formula

Let's see how the formula is derived:

Term Pattern Formula
T₁ a a · r⁰ = a
T₂ a × r a · r¹
T₃ a × r × r a · r²
T₄ a × r × r × r a · r³
... ... ...
Tₙ a × r × r × ... (n-1 times) a · rn-1
✏️

Worked Examples

Example 1 Finding a Specific Term

Problem: If a = 5 and r = -3, find T₈.

1 Write down the formula

Tₙ = a · rⁿ⁻¹

2 Substitute the values (use brackets!)

T₈ = (5) · (-3)⁸⁻¹

T₈ = (5) · (-3)⁷

3 Calculate using a calculator

T₈ = 5 × (-2187)

T₈ = -10935

💡
Calculator Tip: Always use brackets when substituting negative numbers to avoid sign errors!
Example 2 Working with a Given Sequence

Problem: Given the sequence: 2; 6; 18; 54; ... Find the 21st term.

1 Identify the values

a = 2 (first term)

r = 6 ÷ 2 = 3

n = 21

2 Apply the formula

Tₙ = a · rⁿ⁻¹

T₂₁ = (2) · (3)²¹⁻¹

T₂₁ = 2 · 3²⁰

3 Calculate

T₂₁ = 2 × 3,486,784,401

T₂₁ = 6,973,568,802

Example 3 Decreasing Sequence (Fractional r)

Problem: Given the sequence: 9; 3; 1; ... Find the 6th term.

1 Identify the values

a = 9

r = 3 ÷ 9 = 1/3

n = 6

2 Apply the formula

Tₙ = a · rⁿ⁻¹

T₆ = (9) · (1/3)⁶⁻¹

T₆ = 9 · (1/3)⁵

3 Calculate

T₆ = 9 × (1/243)

T₆ = 9/243 = 1/27

T₆ = 1/27 (or approximately 0.037)

📝
Note: When the sequence is decreasing, r is a fraction (0 < r < 1). The terms get smaller and smaller!
Example 4 Finding the Position of a Term

Problem: Which term in the sequence 3; 6; 12; 24; ... is equal to 768?

1 Identify the values

a = 3

r = 6 ÷ 3 = 2

Tₙ = 768

n = ?

2 Set up the equation

Tₙ = a · rⁿ⁻¹

768 = 3 · 2ⁿ⁻¹

3 Solve for n

768 ÷ 3 = 2ⁿ⁻¹

256 = 2ⁿ⁻¹

2⁸ = 2ⁿ⁻¹ (since 256 = 2⁸)

4 Equate exponents

8 = n - 1

n = 9

768 is the 9th term of the sequence
