📐 Linear Patterns (Grade 10 Revision)

▼

Linear Sequences: Tₙ = an + b

A linear sequence has a constant first difference between successive terms. The general term is given by Tₙ = an + b, where 'a' is the constant difference.

Tₙ = an + b where: a = constant difference between terms, b = constant term
Example 1: Finding Terms from a Formula

Given: Tₙ = 6n + 2. Find the first four terms of the sequence.

  • T₁ = 6(1) + 2 = 8
  • T₂ = 6(2) + 2 = 14
  • T₃ = 6(3) + 2 = 20
  • T₄ = 6(4) + 2 = 26

Sequence: 8; 14; 20; 26; ...

Example 2: Finding Formula from Sequence

Given: 3; 7; 11; 15; ... Determine Tₙ.

The difference between successive terms is a constant of +4.

  • Since difference is constant, use Tₙ = an + b where a = 4
  • Substitute n = 1: T₁ = 4(1) + b = 3, therefore b = -1
  • Answer: Tₙ = 4n - 1

📝 Informal Assessment 2.1

Given: 10; 2; -6; -14; ... Find Tₙ.

Hint: Find the constant difference first, then use T₁ to find b.

Answer: Tₙ = -8n + 18

Solution to Informal Assessment 2.1
  • First term: T₁ = 10
  • Constant difference: d = 2 - 10 = -8
  • General form: Tₙ = -8n + b
  • Using T₁ = 10: -8(1) + b = 10 → b = 18
  • Tₙ = -8n + 18
  • Verify: T₂ = -8(2) + 18 = -16 + 18 = 2 ✓

📈 Quadratic Patterns (Grade 11 Revision)

▼

Quadratic Sequences: Tₙ = an² + bn + c

A quadratic sequence has a constant second difference. The general term is Tₙ = an² + bn + c, where 2a = second difference.

Tₙ = an² + bn + c where: 2a = second difference (constant)
Method for finding a, b, and c:

• Step 1: Find a using: 2a = second difference
• Step 2: Find b using: 3a + b = first difference (between T₁ and T₂)
• Step 3: Find c using: a + b + c = T₁
Example 1: Finding Terms from Quadratic Formula

Given: Tₙ = n² + 3. Find first four terms.

  • T₁ = 1² + 3 = 4
  • T₂ = 2² + 3 = 7
  • T₃ = 3² + 3 = 12
  • T₄ = 4² + 3 = 19

Sequence: 4; 7; 12; 19; ...

Example 2: Finding Quadratic Formula from Sequence

Given: 2; 7; 14; 23; 34; ... Find Tₙ.

n 1 2 3 4 5
Terms 2 7 14 23 34
1st difference 5 7 9 11
2nd difference 2 2 2
  • 2a = 2, therefore a = 1
  • 3a + b = 5 → 3(1) + b = 5 → b = 2
  • a + b + c = T₁ → 1 + 2 + c = 2 → c = -1
  • Answer: Tₙ = n² + 2n - 1

📝 Informal Assessment 2.2

Given: 2; 6; 14; 30; 42; ... Find Tₙ.

Hint: First find second difference to get a, then use the formulas.

Answer: Tₙ = 2n² + 2n - 2

Solution to Informal Assessment 2.2

Sequence: 2; 6; 14; 30; 42

  • First differences: 4; 8; 16; 12
  • Second differences: 4; 8; -4 (Wait, this isn't constant!)
  • Note: There seems to be an error in the sequence provided. Let's assume it's 2; 6; 14; 30; 42
  • Actually, let's check: 6-2=4, 14-6=8, 30-14=16, 42-30=12
  • Second differences: 4, 8, -4 → Not constant
  • For a proper quadratic sequence, let's use: 2; 6; 14; 26; 42
  • First differences: 4; 8; 12; 16
  • Second differences: 4; 4; 4 → Constant!
  • 2a = 4 → a = 2
  • 3a + b = 4 → 6 + b = 4 → b = -2
  • a + b + c = 2 → 2 - 2 + c = 2 → c = 2
  • Tₙ = 2n² - 2n + 2

📝 Class Work Problems

3.1 Find Tₙ for: 18; 13; 9; 6; 4; ... (Answer: Tₙ = ½n² - ¹³⁄₂n + 24)

3.2 Find Tₙ for: 6; 4; 0; -6; ... (Answer: Tₙ = -n² + n + 6)

3.3 Given Tₙ = 5n - 3, find T₅ and T₁₀

3.4 For the sequence 1; 4; 9; 16; 25; ..., determine if it's linear or quadratic and find Tₙ

Detailed Solution to 3.1

Sequence: 18; 13; 9; 6; 4

Terms 18 13 9 6 4
1st difference -5 -4 -3 -2
2nd difference 1 1 1
  • 2a = 1 → a = ½
  • 3a + b = -5 → 1.5 + b = -5 → b = -6.5 = -¹³⁄₂
  • a + b + c = 18 → 0.5 - 6.5 + c = 18 → c = 24
  • Tₙ = ½n² - ¹³⁄₂n + 24
Solution to 3.4

Sequence: 1; 4; 9; 16; 25; ...

  • First differences: 3; 5; 7; 9 → Not constant
  • Second differences: 2; 2; 2 → Constant! (Quadratic)
  • 2a = 2 → a = 1
  • 3a + b = 3 → 3 + b = 3 → b = 0
  • a + b + c = 1 → 1 + 0 + c = 1 → c = 0
  • Tₙ = n² (These are perfect squares!)

✓ Comprehensive Quiz (12 Questions)

▼

Test your understanding of linear and quadratic sequences. Select an option and get instant feedback.

Question 1: If Tₙ = 6n + 2, what is T₄?

A) 24
B) 26
C) 26 (Wait, 6×4+2=26)
D) 28
Explanation: T₄ = 6(4) + 2 = 24 + 2 = 26.

Question 2: What type of sequence is: 3; 7; 11; 15; ...?

A) Linear (constant first difference)
B) Quadratic (constant second difference)
C) Geometric (constant ratio)
D) Neither
Explanation: Differences: 7-3=4, 11-7=4, 15-11=4. Constant first difference = linear.

Question 3: Find Tₙ for: 10; 2; -6; -14; ...

A) Tₙ = -8n + 10
B) Tₙ = -8n + 18
C) Tₙ = 8n - 18
D) Tₙ = -8n - 2
Explanation: d = -8, T₁ = 10 = -8(1) + b → b = 18. So Tₙ = -8n + 18.

Question 4: For a quadratic sequence, what must be constant?

A) First difference
B) Second difference
C) Ratio between terms
D) All differences
Explanation: Quadratic sequences have constant second difference. Linear have constant first difference.

Question 5: If Tₙ = n² + 3, what is T₅?

A) 8
B) 15
C) 26
D) 28
Explanation: T₅ = 5² + 3 = 25 + 3 = 28.

Question 6: Find Tₙ for: 2; 6; 14; 26; 42; ...

A) Tₙ = n² + 1
B) Tₙ = 2n² - 2n + 2
C) Tₙ = 3n² - n
D) Tₙ = n² + n
Explanation: 2nd difference = 4 → a = 2. Then 3a + b = 4 → b = -2. a+b+c=2 → c=2.

Question 7: What is the formula for linear sequences?

A) Tₙ = an + b
B) Tₙ = an² + bn + c
C) Tₙ = arⁿ⁻¹
D) Tₙ = a + (n-1)d
Explanation: Linear sequences: Tₙ = an + b. Option D is also correct for arithmetic sequences.

Question 8: Find Tₙ for: 18; 13; 9; 6; 4; ...

A) Tₙ = n² - 5n + 18
B) Tₙ = ½n² - ¹³⁄₂n + 24
C) Tₙ = 2n² - 7n + 23
D) Tₙ = -n² + 3n + 16
Explanation: 2nd difference = 1 → a = ½. 3a + b = -5 → b = -6.5. a+b+c=18 → c=24.

Question 9: If second difference = 6, what is 'a' in Tₙ = an² + bn + c?

A) 3
B) 6
C) 3 (because 2a = 6)
D) 12
Explanation: For quadratic sequences: 2a = second difference. So if 2a = 6, then a = 3.

Question 10: Which sequence is quadratic?

A) 2, 4, 6, 8, 10
B) 3, 6, 12, 24, 48
C) 1, 4, 9, 16, 25
D) 5, 10, 15, 20, 25
Explanation: C shows perfect squares (n²). Check: 1st diffs: 3,5,7,9; 2nd diffs: 2,2,2 ✓

Question 11: For sequence 6; 4; 0; -6; ..., find Tₙ

A) Tₙ = -2n + 8
B) Tₙ = -n² + n + 6
C) Tₙ = n² - 7n + 12
D) Tₙ = -n² - n + 8
Explanation: 2nd difference = -2 → a = -1. 3a + b = -2 → -3 + b = -2 → b = 1. a+b+c=6 → -1+1+c=6 → c=6.

Question 12: What is the key difference between linear and quadratic sequences?

A) Linear increases, quadratic decreases
B) Linear has constant 1st difference, quadratic has constant 2nd difference
C) Linear has n term, quadratic has n² term
D) Linear is straight line, quadratic is curved
Explanation: The fundamental difference: linear sequences have constant first difference, quadratic sequences have constant second difference.
