Number Patterns Revision

🎯 Learning Objectives

  • Revise linear number patterns of the format Tn = an + b from Grade 10
  • Revise quadratic number patterns of the format Tn = an² + bn + c from Grade 11
  • Calculate terms of a sequence given the general term formula

📋 Overview

In this lesson, we will revise the important concepts of number patterns that you learned in Grade 10 and Grade 11. These concepts form the foundation for understanding arithmetic and geometric sequences, which are essential topics in Grade 12 Mathematics.

A sequence is an ordered list of numbers following a specific pattern. Each number in the sequence is called a term, and we use Tn to represent the nth term of the sequence.

📘 Main Concepts & Principles

Linear Sequences: Tn = an + b

A linear sequence has a constant first difference between consecutive terms. The general term is given by:

Tn = an + b

Where:

  • a = the constant (common) difference between terms
  • b = a constant that adjusts the formula
  • n = the term number (position in sequence)

📝 Example 1: Finding Terms from a Formula

The general term Tn of a sequence is given by Tn = 6n + 2. Find the first four terms.

1 T1 = 6(1) + 2 = 6 + 2 = 8
2 T2 = 6(2) + 2 = 12 + 2 = 14
3 T3 = 6(3) + 2 = 18 + 2 = 20
4 T4 = 6(4) + 2 = 24 + 2 = 26

📝 Example 2: Finding the Formula from a Sequence

Given the sequence 3; 7; 11; 15; ... determine the formula for Tn.

1 Find the common difference: 7 - 3 = 4, 11 - 7 = 4, 15 - 11 = 4 → d = 4
2 Since the difference is constant, use Tn = an + b where a = 4
3 Substitute n = 1 and T1 = 3: 4(1) + b = 3 → b = -1
4 Therefore: Tn = 4n - 1

Quadratic Sequences: Tn = an² + bn + c

A quadratic sequence has a constant second difference. The general term is:

Tn = an² + bn + c

Key relationship: 2a = second difference

📝 Example 3: Finding Terms from a Quadratic Formula

Write down the first four terms of the sequence generated by Tn = n² + 3

1 T1 = (1)² + 3 = 1 + 3 = 4
2 T2 = (2)² + 3 = 4 + 3 = 7
3 T3 = (3)² + 3 = 9 + 3 = 12
4 T4 = (4)² + 3 = 16 + 3 = 19

📝 Example 4: Finding the Formula from a Quadratic Sequence

Find Tn if given the sequence 2; 7; 14; 23; 34; ...

Terms 27142334
1st Difference 57911
2nd Difference 222
1 Second difference is constant (2), so use Tn = an² + bn + c
2 2a = 2, therefore a = 1
3 Using 3a + b = first difference (5): 3(1) + b = 5 → b = 2
4 Using a + b + c = T₁: 1 + 2 + c = 2 → c = -1
5 Therefore: Tn = n² + 2n - 1
