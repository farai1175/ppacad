Topic: Inverses

Lesson 1 & 2

Introduction to Logarithmic Functions

Understanding logarithms as inverses of exponential functions

📚 Learning Objectives

  • Demonstrate the ability to work with various types of functions and relations, including inverses
  • Investigate and generate graphs of inverse relations of functions, particularly the inverse of y = aˣ (a > 0)
  • Investigate how to write the inverse of an exponential function with y as the subject – the logarithmic function
  • Understand the definition of a logarithm
  • Demonstrate the ability to change from exponential form to logarithmic form and vice versa
  • Identify characteristics of graphs: domain, range, intercepts with axes, and asymptotes

📋 Overview

In our previous lessons, we found that the inverse of an exponential function leads to an equation where making y the subject seemed problematic using standard algebraic methods. For example:

From our previous work:

• If f(x) = 2ˣ, then the inverse gives us x = 2ʸ

• If f(x) = (½)ˣ, then the inverse gives us x = (½)ʸ

Question: How do we solve for y in these equations?

In this lesson, we will discover the powerful mathematical tool called the logarithm, which allows us to solve for the exponent in exponential equations.

📐 Main Concepts & Principles

📜 Historical Note

In the late 1500s to early 1600s, the Scottish mathematician John Napier devised a brilliant way to make y the subject in equations like x = aʸ. He introduced a new notation called the logarithm, creating an entirely new function called the logarithmic function: y = logax (read as "log base a of x").

1. What is a Logarithm?

Definition of Logarithm

The logarithm (log) of a number is based on the definitions of exponents.

The log of a number, with regard to a given base, is the exponent of that base which will give you that number.

Let's understand this with numbers:

The exponent and the logarithm are THE SAME THING!

General Form

If x = aʸ (exponential form)

Then y = logax (logarithmic form)

The base stays the same in both forms!

2. Formal Definition

Definition

For a > 0 and a ≠ 1 as well as x > 0:

y = logax means x = aʸ

Restrictions:

  • The base (a) cannot be negative, zero, or 1
  • The number inside the log (x) must be greater than zero

3. Key Properties of Logarithms

logaa = 1

Because a¹ = a

Example: log₂2 = 1

loga1 = 0

Because a⁰ = 1

Example: log₃1 = 0

logn0 is undefined

Because no power of n can equal 0

n^anything ≠ 0

logaxᵐ = m·logax

Power law of logarithms

Example: log7² = 2·log7

5. Writing the Inverse as a Logarithm

Now We Can Solve Our Problem!

With logarithms, we can now make y the subject:

Exponential Inverse Logarithmic Form
x = 2ʸ y = log₂x
x = (½)ʸ y = log½x

The inverse of an exponential function is a logarithmic function!

6. Graphs of Logarithmic Functions

Since the logarithmic function is the inverse of the exponential function, they are reflections of each other in the line y = x.

Exponential: f(x) = aˣ

Inverse (Logarithmic): f⁻¹(x) = logax

7. Characteristics of y = logax (a > 0, a ≠ 1, x > 0)

  • Domain: x > 0 (only positive numbers)
  • Range: y ∈ ℝ (all real numbers)
  • y-intercept: None (graph never crosses y-axis)
  • x-intercept: (1, 0) since loga1 = 0 for all valid bases
  • Asymptote: The y-axis (x = 0) is a vertical asymptote
  • One-to-one: The function is one-to-one
  • Reflection: The graph of y = logax is the reflection of y = aˣ about the line y = x
📝 Behavior based on base:
  • If a > 1: As x increases, y increases (increasing function)
  • If 0 < a < 1: As x increases, y decreases (decreasing function)
  • As a increases, the curves become "flatter"

8. Comparison: Exponential vs Logarithmic Functions

Property y = aˣ y = logax
Domain x ∈ ℝ x > 0
Range y > 0 y ∈ ℝ
x-intercept None (1, 0)
y-intercept (0, 1) None
Asymptote y = 0 (horizontal) x = 0 (vertical)
Key Point (0, 1) (1, 0)
Behavior (a > 1) Increasing Increasing
Behavior (0 < a < 1) Decreasing Decreasing
