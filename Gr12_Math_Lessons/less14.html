🔄 Arithmetic vs Geometric: Key Differences

▼

Fundamental Differences

The core difference lies in how we get from one term to the next:

Aspect Arithmetic Sequence Geometric Sequence
Definition Sequence where each term is found by adding a constant to the previous term Sequence where each term is found by multiplying the previous term by a constant
Constant Common difference (d)
T₂ - T₁ = T₃ - T₂ = d		 Common ratio (r)
T₂/T₁ = T₃/T₂ = r
Pattern Linear growth/decay
Equal spacing between terms		 Exponential growth/decay
Equal multiplicative spacing
Means Arithmetic Mean: b = (a + c)/2 Geometric Mean: b = ±√(a·c)
Sum to Infinity NEVER converges (d ≠ 0)
Sum grows without bound		 Converges if |r| < 1
S∞ = a/(1-r)

💡 Quick Identification Trick

Arithmetic: Check differences between consecutive terms. If constant → arithmetic.

Geometric: Check ratios between consecutive terms. If constant → geometric.

Example: 2, 5, 8, 11 → differences: 3, 3, 3 (Arithmetic, d=3)

Example: 3, 6, 12, 24 → ratios: 2, 2, 2 (Geometric, r=2)

Visual Comparison

Compare these sequences side by side:

Arithmetic: 2, 5, 8, 11, 14

Pattern: Add 3 each time

d = 5 - 2 = 3

Formula: Tₙ = 2 + (n-1)×3

Growth: Linear (straight line)

Geometric: 2, 6, 18, 54, 162

Pattern: Multiply by 3 each time

r = 6 ÷ 2 = 3

Formula: Tₙ = 2 × 3ⁿ⁻¹

Growth: Exponential (curved)

⚠️ Common Confusion: Negative Common Ratio

Geometric sequences can have negative common ratios! This creates alternating sequences:

Example: 3, -6, 12, -24, 48,... (r = -2)

The terms alternate signs, but it's still geometric because the ratio is constant: -6/3 = -2, 12/(-6) = -2

📊 Complete Formula Reference

▼

Master all the formulas for both sequence types. Copy this into your notes for revision:

🎯 SEQUENCE FORMULA CHEAT SHEET

ARITHMETIC SEQUENCES

nth Term Formula

Tₙ = a + (n-1)d

Sum of n Terms (2 versions)

Sₙ = n/2 [2a + (n-1)d]
Sₙ = n/2 (a + l)

Common Difference

d = T₂ - T₁ = T₃ - T₂

Arithmetic Mean

AM = (a + b)/2
GEOMETRIC SEQUENCES

nth Term Formula

Tₙ = a·rⁿ⁻¹

Sum of n Terms (r ≠ 1)

Sₙ = a(rⁿ - 1)/(r - 1)
Sₙ = a(1 - rⁿ)/(1 - r)

Common Ratio

r = T₂/T₁ = T₃/T₂

Geometric Mean

GM = ±√(a·c)

Sum to Infinity (|r| < 1)

S∞ = a/(1-r)

📌 Formula Selection Guide

When to use which formula:

• Tₙ formula: When finding a specific term (e.g., "Find the 10th term")

• Sₙ formula: When finding sum of first n terms (e.g., "Sum of first 20 terms")

• S∞ formula: Only for geometric with |r| < 1 (e.g., "Sum to infinity")

• Mean formulas: When inserting terms between two numbers

💡 Memory Tips

Arithmetic: Think "Add" → starts with A, uses Addition

Geometric: Think "Multiply" → starts with G, uses multiplication and Growth factors

Sₙ formulas: For arithmetic, think "average of first and last times n"

Sₙ formulas: For geometric, remember both forms for r > 1 and r < 1

📝 Comprehensive Worked Examples

▼

Example 1: Identifying Sequence Type

Determine whether each sequence is arithmetic, geometric, or neither:
  • a) 4, 7, 10, 13, 16
    Differences: 7-4=3, 10-7=3, 13-10=3, 16-13=3
    ✓ ARITHMETIC (d = 3)
  • b) 2, 6, 18, 54, 162
    Ratios: 6/2=3, 18/6=3, 54/18=3, 162/54=3
    ✓ GEOMETRIC (r = 3)
  • c) 1, 4, 9, 16, 25
    Differences: 3, 5, 7, 9 (not constant)
    Ratios: 4, 2.25, 1.78, 1.56 (not constant)
    ✗ NEITHER (these are perfect squares)

Example 2: Mixed Problems

For the arithmetic sequence 5, 9, 13, 17,... and geometric sequence 2, 6, 18, 54,...
  • a) Find the 10th term of each sequence
    Arithmetic: a=5, d=4 → T₁₀ = 5 + (10-1)×4 = 5 + 36 = 41
    Geometric: a=2, r=3 → T₁₀ = 2 × 3⁹ = 2 × 19683 = 39,366
  • b) Find the sum of first 5 terms of each
    Arithmetic: S₅ = 5/2 [2×5 + (5-1)×4] = 2.5 × [10 + 16] = 2.5 × 26 = 65
    Geometric: S₅ = 2(3⁵ - 1)/(3-1) = 2(243-1)/2 = 242 = 242

Example 3: Real-World Comparison

Compare two investment options over 5 years:
  • Option A (Arithmetic growth):
    Year 1: R1000, each year adds R200
    Sequence: 1000, 1200, 1400, 1600, 1800
    Total after 5 years: S₅ = 5/2 [2×1000 + 4×200] = 2.5 × [2000 + 800] = R7000
  • Option B (Geometric growth):
    Year 1: R1000, grows by 20% each year
    Sequence: 1000, 1200, 1440, 1728, 2073.60
    Total after 5 years: S₅ = 1000(1.2⁵ - 1)/(1.2 - 1) = 1000 × 7.4416 = R7441.60
  • Conclusion: Geometric growth yields more due to compounding effect!

✓ Comprehensive Quiz (12 Questions)

▼

Test your understanding of both sequence types. Select an option and get instant feedback.

Question 1: Which sequence is arithmetic?

A) 2, 4, 8, 16, 32
B) 3, 7, 11, 15, 19
C) 1, 4, 9, 16, 25
D) 5, -10, 20, -40, 80
Explanation: Option B has constant difference: 7-3=4, 11-7=4, etc. Others are geometric or neither.

Question 2: Find T₁₀ for arithmetic: 8, 13, 18, 23,...

A) 48
B) 53
C) 58
D) 63
Explanation: a=8, d=5. T₁₀ = 8 + (10-1)×5 = 8 + 45 = 53.

Question 3: Find T₆ for geometric: 3, 6, 12, 24,...

A) 48
B) 64
C) 96
D) 192
Explanation: a=3, r=2. T₆ = 3 × 2⁵ = 3 × 32 = 96.

Question 4: Sum of first 20 terms: 5 + 9 + 13 + 17 + ...

A) 820
B) 860
C) 900
D) 940
Explanation: a=5, d=4. S₂₀ = 20/2 [2×5 + 19×4] = 10 × [10 + 76] = 10 × 86 = 860.

Question 5: Sum of first 5 terms: 4 + 12 + 36 + 108 + ...

A) 324
B) 400
C) 484
D) 532
Explanation: a=4, r=3. S₅ = 4(3⁵ - 1)/(3-1) = 4(243-1)/2 = 4 × 242/2 = 484.

Question 6: Which can have a sum to infinity?

A) Arithmetic with d=2
B) Geometric with r=0.5
C) Arithmetic with d=0.5
D) Geometric with r=2
Explanation: Only geometric sequences with |r| < 1 can converge. r=0.5 satisfies this.

Question 7: Insert 2 arithmetic means between 10 and 22

A) 12, 14
B) 13, 16
C) 14, 18
D) 15, 20
Explanation: d = (22-10)/3 = 4. Means: 10+4=14, 10+8=18. Sequence: 10, 14, 18, 22.

Question 8: Insert 1 geometric mean between 4 and 16

A) ±8
B) 8
C) 10
D) 12
Explanation: Geometric mean = √(4×16) = √64 = ±8. Two possible sequences: 4, 8, 16 or 4, -8, 16.

Question 9: Find r if geometric: T₂=12, T₄=108

A) 2
B) 2.5
C) 3
D) 4
Explanation: T₄/T₂ = r² = 108/12 = 9. So r = ±3.

Question 10: Find d if arithmetic: T₃=15, T₇=31

A) 3
B) 3.5
C) 4
D) 4.5
Explanation: T₇ - T₃ = 4d = 31-15 = 16. So d = 4.

Question 11: Which formula is for arithmetic sum?

A) Sₙ = a(rⁿ - 1)/(r - 1)
B) Sₙ = n/2 [2a + (n-1)d]
C) Sₙ = a/(1-r)
D) Sₙ = a·rⁿ⁻¹
Explanation: Option B is the arithmetic sum formula. A is geometric sum, C is sum to infinity, D is nth term.

Question 12: Real-world: Which shows exponential growth?

A) Salary increasing by R5000 yearly
B) Population growing 5% annually
C) Distance traveled at constant speed
D) Monthly savings adding R1000
Explanation: Percentage growth (5% annually) creates geometric/exponential growth. Fixed amounts create arithmetic growth.
