Inverses of Quadratic Functions

Grade: 12
Week: Term 1 Week 5
Time: 30 minutes
Topic: Inverses – Quadratic Functions (Lesson 3)

Learn why the inverse of a quadratic is not a function—and how to restrict its domain to make it one.

✓ Lesson Objectives

▼

By the end of this lesson, you will be able to:

  • Identify that quadratic functions are many-to-one
  • Find the inverse relation of a quadratic function
  • Explain why the inverse of a quadratic is not a function
  • Restrict the domain of a quadratic to make it one-to-one
  • Write the inverse function under a domain restriction
  • Sketch both f(x) and f⁻¹(x) on the same axes, showing symmetry over y = x

📚 Core Concepts

▼

1. Quadratic Functions are Many-to-One

A quadratic like \( f(x) = ax^2 \) (a ≠ 0) is a parabola.

It fails the horizontal line test: a horizontal line cuts it twice → many-to-one.

2. Inverse of a Quadratic is Not a Function

Example: \( f(x) = 2x^2 \)

  • Swap: \( x = 2y^2 \)
  • Solve: \( y^2 = \frac{x}{2} \) → \( y = \pm \sqrt{\frac{x}{2}} \)

Two outputs for one input → not a function (fails vertical line test).

⚠️ Critical Insight

Only one-to-one functions have inverses that are also functions.
Quadratics are not one-to-one over their full domain.

3. Restrict the Domain to Fix This

Two common restrictions for \( f(x) = 2x^2 \):

  • Option 1: \( x \geq 0 \) → right half of parabola (one-to-one)
  • Option 2: \( x \leq 0 \) → left half (also one-to-one)

Now the inverse becomes a function:

  • If \( f(x) = 2x^2,\ x \geq 0 \), then \( f^{-1}(x) = \sqrt{\frac{x}{2}},\ x \geq 0 \)
  • If \( f(x) = 2x^2,\ x \leq 0 \), then \( f^{-1}(x) = -\sqrt{\frac{x}{2}},\ x \geq 0 \)
Key Properties

• Graphs of f and f⁻¹ are symmetric about y = x
• Domain of f = Range of f⁻¹
• Range of f = Domain of f⁻¹
• Always restrict domain to make f one-to-one!

💡 Worked Examples

▼

Example 1: Inverse of f(x) = 2x² (No Restriction)

  • Let \( y = 2x^2 \)
  • Swap: \( x = 2y^2 \)
  • Solve: \( y^2 = \frac{x}{2} \) → \( y = \pm \sqrt{\frac{x}{2}} \)
  • Not a function! (two outputs)

Graph: sideways parabola opening right — fails vertical line test.

Example 2: Inverse with Domain x ≥ 0

\( f(x) = 2x^2,\ x \geq 0 \)

  • One-to-one on this domain
  • Inverse: \( f^{-1}(x) = \sqrt{\frac{x}{2}} \)
  • Domain of f⁻¹: \( x \geq 0 \) (same as range of f)
  • Range of f⁻¹: \( y \geq 0 \) (same as domain of f)

Now it passes the vertical line test → function!

Example 3: Inverse with Domain x ≤ 0

\( f(x) = 2x^2,\ x \leq 0 \)

  • Inverse: \( f^{-1}(x) = -\sqrt{\frac{x}{2}} \)
  • Domain of f⁻¹: \( x \geq 0 \)
  • Range of f⁻¹: \( y \leq 0 \)

Also a function! But reflected below the x-axis.

💡 Remember

The range of the original quadratic is always [0, ∞) (if a > 0), so the domain of the inverse is always x ≥ 0, regardless of restriction.

❓ Comprehensive Quiz (12 Questions)

▼

Test your mastery of quadratic inverses and domain restrictions.

Q1: Is f(x) = x² a one-to-one function?

A) Yes
B) No
C) Only if x ≥ 0
D) Only if x ≤ 0
Answer: Over all real numbers, no — fails horizontal line test.

Q2: What is the inverse of f(x) = 3x²?

A) √(3x)
B) ±3√x
C) ±√(x/3)
D) x²/3
Answer: Swap: x = 3y² → y = ±√(x/3)

Q3: Why is the inverse of x² not a function?

A) It fails the vertical line test
B) It fails the horizontal line test
C) Domain is negative
D) It has no intercepts
Answer: Inverse has two y-values for one x → fails vertical line test.

Q4: To make f(x) = x² invertible as a function, restrict domain to:

A) x ≤ 1
B) x ≥ 0
C) x ≠ 0
D) All real x
Answer: x ≥ 0 or x ≤ 0 — both work.

Q5: If f(x) = 4x² (x ≤ 0), what is f⁻¹(x)?

A) √(x/4)
B) -√(x/4)
C) ±√(x/4)
D) -4√x
Answer: Since original is left half, inverse is negative root.

Q6: What is the domain of f⁻¹ if f(x) = 5x² (full domain)?

A) x ≥ 0
B) x ≤ 0
C) All real x
D) x ≠ 0
Answer: Range of f is [0, ∞), so domain of inverse is x ≥ 0.

Q7: What line are f and f⁻¹ symmetric about?

A) x-axis
B) y-axis
C) y = x
D) y = 0
Answer: Always y = x.

Q8: If f(2) = 8 for f(x) = 2x², what is f⁻¹(8)?

A) 2
B) -2
C) Both 2 and -2
D) Undefined (not a function)
Answer: Without domain restriction, inverse isn’t a function.

Q9: After restricting f(x) = x² to x ≥ 0, is f⁻¹ a function?

A) Yes
B) No
C) Only for x > 0
D) Never
Answer: Yes — now one-to-one.

Q10: What is the range of f⁻¹ if f(x) = x², x ≥ 0?

A) y ≥ 0
B) y ≤ 0
C) All real y
D) y > 0
Answer: Range of f⁻¹ = domain of f = [0, ∞).

Q11: Which test determines if an inverse is a function?

A) Vertical line test on inverse
B) Horizontal line test on inverse
C) Vertical line test on original
D) None
Answer: Apply vertical line test to the inverse graph.

Q12: Can an unrestricted quadratic ever have an inverse that is a function?

A) Yes
B) No
C) Only if a = 1
D) Only if vertex is at origin
Answer: No — always many-to-one over full domain.
