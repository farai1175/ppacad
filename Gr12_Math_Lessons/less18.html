Finding Lengths

Important Rule

Length can NEVER be negative! Always use absolute value or arrange subtraction so the result is positive.

Length Formulas

Horizontal Length = |x₂ - x₁|
Vertical Length = |y₂ - y₁|

📏 Horizontal Length

  • Use x-coordinates only
  • Calculate: Bigger x-value − Smaller x-value
  • Example: Distance between x = 2 and x = 7 is |7 - 2| = 5 units

📏 Vertical Length

  • Use y-coordinates only
  • Calculate: Top value − Bottom value
  • Example: Distance between y = -3 and y = 5 is |5 - (-3)| = 8 units

Example: Find the length AB where A(-2, 3) and B(5, 3)

1 Since the y-coordinates are the same (both = 3), this is a horizontal length
2 Length = |x₂ - x₁| = |5 - (-2)| = |5 + 2| = 7 units

Example: Find the vertical distance between points on y = x² at x = 2 and the x-axis

1 Find y-coordinate when x = 2: y = (2)² = 4
2 Point on curve: (2, 4). Point on x-axis: (2, 0)
3 Vertical distance = |4 - 0| = 4 units
📍

Finding Coordinates of Points

A coordinate is written as an ordered pair: (x-value, y-value)

📍 How to Find Coordinates

  • Given x: Substitute into the function to find y
  • Given y: Substitute into the function and solve for x
  • X-intercepts: Set y = 0 and solve for x
  • Y-intercept: Set x = 0 and find y
  • Turning point: Use x = -b/(2a) for parabola, then find y

Example: For f(x) = x² - 4x + 3, find the coordinates of the turning point

1 a = 1, b = -4, c = 3
2 x = -b/(2a) = -(-4)/(2×1) = 4/2 = 2
3 y = f(2) = (2)² - 4(2) + 3 = 4 - 8 + 3 = -1
Turning Point: (2, -1)
✖️

Finding Points of Intersection

Method: Solve Simultaneously

Set f(x) = g(x)

Where the graphs meet, they have the same x AND the same y!

✖️ Steps to Find Intersection

  • Step 1: Set the two equations equal to each other
  • Step 2: Solve for x
  • Step 3: Substitute x back into either equation to find y
  • Step 4: Write answer as coordinate(s): (x, y)

Example: Find where y = x² and y = 2x + 3 intersect

1 Set equal: x² = 2x + 3
2 Rearrange: x² - 2x - 3 = 0
3 Factor: (x - 3)(x + 1) = 0
4 Solve: x = 3 or x = -1
5 When x = 3: y = 2(3) + 3 = 9 → Point: (3, 9)
6 When x = -1: y = 2(-1) + 3 = 1 → Point: (-1, 1)
Points of Intersection: (3, 9) and (-1, 1)
🔄

Transformations of Functions

Transformations change the position, size, or orientation of a graph. Understanding these rules is essential for finding equations after transformations.

Transformation Rule Effect
Vertical Shift Up f(x) + k Shift graph k units UP
Vertical Shift Down f(x) - k Shift graph k units DOWN
Horizontal Shift Left f(x + k) Shift graph k units LEFT
Horizontal Shift Right f(x - k) Shift graph k units RIGHT
Reflection in x-axis -f(x) Flip over x-axis (y-values become negative)
Reflection in y-axis f(-x) Flip over y-axis (x-values become negative)
Vertical Stretch a·f(x), |a| > 1 Stretch vertically (steeper)
Vertical Compression a·f(x), |a| < 1 Compress vertically (flatter)

Remember the Direction Rule!

Horizontal shifts work "opposite":

f(x + k) shifts LEFT (not right) and f(x - k) shifts RIGHT (not left)

Example: If f(x) = x², write the equation for g(x) which is f shifted 3 units right and 2 units up

1 Start with f(x) = x²
2 Shift 3 units RIGHT: replace x with (x - 3) → (x - 3)²
3 Shift 2 units UP: add 2 → (x - 3)² + 2
g(x) = (x - 3)² + 2
