Geometric Sequences and Series: Sum to Infinity

Grade: 12
Week: 3
Lesson: 2
Time: 60 minutes
Topic: Series (Convergence & Sum to Infinity)

Use the convergence condition and the sum-to-infinity formula to solve practical problems and exam-style questions.

🎯 Lesson Objectives

▼

By the end of this lesson, you will be able to:

  • Apply the formula to sum a converging geometric series
  • Apply the formula to practical examples involving the sum to infinity

🧠 Pre-Knowledge Required

▼

  • Geometric sequences and the idea of a constant common ratio, r
  • How to find r using consecutive terms (divide a term by the previous term)
  • When a geometric series converges: |r| < 1
  • Substitution and solving simple inequalities (for interval answers)
  • Using a scientific calculator for fractions and decimals

∞ Sum to Infinity

▼

Key reminder

The sum to infinity formula can only be used for a geometric series, and only when the restriction on r is satisfied.

CONVERGENCE CONDITION

A geometric series converges if and only if:
-1 < r < 1
(equivalently: |r| < 1)
Sum to Infinity

S∞ = a / (1 − r)

Use only if -1 < r < 1

⚠️ Always check r first

If |r| ≥ 1, the series does not have a finite sum to infinity, so you must not use the formula.

📊 Worked Examples

▼

Example 1: Practical context

A tree is 3 m high and its growth each year is 1/10 of its growth the previous year. What is the greatest height it can reach, assuming it lives forever?
  • Model as a geometric series:
    Height gained forms: 3 + 0.3 + 0.03 + 0.003 + ...
    (First term a = 3, common ratio r = 0.1)
  • Check convergence:
    -1 < 0.1 < 1 ✓ so the series converges.
  • Sum to infinity:
    S∞ = a/(1-r) = 3/(1-0.1) = 3/0.9 = 10/3 ≈ 3.333...
  • Interpretation:
    The tree’s total additional growth approaches 3.333... m.
    So the greatest height approaches: 3 + 3.333... = 6.333... m.

💡 Note about wording

If 3 m is the initial height and the yearly growth starts at 3 m (then 0.3 m, etc.), the maximum total height is 6.333... m.

Some worksheets treat “3 m” as the first growth amount rather than initial height; in that case, the sum to infinity is 10/3 m.

Example 2: Convergence interval

For which values of x will the geometric series (1 − x) + (1 − x)² + (1 − x)³ + ... converge?
  • Identify r:
    Each term is multiplied by (1 − x), so r = (1 − x).
  • Apply convergence condition:
    |r| < 1 → |1 − x| < 1
  • Solve the inequality:
    -1 < 1 − x < 1
    Subtract 1: -2 < -x < 0
    Multiply by -1 (flip signs): 2 > x > 0

Answer: The series converges for 0 < x < 2.

Question 1: When can you use S∞ = a/(1 − r)?

A) For any sequence
B) For geometric series with |r| < 1
C) For arithmetic series with d ≠ 0
D) Only when r > 1
Explanation: The sum to infinity exists only for a convergent geometric series, which requires |r| < 1.

Question 2: A series has r = -1. Does it converge?

A) Yes, always
B) No, it diverges
C) Yes, if a is small
D) It converges only if a = 0
Explanation: |r| = 1, so it fails the condition |r| < 1.

Question 3: If a = 3 and r = 0.1, what is S∞?

A) 3.1
B) 10/3
C) 30
D) The series diverges
Explanation: S∞ = 3/(1-0.1) = 3/0.9 = 10/3.

Question 4: For (1 − x) + (1 − x)² + (1 − x)³ + ..., what is r?

A) r = x
B) r = (1 − x)
C) r = (1 + x)
D) r = (1 − x)²
Explanation: Each term is multiplied by (1 − x) to get the next one.

Question 5: Solve |1 − x| < 1

A) 0 < x < 2
B) -2 < x < 0
C) x > 2
D) x < 0
Explanation: -1 < 1 − x < 1 → subtract 1 → -2 < -x < 0 → multiply by -1 → 0 < x < 2.

Question 6: If r = 1.2, what should you conclude?

A) The series diverges (no finite S∞)
B) Use S∞ = a/(1-r) anyway
C) It converges only if a < 1
D) It converges to 0
Explanation: |1.2| ≥ 1, so the geometric series does not converge.

Question 7: If S∞ = 25 and a = 5, find r.

A) r = 0.9
B) r = 0.8
C) r = 1.2
D) r = -0.8
Explanation: 25 = 5/(1-r) → 1-r = 0.2 → r = 0.8.

Question 8: Which step is best to do first in sum-to-infinity questions?

A) Convert to decimals
B) Substitute into S∞ immediately
C) Identify r and check |r| < 1
D) Find Sₙ first for n = 10
Explanation: The formula is only valid if the series converges, so check |r| < 1 before anything else.
