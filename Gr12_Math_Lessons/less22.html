Inverses of Exponential Functions

Grade: 12
Week: Term 1 Week 5
Time: 60 minutes
Topic: Inverses – Exponential Functions (Lessons 4 & 5)

Explore the inverse of exponential functions — the logarithmic function — and learn to graph both with key features.

✓ Lesson Objectives

▼

By the end of this lesson, you will be able to:

  • Recall properties of exponential functions: domain, range, asymptotes, intercepts
  • Identify that exponential functions are one-to-one
  • Find the inverse of an exponential function (which is a logarithmic function)
  • Sketch exponential and inverse (logarithmic) graphs on the same axes
  • Recognize symmetry about the line y = x
  • Determine equations from given points on exponential graphs

📚 Core Concepts

▼

1. Exponential Function: y = aˣ (a > 0, a ≠ 1)

Characteristics:

  • Domain: x ∈ (–∞, ∞)
  • Range: y ∈ (0, ∞)
  • y-intercept: (0, 1) because a⁰ = 1
  • x-intercept: None (graph never touches x-axis)
  • Horizontal asymptote: y = 0 (x-axis)
  • One-to-one: Passes both vertical and horizontal line tests

2. Two Types of Exponential Graphs

  • If a > 1: Increasing function (e.g., y = 2ˣ)
  • If 0 < a < 1: Decreasing function (e.g., y = (½)ˣ)

Note: y = (½)ˣ = 2⁻ˣ → reflection of y = 2ˣ over y-axis.

3. Inverse of y = aˣ

Since y = aˣ is one-to-one, its inverse **is a function**.

y = aˣ ⇔ x = aʸ ⇔ y = logₐ(x)

The inverse of an exponential function is a logarithmic function.

Graph properties of inverse:

  • Domain: x > 0
  • Range: y ∈ ℝ
  • x-intercept: (1, 0)
  • Vertical asymptote: x = 0 (y-axis)
  • Symmetric to original over line y = x

💡 Key Insight

The point (x, y) on f(x) becomes (y, x) on f⁻¹(x).
Example: (0,1) on y=2ˣ → (1,0) on y=log₂(x).

💡 Worked Examples

▼

Example 1: Find a if (4, 81) lies on y = aˣ

  • Plug in: 81 = a⁴
  • Take 4th root: a = ⁴√81 = 3
  • Equation: y = 3ˣ

Example 2: Inverse of y = 2ˣ

Swap x and y: x = 2ʸ → y = log₂(x)

Graph both:

  • f(x) = 2ˣ: passes (–1, ½), (0,1), (1,2), (2,4)
  • f⁻¹(x) = log₂(x): passes (½, –1), (1,0), (2,1), (4,2)

Both symmetric over y = x.

Example 3: Reflections

  • y = –2ˣ → reflection over x-axis
  • y = 2⁻ˣ → reflection over y-axis
  • y = –2⁻ˣ → reflection over origin

✏️ Practice

1. Find equation if (3, 125) ∈ y = aˣ → a = 5, y = 5ˣ

2. Sketch y = (⅓)ˣ and its inverse → y = log₍₁/₃₎(x)

❓ Comprehensive Quiz (12 Questions)

▼

Test your understanding of exponential functions and their inverses.

Q1: What is the y-intercept of y = 5ˣ?

A) (0, 1)
B) (1, 0)
C) (0, 5)
D) None
Answer: a⁰ = 1 for any a ≠ 0.

Q2: What is the inverse of y = 3ˣ?

A) y = x³
B) y = log₃(x)
C) y = 3⁻ˣ
D) y = ln(x)
Answer: Inverse of exponential is logarithmic.

Q3: What is the asymptote of y = 4ˣ?

A) y = 0
B) x = 0
C) y = 1
D) None
Answer: Horizontal asymptote at y = 0.

Q4: Is y = 0.7ˣ increasing or decreasing?

A) Increasing
B) Decreasing
C) Constant
D) Undefined
Answer: 0 < a < 1 → decreasing.

Q5: If (2, 9) is on y = aˣ, what is a?

A) 2
B) 3
C) 9
D) 4.5
Answer: a² = 9 → a = 3.

Q6: What is the x-intercept of y = log₂(x)?

A) (1, 0)
B) (0, 1)
C) (2, 1)
D) None
Answer: logₐ(1) = 0 → (1,0).

Q7: What line are exponential and log graphs symmetric about?

A) x-axis
B) y-axis
C) y = x
D) y = 0
Answer: All functions and their inverses are symmetric over y = x.

Q8: What is the domain of y = log₅(x)?

A) All real x
B) x ≥ 0
C) x > 0
D) x ≠ 0
Answer: Log defined only for positive x.

Q9: Is y = aˣ one-to-one?

A) Yes
B) No
C) Only if a > 1
D) Only if 0 < a < 1
Answer: All valid exponential functions are one-to-one.

Q10: What is the range of y = 2ˣ?

A) All real y
B) y ≥ 0
C) y > 0
D) y ≠ 0
Answer: Exponential never reaches 0 or negative.

Q11: What is the asymptote of y = log₄(x)?

A) y = 0
B) x = 0
C) y = 1
D) None
Answer: Vertical asymptote at x = 0.

Q12: Which point is on both y = aˣ and y = logₐ(x)?

A) (0,1)
B) (1,0)
C) (1,1)
D) No common point
Answer: a¹ = a and logₐ(a) = 1 → only (1,1) if a=1, but a≠1. Actually, no point lies on both unless a = e and x=1? Correction: **No point is common** — but standard answer: (1,1) only if a=1 (invalid). So best answer: None. However, per CAPS: often (1,1) is accepted. For safety, we'll say **no common point**, but here (1,1) is on y=2ˣ? No: 2¹=2 ≠1. So **D) None** is correct.
