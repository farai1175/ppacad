Arithmetic Sequence and Series

Lesson 2: Deriving and Applying the General Term Formula

🎯

Learning Objectives

By the end of this lesson, you will be able to:

  • Derive the general term formula Tn = a + (n − 1)d for an Arithmetic Sequence
  • Find the general term formula when given an arithmetic sequence
  • Calculate the value of any specific term in an arithmetic sequence
  • Solve problems involving unknown terms or positions in arithmetic sequences
📝

Overview

An arithmetic sequence is a sequence of numbers where the difference between consecutive terms is constant. This constant is called the common difference (d). In this lesson, we'll discover how to derive a powerful formula that allows us to find any term in an arithmetic sequence without listing all the preceding terms.

Tn = a + (n − 1)d
Tn = nth term
a = first term
n = term position
d = common difference
🔬

Deriving the General Term Formula

Let's derive the formula using the sequence: 7; 10; 13; 16; 19; ...

Here, the first term is 7 and the common difference is 3.

1
T1 = 7
First term (starting point)
2
T2 = 7 + 3 = 7 + 1(3)
Add d once
3
T3 = 7 + 3 + 3 = 7 + 2(3)
Add d twice
4
T4 = 7 + 3 + 3 + 3 = 7 + 3(3)
Add d three times
5
T5 = 7 + 3 + 3 + 3 + 3 = 7 + 4(3)
Add d four times
n
Tn = 7 + (n − 1)(3)
Pattern: add d (n−1) times

Replacing 7 with a (first term) and 3 with d (common difference):

T1 = a
T2 = a + d
T3 = a + 2d
T4 = a + 3d
Tn = a + (n − 1)d
✏️

Worked Examples

Example 1 Finding the General Term Formula

Question: Find a formula for the general term of the sequence: 3; 5; 7; 9; ...

Step 1: Identify the first term (a)

a = T1 = 3

Step 2: Find the common difference (d)

d = T2 − T1 = 5 − 3 = 2

Step 3: Substitute into Tn = a + (n − 1)d

Tn = 3 + (n − 1)(2)

Tn = 3 + 2n − 2

Tn = 2n + 1

Example 2 Finding a Specific Term

Question: Consider the sequence: 4; 1; −2; −5; ... Determine the 10th term.

Step 1: Identify a and d

a = 4

d = T2 − T1 = 1 − 4 = −3

Step 2: Use the formula with n = 10

Tn = a + (n − 1)d

T10 = 4 + (10 − 1)(−3)

T10 = 4 + (9)(−3)

T10 = 4 − 27

T10 = −23

Example 3 Finding the Sequence from Given Terms

Question: Find the arithmetic sequence with a 4th term of 3 and 8th term of −13.

Step 1: Set up equations using Tn = a + (n − 1)d

T4 = a + 3d = 3 ... (1)

T8 = a + 7d = −13 ... (2)

Step 2: Solve simultaneously (subtract equation 1 from 2)

(a + 7d) − (a + 3d) = −13 − 3

4d = −16

d = −4

Step 3: Substitute d = −4 into equation (1)

a + 3(−4) = 3

a − 12 = 3

a = 15

Step 4: Write the sequence

15; 11; 7; 3; −1; ...
