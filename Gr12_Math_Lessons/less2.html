📚 Key Theory & Derivation

▼

Derivation of General Term Formula

Consider the linear pattern: 7; 10; 13; 16; 19; ...
Common difference: d = T₂ - T₁ = 10 - 7 = 3

Step-by-Step Derivation:
  • T₁ = 7 = 7
  • T₂ = 10 = 7 + 3
  • T₃ = 13 = 7 + 3 + 3 = 7 + 2×3
  • T₄ = 16 = 7 + 3 + 3 + 3 = 7 + 3×3
  • T₅ = 19 = 7 + 3 + 3 + 3 + 3 = 7 + 4×3
  • Pattern: Tₙ = 7 + (n-1)×3

General Formula

Replacing 7 with 'a' (first term) and 3 with 'd' (common difference):

T₁ = a
T₂ = a + d
T₃ = a + 2d
T₄ = a + 3d
...
Tₙ = a + (n-1)d where: a = first term, d = common difference, n = position of term

Finding General Term from Sequence

Example 1: Sequence 3; 5; 7; 9; ...
  • First term: a = 3
  • Common difference: d = 5 - 3 = 2
  • General term: Tₙ = 3 + (n-1)2
  • Simplify: Tₙ = 3 + 2n - 2 = 2n + 1
  • Answer: Tₙ = 2n + 1
Example 2: Sequence -5; -9; -13; -17; ...
  • First term: a = -5
  • Common difference: d = -9 - (-5) = -4
  • General term: Tₙ = -5 + (n-1)(-4)
  • Simplify: Tₙ = -5 - 4n + 4 = -4n - 1
  • Answer: Tₙ = -4n - 1

Finding Specific Terms

Example: Sequence 4; 1; -2; -5; ... Find T₁₀
  • First term: a = 4
  • Common difference: d = 1 - 4 = -3
  • General term: Tₙ = 4 + (n-1)(-3) = 4 - 3n + 3 = 7 - 3n
  • T₁₀ = 7 - 3(10) = 7 - 30 = -23
  • Answer: T₁₀ = -23

Advanced Application: Using Simultaneous Equations

Example: Find arithmetic sequence with T₄ = 3 and T₈ = -13
  • From T₄: a + 3d = 3 ...(1)
  • From T₈: a + 7d = -13 ...(2)
  • Subtract (1) from (2): (a+7d) - (a+3d) = -13 - 3
  • 4d = -16 → d = -4
  • Substitute into (1): a + 3(-4) = 3 → a - 12 = 3 → a = 15
  • Sequence: 15; 11; 7; 3; -1; ...

✏️ Class Work & Practice

▼

📝 Practice Problems

1. Find the 26th term of the sequence: 2; 5; 8; 11; ... (Answer: 77)

2. Which term in the sequence 10; 6; 2; -2; ... will have a value of -58? (Answer: n = 18)

3. Find T₅₀ for the sequence: 4; 1; -2; -5; ... (Answer: -143)

4. Find the arithmetic sequence with T₄ = 3 and T₈ = -13 (Answer: 15; 11; 7; 3; ...)

5. If Tₙ = 5n - 2, find T₁₅ (Answer: 73)

Solution to Problem 2:

Sequence: 10; 6; 2; -2; ... Find n when Tₙ = -58

  • a = 10, d = 6 - 10 = -4
  • Tₙ = 10 + (n-1)(-4) = 10 - 4n + 4 = 14 - 4n
  • Set Tₙ = -58: 14 - 4n = -58
  • -4n = -72
  • n = 18
  • Answer: The 18th term is -58

Question 1: What is the common difference in the sequence: 7; 10; 13; 16; 19?

A) 2
B) 3
C) 4
D) 7
Explanation: The difference between consecutive terms: 10-7=3, 13-10=3, 16-13=3, 19-16=3. Common difference = 3.

Question 2: What is the general term formula for the sequence: 3; 5; 7; 9; ...?

A) Tₙ = 2n + 2
B) Tₙ = 3n + 1
C) Tₙ = 2n + 1
D) Tₙ = n + 2
Explanation: a = 3, d = 2. Tₙ = 3 + (n-1)2 = 3 + 2n - 2 = 2n + 1.

Question 3: Find T₁₀ for the sequence: 4; 1; -2; -5; ...

A) -20
B) -25
C) -23
D) -26
Explanation: a = 4, d = -3. T₁₀ = 4 + (10-1)(-3) = 4 + 9(-3) = 4 - 27 = -23.

Question 4: What is the general term for: -5; -9; -13; -17; ...?

A) Tₙ = -4n - 2
B) Tₙ = -4n - 1
C) Tₙ = -5n + 4
D) Tₙ = -9n + 4
Explanation: a = -5, d = -4. Tₙ = -5 + (n-1)(-4) = -5 -4n + 4 = -4n - 1.

Question 5: Which term in the sequence 10; 6; 2; -2; ... equals -58?

A) 15th
B) 17th
C) 18th
D) 20th
Explanation: a = 10, d = -4. Tₙ = 10 + (n-1)(-4) = 14 - 4n. Set 14 - 4n = -58 → -4n = -72 → n = 18.

Question 6: Find the 26th term of: 2; 5; 8; 11; ...

A) 74
B) 77
C) 80
D) 83
Explanation: a = 2, d = 3. T₂₆ = 2 + (26-1)3 = 2 + 25×3 = 2 + 75 = 77.

Question 7: If T₄ = 3 and T₈ = -13, what is the first term (a)?

A) 15
B) 12
C) 10
D) 8
Explanation: a + 3d = 3, a + 7d = -13. Subtract: 4d = -16 → d = -4. Substitute: a + 3(-4) = 3 → a - 12 = 3 → a = 15.

Question 8: What is T₅₀ for: 4; 1; -2; -5; ...?

A) -140
B) -143
C) -146
D) -149
Explanation: a = 4, d = -3. T₅₀ = 4 + (50-1)(-3) = 4 + 49(-3) = 4 - 147 = -143.

Question 9: In the formula Tₙ = a + (n-1)d, what does 'n' represent?

A) Common difference
B) First term
C) Position of the term
D) Value of the term
Explanation: In Tₙ = a + (n-1)d, 'n' represents the position number of the term (nth term).

Question 10: Find the arithmetic sequence if T₃ = 8 and T₇ = 20

A) 2; 5; 8; 11; ...
B) 3; 6; 9; 12; ...
C) 4; 6; 8; 10; ...
D) 5; 7; 9; 11; ...
Explanation: a + 2d = 8, a + 6d = 20. Subtract: 4d = 12 → d = 3. Then a + 2(3) = 8 → a = 2. Sequence: 2; 5; 8; 11; ...

Question 11: If a = -2 and d = 5, what is T₆?

A) 20
B) 21
C) 22
D) 23
Explanation: T₆ = -2 + (6-1)5 = -2 + 5×5 = -2 + 25 = 23.

Question 12: Which sequence has a common difference of -4?

A) 2, 6, 10, 14, ...
B) 10, 6, 2, -2, ...
C) -3, 1, 5, 9, ...
D) 5, 10, 15, 20, ...
Explanation: 10 to 6: -4, 6 to 2: -4, 2 to -2: -4. This sequence has a constant difference of -4.
