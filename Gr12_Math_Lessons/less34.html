Double Angle Identities (Lesson 3)

Grade: 12

Proving trigonometric identities using double angle identities and strategic approaches

🎯 Lesson Objectives

▼

This lesson focuses on proving trigonometric identities using double angle identities. By the end of this lesson, you will be able to:

  • Revise all trigonometric identities: basic, squared, compound, and double angle
  • Apply identities to prove other identities involving double angles
  • Develop strategic thinking for approaching identity proofs
  • Choose the correct form of cos 2x based on the expression
  • Recognize and factor perfect square trigonometric expressions

📋 Essential Identities Reference

▼
Quotient Identity
tan x = sin x / cos x
Pythagorean Identity
sin²x + cos²x = 1
Derived Form 1
sin²x = 1 - cos²x
Derived Form 2
cos²x = 1 - sin²x
Sine Double Angle
sin 2x = 2 sin x cos x
Cosine Double Angle (Form 1)
cos 2x = cos²x - sin²x
Cosine Double Angle (Form 2)
cos 2x = 2cos²x - 1
Only contains cos x
Cosine Double Angle (Form 3)
cos 2x = 1 - 2sin²x
Only contains sin x
Sine Addition
sin(A + B) = sin A cos B + cos A sin B
Sine Subtraction
sin(A - B) = sin A cos B - cos A sin B
Cosine Addition
cos(A + B) = cos A cos B - sin A sin B
Cosine Subtraction
cos(A - B) = cos A cos B + sin A sin B
Choosing the Right Form of cos 2x:

• Form 1 (cos²x - sin²x): When both sin x and cos x appear in the expression
• Form 2 (2cos²x - 1): When you need to work with cos x only
• Form 3 (1 - 2sin²x): When you need to work with sin x only

💡 Proof Strategies

▼
🎯 Key Strategies for Proving Identities
  1. Start with the more complicated side - usually the LHS (Left Hand Side)
  2. Match the angles - if RHS has angle x, reduce double angles on LHS using identities
  3. Choose the right form of cos 2x - pick the one that helps you simplify
  4. Look for factoring opportunities - difference of squares, perfect squares, etc.
  5. Convert everything to sin and cos when stuck
  6. Always conclude with "∴ LHS = RHS" - this is required for full marks!
⚠️
Important: In an exam or test, you MUST write "∴ LHS = RHS" or "Therefore LHS = RHS" at the end of your proof. Missing this loses you a mark!
Special Factoring Patterns:

• Perfect Square: sin²x ± 2 sin x cos x + cos²x = (sin x ± cos x)²
• Difference of Squares: sin²x - cos²x = -(cos²x - sin²x) = -cos 2x
• Replacing 1: 1 = sin²x + cos²x (very useful!)

✏️ Worked Examples

▼
Example 1 Basic Double Angle Proof

Prove that:

(sin 2x) / (1 + cos 2x) = tan x

💡
Analysis: The RHS has angle x, so we need to reduce the double angles on the LHS. We need cos x in the denominator to form tan x = sin x / cos x.
1
Start with LHS and identify which identities to use

LHS = sin 2x / (1 + cos 2x)

Use: sin 2x = 2 sin x cos x and cos 2x = 2cos²x - 1 (choosing this form to get cos x only)

2
Substitute the identities

= (2 sin x cos x) / (1 + (2cos²x - 1))

3
Simplify the denominator

= (2 sin x cos x) / (1 + 2cos²x - 1)

= (2 sin x cos x) / (2cos²x)

4
Cancel common factors

= (2 sin x cos x) / (2 cos x · cos x)

= sin x / cos x

5
Recognize the quotient identity

= tan x

= RHS

∴ LHS = RHS ✓ (Q.E.D.)
Example 2 Factoring with Double Angles

Prove that:

(1 - sin 2x) / (sin x - cos x) = sin x - cos x

💡
Key insight: The numerator contains 1, which can be replaced with sin²x + cos²x. This often leads to a factorable expression!
1
Start with LHS and expand sin 2x

LHS = (1 - sin 2x) / (sin x - cos x)

= (1 - 2 sin x cos x) / (sin x - cos x)

2
Replace 1 with sin²x + cos²x

= (sin²x + cos²x - 2 sin x cos x) / (sin x - cos x)

3
Recognize the numerator as a perfect square: (a - b)² = a² - 2ab + b²

= (sin x - cos x)² / (sin x - cos x)

4
Cancel one bracket

= sin x - cos x

= RHS

∴ LHS = RHS ✓ (Q.E.D.)
Example 3 Multiple Angle Reduction

Prove that:

8 sin A · cos A · cos 2A · cos 4A = sin 8A

💡
Strategy: We need to go from angle A to angle 8A. Using the double angle identity repeatedly: A → 2A → 4A → 8A
1
Start with LHS and group strategically

LHS = 8 sin A · cos A · cos 2A · cos 4A

2
Use: 2 sin A cos A = sin 2A, so 8 sin A cos A = 4 sin 2A

= 4 sin 2A · cos 2A · cos 4A

3
Use: 2 sin 2A cos 2A = sin 4A, so 4 sin 2A cos 2A = 2 sin 4A

= 2 sin 4A · cos 4A

4
Use: 2 sin 4A cos 4A = sin 8A

= sin 8A

= RHS

∴ LHS = RHS ✓ (Q.E.D.)

Question 1: Which identity should you use to simplify sin 2x?

A) sin²x + cos²x = 1
B) 2 sin x cos x
C) cos²x - sin²x
D) sin x / cos x
Explanation: sin 2x = 2 sin x cos x is the double angle identity for sine.

Question 2: Which form of cos 2x contains ONLY cos x (no sin x)?

A) cos²x - sin²x
B) 1 - 2sin²x
C) 2cos²x - 1
D) sin²x + cos²x
Explanation: cos 2x = 2cos²x - 1 contains only cos x, making it useful when you need cos x in your answer.

Question 3: What is the first step to prove: sin 2x / (1 + cos 2x) = tan x?

A) Start with RHS
B) Cross multiply
C) Start with LHS and apply double angle identities
D) Square both sides
Explanation: Always start with the more complicated side (LHS) and apply identities to simplify.

Question 4: Simplify: (1 - cos 2x) / 2

A) sin²x
B) cos²x
C) tan²x
D) sin x cos x
Explanation: Using cos 2x = 1 - 2sin²x, we get 1 - cos 2x = 2sin²x, so (1 - cos 2x)/2 = sin²x

Question 5: What can replace the number 1 in a trigonometric expression?

A) sin x + cos x
B) sin²x + cos²x
C) tan x × cot x
D) Both B and C
Explanation: Both sin²x + cos²x = 1 and tan x × cot x = 1 can be used to replace 1.

Question 6: Simplify: 4 sin x cos x cos 2x

A) sin 4x
B) 2 sin 4x
C) cos 4x
D) sin 2x cos 2x
Explanation: 4 sin x cos x = 2(2 sin x cos x) = 2 sin 2x. Then 2 sin 2x cos 2x = sin 4x.

Question 7: What should you write at the end of every identity proof?

A) Q.E.D.
B) ∴ LHS = RHS
C) Proved
D) Any of these
Explanation: You must conclude with a statement showing LHS = RHS. Any of these options is acceptable.

Question 8: If sin x - cos x appears in a denominator, and sin²x + cos²x - 2 sin x cos x is in the numerator, what can you factor?

A) Cannot factor
B) (sin x - cos x)²
C) (sin x + cos x)²
D) sin 2x
Explanation: sin²x - 2 sin x cos x + cos²x = (sin x - cos x)², which is a perfect square.

Question 9: Which form of cos 2x is best when you want to eliminate cos x and keep sin x?

A) cos²x - sin²x
B) 2cos²x - 1
C) 1 - 2sin²x
D) None of these
Explanation: cos 2x = 1 - 2sin²x contains only sin x, useful when you want to work with sin x only.

Question 10: Simplify: sin²x - cos²x

A) cos 2x
B) -cos 2x
C) sin 2x
D) -sin 2x
Explanation: cos 2x = cos²x - sin²x, so sin²x - cos²x = -(cos²x - sin²x) = -cos 2x
