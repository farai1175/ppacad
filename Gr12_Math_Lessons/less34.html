Essential Identities Reference

Quotient Identity
tan x = sin x / cos x
Pythagorean Identity
sin²x + cos²x = 1
Derived Form 1
sin²x = 1 - cos²x
Derived Form 2
cos²x = 1 - sin²x
Sine Double Angle
sin 2x = 2 sin x cos x
Cosine Double Angle (Form 1)
cos 2x = cos²x - sin²x
Cosine Double Angle (Form 2)
cos 2x = 2cos²x - 1
Only contains cos x
Cosine Double Angle (Form 3)
cos 2x = 1 - 2sin²x
Only contains sin x
Sine Addition
sin(A + B) = sin A cos B + cos A sin B
Sine Subtraction
sin(A - B) = sin A cos B - cos A sin B
Cosine Addition
cos(A + B) = cos A cos B - sin A sin B
Cosine Subtraction
cos(A - B) = cos A cos B + sin A sin B
💡

Proof Strategies

🎯 Key Strategies for Proving Identities
  1. Start with the more complicated side - usually the LHS (Left Hand Side)
  2. Match the angles - if RHS has angle x, reduce double angles on LHS using identities
  3. Choose the right form of cos 2x - pick the one that helps you simplify
  4. Look for factoring opportunities - difference of squares, perfect squares, etc.
  5. Convert everything to sin and cos when stuck
  6. Always conclude with "∴ LHS = RHS" - this is required for full marks!
⚠️
Important: In an exam or test, you MUST write "∴ LHS = RHS" or "Therefore LHS = RHS" at the end of your proof. Missing this loses you a mark!
✏️

Worked Examples

Example 1 Basic Double Angle Proof

Prove that:

(sin 2x) / (1 + cos 2x) = tan x

💡
Analysis: The RHS has angle x, so we need to reduce the double angles on the LHS. We need cos x in the denominator to form tan x = sin x / cos x.
1
Start with LHS and identify which identities to use

LHS = sin 2x / (1 + cos 2x)

Use: sin 2x = 2 sin x cos x and cos 2x = 2cos²x - 1 (choosing this form to get cos x only)

2
Substitute the identities

= (2 sin x cos x) / (1 + (2cos²x - 1))

3
Simplify the denominator

= (2 sin x cos x) / (1 + 2cos²x - 1)

= (2 sin x cos x) / (2cos²x)

4
Cancel common factors

= (2 sin x cos x) / (2 cos x · cos x)

= sin x / cos x

5
Recognize the quotient identity

= tan x

= RHS

∴ LHS = RHS ✓ (Q.E.D.)
Example 2 Factoring with Double Angles

Prove that:

(1 - sin 2x) / (sin x - cos x) = sin x - cos x

💡
Key insight: The numerator contains 1, which can be replaced with sin²x + cos²x. This often leads to a factorable expression!
1
Start with LHS and expand sin 2x

LHS = (1 - sin 2x) / (sin x - cos x)

= (1 - 2 sin x cos x) / (sin x - cos x)

2
Replace 1 with sin²x + cos²x

= (sin²x + cos²x - 2 sin x cos x) / (sin x - cos x)

3
Recognize the numerator as a perfect square: (a - b)² = a² - 2ab + b²

= (sin x - cos x)² / (sin x - cos x)

4
Cancel one bracket

= sin x - cos x

= RHS

∴ LHS = RHS ✓ (Q.E.D.)
Example 3 Multiple Angle Reduction

Prove that:

8 sin A · cos A · cos 2A · cos 4A = sin 8A

💡
Strategy: We need to go from angle A to angle 8A. Using the double angle identity repeatedly: A → 2A → 4A → 8A
1
Start with LHS and group strategically

LHS = 8 sin A · cos A · cos 2A · cos 4A

2
Use: 2 sin A cos A = sin 2A, so 8 sin A cos A = 4 sin 2A

= 4 sin 2A · cos 2A · cos 4A

3
Use: 2 sin 2A cos 2A = sin 4A, so 4 sin 2A cos 2A = 2 sin 4A

= 2 sin 4A · cos 4A

4
Use: 2 sin 4A cos 4A = sin 8A

= sin 8A

= RHS

∴ LHS = RHS ✓ (Q.E.D.)
