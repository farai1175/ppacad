Topic: Inverses

Lesson 3 & 4

Finding Equations of Logarithmic Functions & Domain

Determining equations from given points and understanding domain restrictions

📚 Learning Objectives

  • Demonstrate the ability to work with various types of functions and relations, including inverses
  • Investigate how to write the inverse of an exponential function with y as the subject – logarithmic function
  • Demonstrate the ability to find the equation of a logarithmic function given a point
  • Develop an understanding of the definition of a logarithm to restrict the domain of the function
  • Identify characteristics of graphs: domain, range, intercepts with axes, asymptotes
  • Make deductions from all types of functions studied
  • Assess understanding of concepts covered during lessons on inverses

📋 Overview

In this lesson, we will learn how to find the equation of a logarithmic function when given a point that lies on the graph. We will also explore how to determine the domain of logarithmic functions by understanding that the argument of a logarithm must always be positive.

📐 Main Concepts & Principles

1. Finding the Equation of a Logarithmic Function Given a Point

When given a point that lies on a logarithmic function, we can find the base of the logarithm by substituting the coordinates into the equation and solving.

Worked Example

Given: The function f : x → logax passes through the point (9, 2)

Find:

a) Determine the value of a and hence the equation of f

b) Write down the equation of the inverse of f in the form f⁻¹(x) = ...

c) Draw a neat sketch graph of f and f⁻¹ on the same system of axes

d) Write down the domain and range of each function

e) Determine the values of x for which the functions are increasing or decreasing

Solution Part (a): Finding the Base

1 Since (9, 2) lies on y = logax, substitute:

2 = loga9

2 Convert to exponential form:

a² = 9

3 Take the square root of both sides:

a = ±√9 = ±3

4 Since the base of a logarithm must be positive and not equal to 1:

a = 3

Therefore: f(x) = log₃x

Solution Part (b): Finding the Inverse

To find the inverse, swap x and y:

Original: y = log₃x

Swap: x = log₃y

Convert to exponential form: y = 3ˣ

f⁻¹(x) = 3ˣ

📝 Remember: The inverse of a logarithmic function is an exponential function, and vice versa. They are reflections of each other in the line y = x.

Solution Part (c): Sketching the Graphs

Key features to plot:

Function f(x) = log₃x f⁻¹(x) = 3ˣ
Key Point (1, 0), (3, 1), (9, 2) (0, 1), (1, 3), (2, 9)
Asymptote x = 0 (vertical) y = 0 (horizontal)
Intercept x-intercept: (1, 0) y-intercept: (0, 1)

Solution Part (d): Domain and Range

Function Domain Range
f(x) = log₃x x ∈ (0, ∞) y ∈ ℝ or y ∈ (-∞, ∞)
f⁻¹(x) = 3ˣ x ∈ ℝ or x ∈ (-∞, ∞) y ∈ (0, ∞)

Notice: The domain of f equals the range of f⁻¹, and the range of f equals the domain of f⁻¹!

Solution Part (e): Increasing or Decreasing

Since the base a = 3 > 1:

  • f(x) = log₃x is an increasing function for x ∈ (0, ∞)
  • f⁻¹(x) = 3ˣ is an increasing function for x ∈ ℝ

If the base were between 0 and 1, both functions would be decreasing.

2. Finding the Domain of Logarithmic Functions

🔑 Critical Rule

For a logarithmic expression loga(expression) to be defined, the expression inside the logarithm must be POSITIVE.

expression > 0

Worked Example: Finding Domain

Determine the domain of: f(x) = log₇(x + 5)

1 For the logarithm to be defined, the argument must be positive:

x + 5 > 0

2 Solve the inequality:

x > -5

3 Write the domain in interval notation:

Domain: x ∈ (-5, ∞)

Worked Example: Domain with Negative Coefficient

Determine the domain of: f(x) = log₃(-7x + 5)

1 Set the argument greater than zero:

-7x + 5 > 0

2 Rearrange:

-7x > -5

3 Divide by -7 (remember to flip the inequality sign!):

x < 5/7

4 Write the domain:

Domain: x ∈ (-∞, 5/7)

⚠️ Important Reminder: When dividing or multiplying an inequality by a negative number, you must reverse the inequality sign!

3. Graph Transformations and Reflections

Transformations of Logarithmic Functions

Transformation Equation Description
Reflection about x-axis g(x) = -log₂x Flip the graph upside down
Reflection about y-axis g(x) = log₂(-x) Flip the graph left to right (domain: x < 0)
Vertical shift up g(x) = log₂x + k Shift up by k units
Vertical shift down g(x) = log₂x - k Shift down by k units
Horizontal shift left g(x) = log₂(x + h) Shift left by h units
Horizontal shift right g(x) = log₂(x - h) Shift right by h units

Example: Sketching Transformed Graphs

Given f(x) = log₂x, explain how to sketch:

4.1 g(x) = -log₂x

This is a reflection of f about the x-axis

4.2 h(x) = 2ˣ - 5

First, note that 2ˣ is the inverse of log₂x (reflection about y = x)

Then shift the graph 5 units downward

4. Using Graphs to Solve Logarithmic Inequalities

Example: Solving log₂x < 3 using a graph

1 Find where log₂x = 3:

2³ = x, so x = 8

2 On the graph, log₂x < 3 means we need values below y = 3

3 Since log₂x is defined only for x > 0:

Solution: 0 < x < 8
