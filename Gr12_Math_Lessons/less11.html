Infinite Geometric Series

Grade: 12
Week: Term 1 Week 3
Time: 60 minutes
Topic: Series - Convergence & Sum to Infinity

Discover when an infinite geometric series has a finite sum, and learn to calculate the sum to infinity using the formula S∞ = a/(1-r).

🎯 Lesson Objectives

▼

This lesson introduces the concept of infinite geometric series. By the end of this lesson, you will be able to:

  • Distinguish between diverging and converging geometric series
  • Investigate the sum of an infinite geometric series
  • Identify a converging geometric series and understand the condition: -1 < r < 1
  • Apply the formula S∞ = a/(1-r) to sum a converging geometric series to infinity
  • Determine whether a given series converges or diverges based on the common ratio

🧠 Pre-Knowledge Required

▼

Before starting this lesson, you should be familiar with:

  • The general term of a geometric sequence: Tₙ = a·rⁿ⁻¹
  • The sum formula for a finite geometric series: Sₙ = a(rⁿ - 1)/(r - 1)
  • Finding the common ratio r by dividing consecutive terms
  • Understanding what happens when you multiply by numbers less than 1
  • The concept of limits and what it means for a value to "approach" something

🔄 Diverging vs Converging Series

▼

What Happens When We Add Infinite Terms?

Up until now, we've been finding the sum of a finite (fixed) number of terms. But what happens if the series goes on forever? Can we still find a sum?

An infinite series is one with no last term—it continues without ending. The behavior of such a series depends entirely on the value of the common ratio r.

Examples of Different Series Behaviors

Series Common Ratio (r) Behavior Result
1 + 3 + 9 + 27 + ... r = 3 r > 1 DIVERGES (sum gets bigger forever)
1 - 2 + 4 - 8 + ... r = -2 r < -1 DIVERGES (sum oscillates wildly)
2 + 2 + 2 + 2 + ... r = 1 r = 1 DIVERGES (sum grows without bound)
2 - 2 + 2 - 2 + ... r = -1 r = -1 DIVERGES (sum alternates 2 or 0)
1 + ½ + ¼ + ⅛ + ... r = ½ -1 < r < 1 CONVERGES to 2

💡 Key Insight: The Converging Series

Look at the last example: 1 + ½ + ¼ + ⅛ + 1/16 + ...

S₁ = 1 (just the first term)

S₂ = 1.5 (1 + 0.5)

S₃ = 1.75 (1 + 0.5 + 0.25)

S₄ = 1.875 (getting closer to 2...)

S₁₀ ≈ 1.998 (almost at 2!)

As we add more terms, the sum gets closer and closer to 2, but never exceeds it!

CONVERGENCE CONDITION
A geometric series CONVERGES (has a finite sum) if and only if:

-1 < r < 1 (equivalently: |r| < 1)

⚠️ Important: Arithmetic Series NEVER Converge

An arithmetic series (with constant difference d ≠ 0) will always diverge because we keep adding the same amount forever. Only geometric series with |r| < 1 can converge.

∞ Sum to Infinity Formula

▼

Deriving the Sum to Infinity Formula

Recall the sum formula for n terms: Sₙ = a(1 - rⁿ)/(1 - r)

When |r| < 1, something special happens as n → ∞:

What happens to rⁿ when |r| < 1?

Let's take r = 0.5 (which is between -1 and 1):

  • (0.5)¹ = 0.5
  • (0.5)² = 0.25
  • (0.5)⁵ = 0.03125
  • (0.5)¹⁰ = 0.0009765625
  • (0.5)²⁰ = 0.00000095... (almost zero!)

As n → ∞, rⁿ → 0 when |r| < 1

So in our formula Sₙ = a(1 - rⁿ)/(1 - r), as n approaches infinity:

  • rⁿ approaches 0
  • Therefore (1 - rⁿ) approaches (1 - 0) = 1
  • And Sₙ approaches a/(1 - r)
Sum to Infinity Formula

S∞ = a / (1 - r)

Valid ONLY when: -1 < r < 1 (i.e., |r| < 1)

💡 Memory Tip

"a over (1 minus r)" - Remember: the first term 'a' divided by (1 - r)

Always check that |r| < 1 before using this formula!

📌 Alternative Notation

The condition -1 < r < 1 is sometimes written as:

• |r| < 1 (absolute value of r is less than 1)

• r ∈ (-1, 1) (r is in the open interval from -1 to 1)

📊 Worked Examples

▼

Example 1: Simple Sum to Infinity

Find the sum to infinity of: 10 + 1 + 0.1 + 0.01 + ...
  • Identify a and r:
    First term: a = 10
    Common ratio: r = 1/10 = 0.1
  • Check convergence condition:
    Is -1 < r < 1?
    Is -1 < 0.1 < 1? ✓ YES - the series converges!
  • Apply the formula:
    S∞ = a / (1 - r)
    S∞ = 10 / (1 - 0.1)
    S∞ = 10 / 0.9
    S∞ = 100/9 ≈ 11.111...

Answer: S∞ = 100/9 or 11⅑

Example 2: Negative Common Ratio

Find: Σ(from n=1 to ∞) of 3·(-½)ⁿ⁻¹

First, let's write out some terms to understand the series:

  • Find the first few terms:
    T₁ = 3·(-½)⁰ = 3·1 = 3
    T₂ = 3·(-½)¹ = -3/2 = -1.5
    T₃ = 3·(-½)² = 3/4 = 0.75
    Series: 3 - 1.5 + 0.75 - 0.375 + ...
  • Identify a and r:
    a = 3
    r = -½ = -0.5
  • Check convergence:
    Is -1 < -0.5 < 1? ✓ YES
  • Calculate S∞:
    S∞ = a / (1 - r)
    S∞ = 3 / (1 - (-0.5))
    S∞ = 3 / (1 + 0.5)
    S∞ = 3 / 1.5 = 2

Example 3: Non-Convergent Series

Does the series 2 + 6 + 18 + 54 + ... have a sum to infinity?
  • Find r:
    r = 6/2 = 3
  • Check convergence:
    Is -1 < 3 < 1? NO! (3 is greater than 1)
  • Conclusion:
    The series DIVERGES. There is no finite sum to infinity.

📝 Practice Problems

1. Find S∞ for: 8 + 4 + 2 + 1 + ... (Answer: 16)

2. Find S∞ for: 27 - 9 + 3 - 1 + ... (Answer: 81/4 = 20.25)

3. Does 5 + 10 + 20 + 40 + ... converge? (Answer: No, r = 2 > 1)

4. Find S∞: Σ(n=1 to ∞) of (2/3)ⁿ (Answer: 2)

✓ Comprehensive Quiz (12 Questions)

▼

Test your understanding of infinite geometric series. Select an option and get instant feedback.

Question 1: What condition must r satisfy for a geometric series to converge?

A) r > 1
B) -1 < r < 1
C) r < -1
D) r = 1
Explanation: A geometric series converges only when the absolute value of r is less than 1, meaning -1 < r < 1 (or |r| < 1).

Question 2: What is the sum to infinity of: 8 + 4 + 2 + 1 + ...?

A) 8
B) 16
C) 15
D) The series diverges
Explanation: a = 8, r = 0.5. Since |0.5| < 1, it converges. S∞ = 8/(1-0.5) = 8/0.5 = 16.

Question 3: Does the series 1 + 3 + 9 + 27 + ... have a sum to infinity?

A) Yes, S∞ = 40
B) Yes, S∞ = -0.5
C) No, the series diverges
D) Yes, S∞ = ∞
Explanation: r = 3, which is greater than 1. Since |r| > 1, the series diverges and has no finite sum.

Question 4: What is the formula for sum to infinity?

A) S∞ = a·r/(1-r)
B) S∞ = a/(1-r)
C) S∞ = a/(r-1)
D) S∞ = a(1-r)
Explanation: The correct formula is S∞ = a/(1-r), valid only when -1 < r < 1.

Question 5: Find S∞ for the series: 12 - 6 + 3 - 1.5 + ...

A) 8
B) 6
C) 24
D) 4
Explanation: a = 12, r = -6/12 = -0.5. S∞ = 12/(1-(-0.5)) = 12/1.5 = 8.

Question 6: What happens to rⁿ as n → ∞ when |r| < 1?

A) rⁿ → 0
B) rⁿ → 1
C) rⁿ → ∞
D) rⁿ → r
Explanation: When |r| < 1, repeatedly multiplying by r makes the result smaller and smaller, approaching 0.

Question 7: For which value of r does the series 5 + 5r + 5r² + ... converge?

A) r = 2
B) r = -1
C) r = 0.8
D) r = 1
Explanation: Only r = 0.8 satisfies -1 < r < 1. The others are outside this range.

Question 8: If S∞ = 20 and a = 4, find r.

A) r = 0.2
B) r = 0.8
C) r = 5
D) r = -0.8
Explanation: 20 = 4/(1-r) → 1-r = 4/20 = 0.2 → r = 1 - 0.2 = 0.8.

Question 9: Which statement about the series 2 - 2 + 2 - 2 + ... is TRUE?

A) It converges to 2
B) It converges to 0
C) It converges to 1
D) It diverges
Explanation: r = -1, which does not satisfy -1 < r < 1. The sum alternates between 2 and 0, never settling on a single value.

Question 10: Find the sum: Σ(n=1 to ∞) of 5·(⅓)ⁿ

A) 15
B) 7.5
C) 2.5
D) 5
Explanation: T₁ = 5·(⅓)¹ = 5/3. So a = 5/3, r = ⅓. S∞ = (5/3)/(1-⅓) = (5/3)/(⅔) = 5/2 = 2.5.

Question 11: Can an arithmetic series ever have a finite sum to infinity?

A) No, arithmetic series always diverge (when d ≠ 0)
B) Yes, when d < 1
C) Yes, when d is negative
D) Yes, when a < 0
Explanation: Arithmetic series (with constant difference d ≠ 0) always diverge because we keep adding the same amount forever. Only geometric series with |r| < 1 can converge.

Question 12: If the first term is 100 and S∞ = 200, what is r?

A) r = 0.5
B) r = 2
C) r = -0.5
D) r = 0.25
Explanation: 200 = 100/(1-r) → 1-r = 100/200 = 0.5 → r = 0.5.
