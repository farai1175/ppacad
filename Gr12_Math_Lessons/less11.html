📚 Key Concepts Review

In this lesson, we apply the sum to infinity formula to solve real-world problems. Remember:

S∞ = a/1 − r , where −1 < r < 1
Sum to Infinity Formula
✅ Before Using the Formula - Checklist
  • Identify the first term (a)
  • Find the common ratio (r)
  • Verify that −1 < r < 1 (series converges)
  • Apply the formula S∞ = a/(1−r)
💡 Real-World Applications:

Sum to infinity appears in many contexts: population growth limits, depreciation, bouncing balls, tree growth, medicine dosages, and more!

✏️ Worked Examples

Example 1 Tree Growth Problem
🌳 Problem: A tree is 3 m high and its growth each year is 1/10 of its growth the previous year. What is the greatest height that it can reach, assuming it lives forever?

Solution:

1

Understand the pattern:

  • Initial height: 3 m
  • Year 1 growth: 3 m (the initial height)
  • Year 2 growth: 3 × (1/10) = 0.3 m
  • Year 3 growth: 0.3 × (1/10) = 0.03 m
2

Write as a geometric series:

Total Height = 3 + 3(1/10) + 3(1/10)² + 3(1/10)³ + ...
3

Identify a and r:

a = 3 (first term)
r = 1/10 = 0.1
4

Check convergence condition:

−1 < 0.1 < 1 ✓ Series converges!
5

Apply the sum to infinity formula:

S∞ = a / (1 − r)
S∞ = 3 / (1 − 1/10)
S∞ = 3 / (9/10)
S∞ = 3 × (10/9) = 30/9 = 10/3
6

Final Answer:

Greatest Height = 10/3 m ≈ 3.33 m

✓ The tree will approach but never exceed 3.33 meters.

🔍 Note: If the problem states the initial height is 3 m and each subsequent year's growth is 1/10 of the previous year's growth, then the total height = 3/(1 - 0.1) = 3/0.9 = 10/3 ≈ 3.33 m. However, if interpreted as 3m being the first year's growth, then S∞ = 3/(1-0.1) = 3.33 m is the total growth, and if started at 0, max height = 3.33 m.
Example 2 Finding Convergence Values

Problem: For which values of x will the geometric series (1−x) + (1−x)² + (1−x)³ + ... converge?

Solution:

1

Identify the common ratio:

The first term is (1−x), the second term is (1−x)².

r = (1−x)² / (1−x) = (1−x)

So r = (1 − x)

2

Apply the convergence condition:

For convergence: −1 < r < 1
−1 < (1 − x) < 1
3

Solve the compound inequality:

Split into two parts:

Left side:

−1 < 1 − x
−1 − 1 < −x
−2 < −x
x < 2

Right side:

1 − x < 1
−x < 0
x > 0
4

Combine the results:

0 < x < 2

✓ The series converges when x is between 0 and 2 (exclusive).
