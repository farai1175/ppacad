Lesson 3 (60 minutes)

Proving Compound Angle Identities

Learning to prove trigonometric identities and find values using given information

📚 Learning Objectives

  • Understand the difference between "verify" and "prove"
  • Apply compound angle identities to prove trigonometric identities
  • Use special angle values in proofs
  • Find sin(A + B) and cos(A - B) given specific information about angles
  • Work with angles in different quadrants
  • Determine missing trigonometric ratios using Pythagoras

📋 Overview

In this lesson, we take our understanding of compound angle identities to the next level by learning how to prove trigonometric identities. We'll also learn how to calculate expressions like sin(A + B) when we're given information about sin A, cos B, and the quadrants in which the angles lie.

⚠️ Important Distinction

Verify: Substitute specific values to check if an identity is true for those values.

Prove: Show that an identity is true for ALL possible values using algebraic manipulation.

📐 Main Concepts & Principles

1. Verify vs. Prove

The Difference

To Verify: Substitute specific numerical values and show both sides are equal.

Example: Verify sin 60° = √3/2 by calculating it.

To Prove: Manipulate one or both sides algebraically until they are identical, without assuming they're equal from the start.

📝 Three Methods to Prove Identities

  1. LHS → RHS: Start with the Left Hand Side and manipulate until you get the Right Hand Side
  2. RHS → LHS: Start with the Right Hand Side and manipulate until you get the Left Hand Side
  3. Both sides → Same expression: Work on both sides separately until they equal the same thing
⚠️ Important Rule: During a proof, you CANNOT write LHS = RHS until you've actually shown they're equal. You cannot assume what you're trying to prove!

💡 Strategy Tip

It's usually easier to start with the side that has more terms and simplify it, rather than starting with fewer terms and trying to expand.

2. Worked Example 1: Proving an Identity

Prove: cos(A - 30°) + sin(A - 60°) = sin A

Strategy: Start with LHS (has more terms) and work toward RHS

1
LHS = cos(A - 30°) + sin(A - 60°)
Write out the left hand side
2
= cos A cos 30° + sin A sin 30° + sin A cos 60° - cos A sin 60°
Apply compound angle identities
3
= cos A · (√3/2) + sin A · (½) + sin A · (½) - cos A · (√3/2)
Substitute special angle values
4
= (√3/2)cos A - (√3/2)cos A + (½)sin A + (½)sin A
Group like terms
5
= 0 + sin A
cos A terms cancel
6
= sin A = RHS ✓
We've reached the RHS!

4. Working with Angles in Different Quadrants

Quadrant I (0° - 90°)

All positive

sin +, cos +, tan +

Quadrant II (90° - 180°)

Only Sin positive

sin +, cos -, tan -

Quadrant III (180° - 270°)

Only Tan positive

sin -, cos -, tan +

Quadrant IV (270° - 360°)

Only Cos positive

sin -, cos +, tan -

🔑 Memory Aid: CAST

Going counter-clockwise from Q4: Cos (Q4), All (Q1), Sin (Q2), Tan (Q3)

5. Worked Example 2: Finding sin(A + B) and cos(A - B)

Problem

If sin A = 3/5 and cos B = 15/17, where A is an obtuse angle and B is an acute angle, find the values of sin(A + B) and cos(A - B).

Solution

Step 1: Find the missing ratios using Pythagoras

For angle A (obtuse means Quadrant II):

  • sin A = 3/5, so opposite = 3, hypotenuse = 5
  • Adjacent = √(5² - 3²) = √16 = 4
  • Since A is in Q2, cos A is negative: cos A = -4/5

For angle B (acute means Quadrant I):

  • cos B = 15/17, so adjacent = 15, hypotenuse = 17
  • Opposite = √(17² - 15²) = √64 = 8
  • Since B is in Q1, sin B is positive: sin B = 8/17

Step 2: Calculate sin(A + B)

1
sin(A + B) = sin A cos B + cos A sin B
2
= (3/5)(15/17) + (-4/5)(8/17)
3
= 45/85 - 32/85
4
= 13/85

Step 3: Calculate cos(A - B)

1
cos(A - B) = cos A cos B + sin A sin B
2
= (-4/5)(15/17) + (3/5)(8/17)
3
= -60/85 + 24/85
4
= -36/85
