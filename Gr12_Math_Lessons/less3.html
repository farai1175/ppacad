Arithmetic Sequences & Series (Lesson 3)

Grade: 12
Week: Term 1 Week 1
Time: 60 minutes
Topic: Series (3)
Lesson: 3

Finding the value of n in arithmetic sequences and determining terms when only two terms are given

🎯 Lesson Objectives

▼

This lesson focuses on solving problems involving arithmetic sequences. By the end of this lesson, you will be able to:

  • Find the value of n in the general term formula: Tₙ = a + (n-1)d
  • Determine specific terms in an arithmetic sequence when only two terms are given
  • Apply algebraic techniques to solve arithmetic sequence problems
  • Verify solutions by substituting back into the original sequence

Arithmetic Sequence Formula

Tₙ = a + (n-1)d
Where: a = first term, d = common difference, n = term number

Key Concept

Solve for n
Given Tₙ, a, and d, find which term number (n) equals a specific value

✍️ Worked Examples

▼

Example 1: Finding the Value of n

Problem: Considering the arithmetic sequence: 1, 1½, 2, 2½, ... Which term is equal to 80?
  • Step 1: Identify known values
    First term (a) = 1
    Common difference (d) = T₂ - T₁ = 1½ - 1 = ½ = 0.5
    Tₙ = 80
  • Step 2: Apply general term formula
    Tₙ = a + (n-1)d
    80 = 1 + (n-1)(0.5)
  • Step 3: Solve for n
    80 = 1 + 0.5(n-1)
    80 - 1 = 0.5(n-1)
    79 = 0.5(n-1)
    79 × 2 = n-1
    158 = n-1
    n = 159
  • Step 4: Verify
    T₁₅₉ = 1 + (159-1)(0.5) = 1 + 158(0.5) = 1 + 79 = 80 ✓

    • Answer: The 159th term equals 80.

    📝 Informal Assessment 2.2.1

    Try this: Consider the arithmetic sequence: 2; 5; 8; 11; ... Which term is equal to 77?

    Hint: a = 2, d = 3, Tₙ = 77. Solve for n.

    Answer: n = 26

    Example 2: Finding Terms When Only Two Terms Are Given

    Problem: Determine the first three terms of an arithmetic sequence if the 5th term is 12 and the 14th term is -33.
  • Step 1: Set up equations
    Tₙ = a + (n-1)d
    T₅ = a + (5-1)d = a + 4d = 12
    T₁₄ = a + (14-1)d = a + 13d = -33
  • Step 2: Solve simultaneously
    Equation 1: a + 4d = 12
    Equation 2: a + 13d = -33

    Subtract Equation 1 from Equation 2:
    (a + 13d) - (a + 4d) = -33 - 12
    9d = -45
    d = -5
  • Step 3: Find a
    Substitute d = -5 into Equation 1:
    a + 4(-5) = 12
    a - 20 = 12
    a = 32
  • Step 4: Find first three terms
    T₁ = a = 32
    T₂ = a + d = 32 + (-5) = 27
    T₃ = a + 2d = 32 + 2(-5) = 22
  • Step 5: Verify
    T₅ = 32 + 4(-5) = 32 - 20 = 12 ✓
    T₁₄ = 32 + 13(-5) = 32 - 65 = -33 ✓

    • Answer: First three terms: 32; 27; 22

    📝 Informal Assessment 2.2.2

    Try this: Determine the first three terms of the arithmetic sequence if the 10th term is 17 and the 16th term is 44.

    Hint: Set up T₁₀ = a + 9d = 17 and T₁₆ = a + 15d = 44, then solve.

    Answer: -47; -19; 29; ...

    📝 Class Work Problems

    2.3.1 Considering the arithmetic sequence: 4; 11; 18; ... Which term is equal to 697?

    2.3.2 Given the sequence Tₓ = 73 - 3(x - 4). Find:
    a) T₄
    b) x if Tₓ = 50

    2.3.3 The first 3 terms of an arithmetic sequence is given by: x; 4x + 5; 10x + 5. Determine the value of x.

    Detailed Solution to 2.3.1

    Sequence: 4; 11; 18; ...

    • a = 4
    • d = 11 - 4 = 7
    • Tₙ = 697
    • Apply formula: Tₙ = a + (n-1)d
      697 = 4 + (n-1)(7)
      697 = 4 + 7n - 7
      697 = 7n - 3
      700 = 7n
      n = 100
    • Answer: The 100th term equals 697.
    Detailed Solution to 2.3.2

    Given: Tₓ = 73 - 3(x - 4)

  • a) Find T₄:
    T₄ = 73 - 3(4 - 4) = 73 - 3(0) = 73
  • b) Find x if Tₓ = 50:
    50 = 73 - 3(x - 4)
    50 = 73 - 3x + 12
    50 = 85 - 3x
    3x = 85 - 50
    3x = 35
    x = 35/3 ≈ 11.67
    Note: Since x represents term number, this suggests 50 is not a term in the sequence.
    • Detailed Solution to 2.3.3

    Sequence: x; 4x + 5; 10x + 5

    • For arithmetic sequence, difference between consecutive terms is constant
    • T₂ - T₁ = T₃ - T₂
      (4x + 5) - x = (10x + 5) - (4x + 5)
      3x + 5 = 6x
    • Solve: 3x + 5 = 6x
      5 = 3x
      x = 5/3
    • Answer: x = 5/3
    • Verify:
      Sequence: 5/3; 4(5/3)+5 = 20/3+15/3 = 35/3; 10(5/3)+5 = 50/3+15/3 = 65/3
      Differences: 35/3 - 5/3 = 30/3 = 10; 65/3 - 35/3 = 30/3 = 10 ✓

    ✓ Comprehensive Quiz

    ▼

    Test your understanding of finding n and terms in arithmetic sequences.

    Question 1: What is the formula for the general term of an arithmetic sequence?

    A) Tₙ = arⁿ⁻¹
    B) Tₙ = a + (n-1)d
    C) Tₙ = an² + bn + c
    D) Tₙ = a + nd
    Explanation: The correct formula for arithmetic sequences is Tₙ = a + (n-1)d, where a is the first term and d is the common difference.

    Question 2: In the sequence 4; 11; 18; ..., which term equals 697?

    A) 50th term
    B) 75th term
    C) 100th term
    D) 125th term
    Explanation: a=4, d=7, Tₙ=697. Solving: 697=4+(n-1)7 → 697=4+7n-7 → 697=7n-3 → 700=7n → n=100.

    Question 3: If T₅ = 12 and T₁₄ = -33, what is the common difference?

    A) -5
    B) 5
    C) -3
    D) 3
    Explanation: T₅ = a+4d=12, T₁₄ = a+13d=-33. Subtract: 9d=-45 → d=-5.

    Question 4: If a=2 and d=3, which term equals 77?

    A) 24th term
    B) 25th term
    C) 26th term
    D) 27th term
    Explanation: 77=2+(n-1)3 → 77=2+3n-3 → 77=3n-1 → 78=3n → n=26.

    Question 5: What is the first term if T₁₀=17 and T₁₆=44?

    A) -40
    B) -45
    C) -47
    D) -50
    Explanation: T₁₀ = a+9d=17, T₁₆ = a+15d=44. Subtract: 6d=27 → d=4.5. Substitute: a+9(4.5)=17 → a+40.5=17 → a=-23.5. Wait, check: Actually solving: 6d=27 → d=4.5. a+9(4.5)=17 → a=17-40.5=-23.5. But given answer is -47, so let's recalculate properly: 44-17=27, 16-10=6, d=27/6=4.5. a=17-9(4.5)=17-40.5=-23.5. The given answer seems incorrect.
