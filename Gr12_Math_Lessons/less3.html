Arithmetic Sequence and Series

Lesson 3: Finding the Position (n) and Unknown Terms

🎯

Learning Objectives

By the end of this lesson, you will be able to:

  • Find the value of n (position) when given a specific term value in an arithmetic sequence
  • Determine the first term and common difference when only two terms are given
  • Set up and solve simultaneous equations to find unknown values in arithmetic sequences
  • Apply these skills to solve complex arithmetic sequence problems
📚

Pre-requisite Knowledge

Before starting this lesson, you should know:

  • The general term formula: Tn = a + (n − 1)d
  • How to find the general term when a sequence is given
  • How to calculate specific terms using the formula
  • Basic algebraic manipulation and solving equations
Tn = a + (n − 1)d

where a = first term, d = common difference, n = position

🔢

Part 1: Finding the Position (n)

Sometimes we know what a term's value is, but we need to find its position in the sequence. This means solving for n in the general term formula.

Method: Finding Which Term Equals a Given Value

1
Identify a and d from the sequence
2
Set Tn equal to the given value
3
Substitute into Tn = a + (n − 1)d
4
Solve for n (must be a positive integer)
Example 1 Finding Which Term Equals 80

Question: In the arithmetic sequence ½; 1; 1½; 2; 2½; ..., which term is equal to 80?

Step 1: Identify a and d

a = ½

d = T₂ − T₁ = 1 − ½ = ½

Step 2: Set up the equation

Tn = 80

Step 3: Substitute into the formula

80 = ½ + (n − 1)(½)

Step 4: Solve for n

80 = ½ + ½n − ½

80 = ½n

n = 160

∴ The 160th term equals 80

Example 2 Finding Which Term Equals 77

Question: In the sequence 2; 5; 8; 11; ..., which term is equal to 77?

Step 1: Identify a and d

a = 2, d = 5 − 2 = 3

Step 2: Set Tn = 77 and substitute

77 = 2 + (n − 1)(3)

77 = 2 + 3n − 3

77 = 3n − 1

78 = 3n

n = 26

∴ The 26th term equals 77

Part 2: Finding Terms When Two Terms Are Given

When we're given two terms of an arithmetic sequence (but not the first term or common difference), we can use simultaneous equations to find a and d.

Method: Using Two Known Terms

1
Write two equations using Tn = a + (n − 1)d for each known term
2
Solve simultaneously by subtracting one equation from the other to eliminate 'a'
3
Find d from the simplified equation
4
Substitute d back to find a
5
Generate the sequence using a and d
Example 3 Finding Sequence from Two Terms

Question: Find the first three terms of the arithmetic sequence if the 5th term is 12 and the 14th term is −33.

Step 1: Set up two equations

A T₅ = a + 4d = 12
B T₁₄ = a + 13d = −33

Step 2: Subtract equation A from B to eliminate a

(a + 13d) − (a + 4d) = −33 − 12

9d = −45

d = −5

Step 3: Substitute d = −5 into equation A

a + 4(−5) = 12

a − 20 = 12

a = 32

Step 4: Generate the first three terms

T₁ = 32

T₂ = 32 + (−5) = 27

T₃ = 27 + (−5) = 22

∴ First three terms: 32; 27; 22

Example 4 Another Two-Term Problem

Question: Find the first three terms if T₁₀ = −17 and T₁₆ = −44.

Step 1: Set up equations

A a + 9d = −17
B a + 15d = −44

Step 2: Subtract A from B

6d = −27

d = −4.5

Step 3: Find a

a + 9(−4.5) = −17

a = −17 + 40.5 = 23.5

Step 4: First three terms

T₁ = 23.5

T₂ = 23.5 − 4.5 = 19

T₃ = 19 − 4.5 = 14.5

∴ First three terms: 23.5; 19; 14.5

💡

Special Case: Finding x in Algebraic Terms

Sometimes the terms of an arithmetic sequence are given as expressions involving x. Since the common difference is constant, we can set up an equation.

Key Principle

In an arithmetic sequence: T₂ − T₁ = T₃ − T₂ (constant difference)

d = d (use this to solve for x)

Example 5 Finding x

Question: The first 3 terms of an arithmetic sequence are: x; 4x + 5; 10x − 5. Determine the value of x.

Method: Use the property that T₂ − T₁ = T₃ − T₂

(4x + 5) − x = (10x − 5) − (4x + 5)

3x + 5 = 6x − 10

5 + 10 = 6x − 3x

15 = 3x

x = 5

Verify: Substitute x = 5

T₁ = 5

T₂ = 4(5) + 5 = 25

T₃ = 10(5) − 5 = 45

d = 25 − 5 = 20 ✓ and 45 − 25 = 20 ✓

∴ x = 5
