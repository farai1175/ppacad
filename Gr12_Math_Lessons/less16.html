Function Details & Examples

Linear Function Form

y = mx + c
or
y = ax + q

Key Properties

  • m (or a) = gradient (slope) of the line
  • c (or q) = y-intercept (where line crosses y-axis)
  • If m > 0 → positive slope (line goes up from left to right)
  • If m < 0 → negative slope (line goes down from left to right)
  • If m = 0 → horizontal line
  • Sketching method: Dual intercept method

Example: Sketch f(x) = 2x - 3

1 Y-intercept: Put x = 0 → y = 2(0) - 3 = -3 → Point: (0, -3)
2 X-intercept: Put y = 0 → 0 = 2x - 3 → x = 3/2 → Point: (1.5, 0)
3 Sketch: Plot points (0, -3) and (1.5, 0), draw straight line through them

Special Cases

Horizontal line: y = k (e.g., y = 2) - gradient is ZERO

Vertical line: x = k (e.g., x = 2) - gradient is UNDEFINED

Quadratic Function Forms

y = ax²
y = a(x + p)² + q
y = ax² + bx + c

Key Properties

  • a > 0 → "Happy face" parabola ∪ (minimum turning point)
  • a < 0 → "Sad face" parabola ∩ (maximum turning point)
  • Axis of symmetry: x = -p (from turning point form) or x = -b/(2a)
  • Turning point: (-p, q) or calculate using axis of symmetry
  • |a| > 1 → narrower parabola; |a| < 1 → wider parabola

Example: Sketch f(x) = -(x - 2)² + 9

1 Shape: a = -1 < 0 → Sad face (maximum) ∩
2 Turning point: (p, q) = (2, 9)
3 X-intercepts: 0 = -(x-2)² + 9 → (x-2)² = 9 → x = -1 or x = 5
4 Y-intercept: f(0) = -(0-2)² + 9 = -4 + 9 = 5

Hyperbolic Function Form

y = a/x
y = a/(x + p) + q

Key Properties

  • a > 0 → hyperbola in 1st and 3rd quadrants
  • a < 0 → hyperbola in 2nd and 4th quadrants
  • Vertical asymptote: x = -p (the graph never touches this line)
  • Horizontal asymptote: y = q
  • Axes of symmetry: y = x + p + q (if a > 0) or y = -x - p + q (if a < 0)

Example: Sketch f(x) = 4/(x - 3) + 2

1 Asymptotes: Vertical: x = 3; Horizontal: y = 2
2 X-intercept: 0 = 4/(x-3) + 2 → -2 = 4/(x-3) → x = 1
3 Y-intercept: f(0) = 4/(0-3) + 2 = -4/3 + 2 = 2/3
4 Quadrants: a = 4 > 0 → curves in quadrants 1 & 3 (relative to asymptotes)

Exponential Function Forms

y = bˣ
y = ab^(x+p) + q

Key Properties

  • b > 1 → increasing function (growth)
  • 0 < b < 1 → decreasing function (decay)
  • Horizontal asymptote: y = q
  • a > 0 → graph above asymptote; a < 0 → graph below asymptote
  • Reference point: The point (0, 1) on y = bˣ moves to (-p, a + q)
  • The graph never touches the asymptote

Example: Sketch f(x) = 2·2^(x+1) - 4

1 Asymptote: y = -4 (horizontal)
2 Position: a = 2 > 0 → graph above asymptote
3 Direction: b = 2 > 1 → increasing
4 Y-intercept: f(0) = 2·2¹ - 4 = 4 - 4 = 0
5 Reference point: Moves to (-1, 2 + (-4)) = (-1, -2)
⚙️

Effect of Parameters a, p, and q

Understanding Transformations

The parameters a, p, and q transform the basic "mother" function in predictable ways:

Parameter Effect Description
a Vertical Stretch/Compression |a| > 1: steeper; |a| < 1: flatter; a < 0: reflection in x-axis
p Horizontal Translation (x + p): shifts p units LEFT; (x - p): shifts p units RIGHT
q Vertical Translation q > 0: shifts UP; q < 0: shifts DOWN
