Functions and Inverses

Grade: 12
Week: Term 1 Week 4
Time: 60 minutes
Topic: Determining Function Equations & Characteristics

🎯 Lesson Objectives

▼

This lesson focuses on determining equations of various functions and understanding their characteristics. By the end of this lesson, you will be able to:

  • Determine the equation of any linear, quadratic, hyperbolic, and exponential function
  • Understand and apply the concepts of domain and range
  • Interpret various characteristics of unseen graph problems
  • Find function equations from given points, intercepts, and asymptotes
  • Identify increasing and decreasing intervals of functions

📈 Linear Functions (Straight Line Graphs)

▼

Standard Form: y = mx + c

Where m is the gradient (slope) and c is the y-intercept.

Gradient Formula

m = (y₂ - y₁) / (x₂ - x₁)

For any two points (x₁, y₁) and (x₂, y₂)

Case 1: Given y-intercept and one other point

Example: Find the equation of the straight line passing through (0; -10) and (-4; -6)
  • Step 1: Identify y-intercept
    Point (0; -10) is the y-intercept ⇒ c = -10
    Equation becomes: y = mx - 10
  • Step 2: Use the other point to find m
    Substitute (-4; -6): -6 = m(-4) - 10
    -6 = -4m - 10
    4m = -10 + 6 = -4
    m = -1
  • Step 3: Write final equation
    y = -x - 10

Case 2: Given two random points

Example: Find equation through (4;4) and (-6;8)
  • Step 1: Find gradient
    m = (8 - 4) / (-6 - 4) = 4 / (-10) = -2/5
    Equation: y = (-2/5)x + c
  • Step 2: Find c using either point
    Using (4;4): 4 = (-2/5)(4) + c
    4 = -8/5 + c
    c = 4 + 8/5 = 20/5 + 8/5 = 28/5
  • Step 3: Write final equation
    y = (-2/5)x + 28/5

💡 Alternative Method: Point-Slope Form

You can also use: y - y₁ = m(x - x₁)

Using our example: y - 4 = (-2/5)(x - 4)

This avoids having to solve for c separately!

📊 Quadratic Functions (Parabolas)

▼

Standard Form: y = ax² + bx + c

Where a determines the shape, b affects symmetry, and c is the y-intercept.

Case 1: Given turning point and one other point

Turning Point Form

y = a(x - p)² + q

Where (p; q) is the turning point
Example: Parabola with turning point (2; 3) passing through (1; 2)
  • Step 1: Use turning point form
    y = a(x - 2)² + 3
  • Step 2: Substitute given point
    2 = a(1 - 2)² + 3
    2 = a(-1)² + 3
    2 = a + 3
  • Step 3: Solve for a
    a = 2 - 3 = -1
  • Step 4: Write equation
    y = -1(x - 2)² + 3
    y = -(x² - 4x + 4) + 3
    y = -x² + 4x - 4 + 3
    y = -x² + 4x - 1

Case 2: Given x-intercepts (roots) and one point

Root Form

y = a(x - R₁)(x - R₂)

Where R₁ and R₂ are the x-intercepts
Example: Parabola with x-intercepts -3 and 4 passing through (1; -24)
  • Step 1: Use root form
    y = a(x + 3)(x - 4)
  • Step 2: Substitute given point
    -24 = a(1 + 3)(1 - 4)
    -24 = a(4)(-3)
    -24 = -12a
  • Step 3: Solve for a
    a = (-24) / (-12) = 2
  • Step 4: Write equation
    y = 2(x + 3)(x - 4)
    y = 2(x² - x - 12)
    y = 2x² - 2x - 24

📌 Extended Opportunity: Case 3

Given any two points and y-intercept:

1. y-intercept gives you c

2. Create two equations using the given points

3. Solve simultaneously for a and b

📉 Hyperbolic Functions

▼

Standard Form: f(x) = a/(x - p) + q

Where p is vertical asymptote (x = p), q is horizontal asymptote (y = q), and a determines shape.

Hyperbolic Function Structure

y = a/(x - p) + q

Vertical asymptote: x = p | Horizontal asymptote: y = q
Example: Hyperbola with vertical asymptote x = -1, horizontal asymptote y = 1, passing through (-3; 2)
  • Step 1: Identify p and q from asymptotes
    Vertical asymptote: x = -1 ⇒ p = -1
    Horizontal asymptote: y = 1 ⇒ q = 1
    Equation: y = a/(x + 1) + 1
  • Step 2: Substitute given point
    2 = a/(-3 + 1) + 1
    2 = a/(-2) + 1
    2 - 1 = a/(-2)
    1 = a/(-2)
  • Step 3: Solve for a
    a = -2
  • Step 4: Write final equation
    y = -2/(x + 1) + 1

💡 Key Understanding

• The denominator (x - p) determines the vertical asymptote

• When x = p, denominator = 0 ⇒ function undefined ⇒ vertical asymptote

• As x → ±∞, a/(x - p) → 0 ⇒ y → q ⇒ horizontal asymptote

📈 Exponential Functions

▼

Standard Form: g(x) = bˣ + q

Where b is the base (growth/decay factor) and q is the horizontal asymptote.

Exponential Function

y = bˣ + q

Horizontal asymptote: y = q
Example: Exponential graph with horizontal asymptote y = 2 passing through (1; 4)
  • Step 1: Identify q from asymptote
    Horizontal asymptote: y = 2 ⇒ q = 2
    Equation: y = bˣ + 2
  • Step 2: Substitute given point
    4 = b¹ + 2
    4 = b + 2
  • Step 3: Solve for b
    b = 4 - 2 = 2
  • Step 4: Write final equation
    g(x) = 2ˣ + 2

⚠️ Important Distinctions

Growth vs Decay:

• If b > 1: Exponential growth

• If 0 < b < 1: Exponential decay

• If b ≤ 0: Not a standard exponential function

📋 Characteristics of Graphs

▼

Domain and Range

Domain: Set of all x-values for which the function is defined.

Range: Set of all corresponding y-values.

Example: f(x) = 3x² + 2

Domain: x ∈ ℝ (all real numbers)

Range: Since x² ≥ 0, 3x² ≥ 0, so 3x² + 2 ≥ 2

Therefore, Range: y ∈ [2, ∞) or y ∈ [2, ∞)

Increasing and Decreasing Functions

Increasing: Gradient/derivative is positive within an interval.

Decreasing: Gradient/derivative is negative within an interval.

Function Type Typically Increasing Typically Decreasing
Linear When m > 0 When m < 0
Quadratic One side of vertex (depends on a) Other side of vertex
Hyperbolic Throughout if a < 0 Throughout if a > 0
Exponential When b > 1 When 0 < b < 1

💡 Quick Reference: Common Domains

Linear: Domain = ℝ, Range = ℝ

Quadratic: Domain = ℝ, Range depends on vertex

Hyperbolic: Domain = ℝ \ {p}, Range = ℝ \ {q}

Exponential: Domain = ℝ, Range = (q, ∞)

✓ Comprehensive Quiz (10 Questions)

▼

Test your understanding of functions and their equations. Select an option and get instant feedback.

Question 1: What is the gradient formula?

A) (x₂ - x₁)/(y₂ - y₁)
B) (y₂ - y₁)/(x₂ - x₁)
C) (x₁ + x₂)/(y₁ + y₂)
D) (y₁ + y₂)/(x₁ + x₂)
Explanation: The gradient (slope) is calculated as the change in y divided by the change in x: m = (y₂ - y₁)/(x₂ - x₁).

Question 2: A line passes through (0, 5) and (2, 9). What is its equation?

A) y = x + 5
B) y = 2x + 5
C) y = 0.5x + 5
D) y = 2x - 5
Explanation: y-intercept is 5. Gradient = (9-5)/(2-0) = 4/2 = 2. So equation is y = 2x + 5.

Question 3: A parabola has turning point (3, -2) and passes through (1, 6). What is 'a' in y = a(x-3)² - 2?

A) 2
B) -2
C) 4
D) -4
Explanation: 6 = a(1-3)² - 2 → 6 = a(4) - 2 → 8 = 4a → a = 2.

Question 4: A hyperbola has vertical asymptote x = 2 and horizontal asymptote y = -1. What is its form?

A) y = a/(x+2) - 1
B) y = a/(x-2) - 1
C) y = a/(x-2) + 1
D) y = a/(x+2) + 1
Explanation: Vertical asymptote x = 2 means (x-2) in denominator. Horizontal asymptote y = -1 means q = -1.

Question 5: An exponential function has horizontal asymptote y = 3 and passes through (1, 5). What is b in y = bˣ + 3?

A) 1
B) 3
C) 2
D) 4
Explanation: 5 = b¹ + 3 → b = 5 - 3 = 2.

Question 6: What is the domain of f(x) = 4/(x+3)?

A) All real numbers
B) ℝ \ {-3}
C) x > -3
D) x < -3
Explanation: The function is undefined when denominator = 0 → x+3=0 → x=-3. So domain is all real numbers except -3.

Question 7: A quadratic has x-intercepts at -2 and 4, and passes through (0, -16). What is its equation?

A) y = (x+2)(x-4)
B) y = 2(x+2)(x-4)
C) y = 2(x+2)(x-4) but wait...
D) y = -2(x+2)(x-4)
Explanation: y = a(x+2)(x-4). Using (0, -16): -16 = a(2)(-4) = -8a → a = 2. So y = 2(x+2)(x-4) = 2x² - 4x - 16.

Question 8: Which function is always increasing?

A) y = -2x + 3
B) y = (0.5)ˣ
C) y = 3ˣ
D) y = -x²
Explanation: y = 3ˣ is an exponential growth function (base > 1), so it's always increasing. The others are either decreasing or not always increasing.

Question 9: What is the range of f(x) = 2x² + 1?

A) All real numbers
B) y ≥ 1
C) y ≤ 1
D) y > 1
Explanation: x² ≥ 0, so 2x² ≥ 0, so 2x² + 1 ≥ 1. Therefore range is y ≥ 1 or [1, ∞).

Question 10: For a hyperbola y = a/(x-p) + q, what happens as x → p?

A) y → q
B) y → 0
C) y → ±∞
D) y → a
Explanation: As x approaches p, the denominator (x-p) approaches 0, making the fraction a/(x-p) approach ±∞, depending on direction.
