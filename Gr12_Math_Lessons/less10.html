📚 Key Concepts

So far, we've been finding the sum of a finite number of terms using:

Sn = a(rn − 1)/r − 1 , r ≠ 1
Sum of n terms

Now we investigate: What happens when a series has infinitely many terms?

🔑 The Big Question

Can we add up infinitely many numbers and get a finite answer?

The answer is: Sometimes yes! It depends on the value of r.

Divergent vs Convergent Series

Type Condition Behavior Sum to ∞
Divergent r ≥ 1 or r ≤ −1 Sum grows without bound or oscillates Does NOT exist
Convergent −1 < r < 1 Sum approaches a fixed value S∞ = a/(1−r)

Examples of Series Behavior

Example 1 Diverges
1 + 3 + 9 + 27 + ...
r = 3 (r > 1)
The sum gets bigger and bigger without limit.
Example 2 Diverges
1 − 2 + 4 − 8 + ...
r = −2 (r < −1)
The sum alternates between positive and negative, never settling.
Example 3 Diverges
2 + 2 + 2 + 2 + ...
r = 1
The sum keeps growing: 2, 4, 6, 8, ...
Example 4 Diverges
2 − 2 + 2 − 2 + ...
r = −1
The sum oscillates: 2, 0, 2, 0, ...
Example 5 Converges ✓
1/2 + 1/4 + 1/8 + 1/16 + ...
r = 1/2 (−1 < r < 1)
Partial sums: 0.5, 0.75, 0.875, 0.9375... → approaching 1
S∞ = a/1 − r , where −1 < r < 1
Sum to Infinity Formula (Convergent Series Only)
📌 Key Point: An Arithmetic Series will always diverge (the terms don't get smaller). Only geometric series with |r| < 1 can converge.

✏️ Worked Examples

Example 1 Finding Sum to Infinity

Problem: Find the sum to infinity of: 10/3 + 10/9 + 10/27 + ...

Solution:

1

Identify a and r:

a = 10/3

Find r by dividing consecutive terms:

r = (10/9) ÷ (10/3) = (10/9) × (3/10) = 1/3
2

Check if series converges:

−1 < 1/3 < 1 ✓ Series converges!
3

Apply the sum to infinity formula:

S∞ = a / (1 − r)
S∞ = (10/3) / (1 − 1/3)
S∞ = (10/3) / (2/3)
S∞ = (10/3) × (3/2) = 10/2 = 5
4

Final Answer:

S∞ = 5
Example 2 Sum to Infinity with Sigma Notation

Problem: Find the sum to infinity of: ∑n=1∞ (1/5)n

Solution:

1

Write out the first few terms:

Substitute n = 1, 2, 3, ... into (1/5)n:

T1 = (1/5)1 = 1/5
T2 = (1/5)2 = 1/25
T3 = (1/5)3 = 1/125

Series: 1/5 + 1/25 + 1/125 + ...

2

Identify a and r:

a = 1/5
r = (1/25) ÷ (1/5) = 1/5
3

Check convergence:

−1 < 1/5 < 1 ✓ Series converges!
4

Apply the formula:

S∞ = (1/5) / (1 − 1/5)
S∞ = (1/5) / (4/5)
S∞ = (1/5) × (5/4) = 1/4
5

Final Answer:

S∞ = 1/4 = 0.25
