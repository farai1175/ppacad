LESSON 3

Finding Equations of Functions

Domain, Range & Graph Characteristics

🎯

Learning Objectives

  • Determine the equation of any linear, quadratic, hyperbolic and exponential function
  • Understand the concepts of domain and range
  • Interpret various characteristics of graph problems
  • Apply different methods based on given information
📋

Lesson Overview

In this lesson, we learn how to work backwards from graph information to find the equation of a function. Different types of information require different approaches. We'll also explore how to determine the domain and range of functions and identify key characteristics.

Key Skill

Finding equations requires identifying what information is given and selecting the appropriate formula or method. Always start by sketching the information if no graph is provided!

🔍

Finding Equations of Functions

Standard Form of Linear Function

y = mx + c

Must find: m (gradient) and c (y-intercept)

Special Cases

Vertical line: x = number (e.g., x = 3)

Horizontal line: y = number (e.g., y = 5)

1 Given Y-intercept and One Other Point

  1. Substitute the y-intercept into c in the equation
  2. Use the other point: substitute x and y to solve for m

Example: Find the equation through (0, -10) and (-4, -6)

1 (0, -10) is the y-intercept, so c = -10
2 Equation becomes: y = mx - 10
3 Substitute (-4, -6): -6 = m(-4) - 10
4 -4m = -6 + 10 = 4, so m = -1
y = -x - 10

2 Given Two Random Points

  1. Use gradient formula: m = (y₂ - y₁)/(x₂ - x₁)
  2. Substitute one point into y = mx + c to find c
  3. OR use: y - y₁ = m(x - x₁)

Example: Find the equation through (4, 4) and (-6, 8)

1 m = (8 - 4)/(-6 - 4) = 4/(-10) = -2/5
2 Using point (4, 4): 4 = (-2/5)(4) + c
3 4 = -8/5 + c, so c = 4 + 8/5 = 28/5
y = -2x/5 + 28/5 or y = (-2x + 28)/5

Forms of Quadratic Function

y = a(x + p)² + q
y = a(x - R₁)(x - R₂)
y = ax² + bx + c

1 Given Turning Point and One Other Point

Use: y = a(x + p)² + q

  1. Turning point (-p, q) gives you p and q directly
  2. Substitute the other point to find a

Example: Turning point (2, 3), passes through (1, 2)

1 TP is (2, 3), so -p = 2 → p = -2 and q = 3
2 Equation: y = a(x - 2)² + 3
3 Substitute (1, 2): 2 = a(1 - 2)² + 3
4 2 = a(1) + 3 → a = -1
y = -(x - 2)² + 3 or y = -x² + 4x - 1

2 Given X-intercepts (Roots) and One Other Point

Use: y = a(x - R₁)(x - R₂)

  1. Substitute the x-intercepts as R₁ and R₂
  2. Use the other point to find a

Example: X-intercepts at -3 and 4, passes through (1, -24)

1 y = a(x + 3)(x - 4)
2 Substitute (1, -24): -24 = a(1 + 3)(1 - 4)
3 -24 = a(4)(-3) = -12a
4 a = 2
y = 2(x + 3)(x - 4) = 2x² - 2x - 24

3 Given Y-intercept and Two Other Points

Use: y = ax² + bx + c (simultaneous equations)

  1. Y-intercept gives you c directly
  2. Substitute both points to get two equations
  3. Solve simultaneously for a and b

Hyperbolic Function Form

y = a/(x + p) + q

Must find: a, p, and q

1 Given Asymptotes and One Point

  1. Vertical asymptote x = k: means (x + p) = (x - k), so p = -k
  2. Horizontal asymptote y = q: gives q directly
  3. Substitute the given point to find a

Example: Vertical asymptote x = 1, horizontal asymptote y = 1, passes through (-3, 2)

1 Vertical asymptote x = 1 → denominator is (x - 1)
2 Horizontal asymptote y = 1 → q = 1
3 Equation: y = a/(x - 1) + 1
4 Substitute (-3, 2): 2 = a/(-3 - 1) + 1
5 2 - 1 = a/(-4) → 1 = -a/4 → a = -4
y = -4/(x - 1) + 1

Reading Asymptotes from a Graph

The vertical asymptote is the vertical dashed line the curve approaches but never touches.

The horizontal asymptote is the horizontal dashed line the curve approaches as x → ±∞.

Exponential Function Form

y = abˣ + q
or
y = ab^(x+p) + q

1 Given Horizontal Asymptote and One Point

  1. Horizontal asymptote y = q: gives q directly
  2. Substitute the given point to find b (or a)

Example: Form y = bˣ + q, asymptote y = 2, passes through (1, 4)

1 Horizontal asymptote y = 2 → q = 2
2 Equation: y = bˣ + 2
3 Substitute (1, 4): 4 = b¹ + 2
4 b = 4 - 2 = 2
y = 2ˣ + 2

2 Given Two Points (with known q)

  1. Substitute both points to get two equations
  2. Divide one by the other to eliminate a and find b
  3. Substitute back to find a

Domain and Range

📌 Domain

The set of all x-values for which the function is defined. "All possible inputs."

📌 Range

The set of all corresponding y-values. "All possible outputs."

Notation Guide

x ∈ ℝ (all real numbers)
x ∈ (-∞, ∞)
y ≥ k or y ∈ [k, ∞)
x ≠ k (excluding k)
Function Type Domain Range
Linear y = mx + c x ∈ ℝ (all real numbers) y ∈ ℝ (all real numbers)
Quadratic (a > 0) x ∈ ℝ y ≥ q (minimum at TP)
Quadratic (a < 0) x ∈ ℝ y ≤ q (maximum at TP)
Hyperbolic x ∈ ℝ, x ≠ -p y ∈ ℝ, y ≠ q
Exponential (a > 0) x ∈ ℝ y > q
Exponential (a < 0) x ∈ ℝ y < q

Example: f(x) = -3(x - 2)² + 5

This is a parabola with a = -3 (sad face, maximum)

Turning point: (2, 5)

D Domain: x ∈ ℝ or x ∈ (-∞, ∞)
R Range: y ≤ 5 or y ∈ (-∞, 5]
📈

Increasing & Decreasing Functions

📌 Increasing

A function is increasing on an interval if the gradient is positive (graph goes up from left to right).

📌 Decreasing

A function is decreasing on an interval if the gradient is negative (graph goes down from left to right).

Example: For f(x) = -x² + 4

This parabola has turning point at (0, 4) and opens downward.

  • Increasing for x < 0 (left of turning point)
  • Decreasing for x > 0 (right of turning point)
