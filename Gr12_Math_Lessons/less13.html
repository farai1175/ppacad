Comparison: Arithmetic vs Geometric Sequences

Property Arithmetic Sequence Geometric Sequence
Definition Add/subtract a constant value Multiply/divide by a constant value
Common Term d (common difference) r (common ratio)
Finding d or r d = T₂ - T₁ = T₃ - T₂ ... r = T₂/T₁ = T₃/T₂ ...
General Term Tₙ = a + (n-1)d Tₙ = a · rⁿ⁻¹
Sum Formula Sₙ = n/2[2a + (n-1)d]
or Sₙ = n/2(a + l)		 Sₙ = a(rⁿ - 1)/(r - 1)
or Sₙ = a(1 - rⁿ)/(1 - r)
Mean Formula b = (a + c)/2 b = ±√(a · c)
Example 2, 5, 8, 11, 14, ... (d = 3) 2, 6, 18, 54, ... (r = 3)
📝

Essential Formulae

📌 Common Difference

d = T₂ - T₁

The constant value added between consecutive terms

📌 General Term (nth term)

Tₙ = a + (n - 1)d

Where a = first term, n = term number, d = common difference

📌 Sum of n Terms

Sₙ = n/2[2a + (n - 1)d]

Sum from first term to nth term

📌 Sum (Alternative)

Sₙ = n/2(a + l)

Where l = last term (useful when last term is known)

📌 Common Ratio

r = T₂ / T₁

The constant value multiplied between consecutive terms

📌 General Term (nth term)

Tₙ = a · rⁿ⁻¹

Where a = first term, n = term number, r = common ratio

📌 Sum of n Terms (r > 1)

Sₙ = a(rⁿ - 1) / (r - 1)

Used when common ratio is greater than 1

📌 Sum of n Terms (r < 1)

Sₙ = a(1 - rⁿ) / (1 - r)

Used when common ratio is less than 1

📌 Sum to Infinity (|r| < 1)

S∞ = a / (1 - r)

Only valid when -1 < r < 1

Arithmetic Mean
b = (a + c) / 2
  • Average of two numbers
  • Creates arithmetic sequence: a, b, c
  • Results in ONE value
  • Also called "Average"
Geometric Mean
b = ±√(a × c)
  • Square root of product
  • Creates geometric sequence: a, b, c
  • Results in TWO values (±)
  • Also called "Mean Proportional"
✏️

Worked Examples

Example 1: Arithmetic Sequence

Find the 15th term and sum of the first 15 terms of: 3, 7, 11, 15, ...

1 Identify: a = 3, d = 7 - 3 = 4
2 T₁₅ = a + (n-1)d = 3 + (15-1)(4) = 3 + 56 = 59
3 S₁₅ = n/2[2a + (n-1)d] = 15/2[2(3) + 14(4)]
4 S₁₅ = 15/2[6 + 56] = 15/2(62) = 465

Example 2: Geometric Sequence

Find the 8th term and sum of the first 8 terms of: 2, 6, 18, 54, ...

1 Identify: a = 2, r = 6 ÷ 2 = 3
2 T₈ = a · rⁿ⁻¹ = 2 × 3⁷ = 2 × 2187 = 4374
3 S₈ = a(rⁿ - 1)/(r - 1) = 2(3⁸ - 1)/(3 - 1)
4 S₈ = 2(6561 - 1)/2 = 6560 = 6560

Example 3: Identifying Sequence Type

Determine if the sequence 4, 12, 36, 108, ... is arithmetic or geometric.

1 Check for common difference: 12 - 4 = 8, 36 - 12 = 24 ❌ (not constant)
2 Check for common ratio: 12 ÷ 4 = 3, 36 ÷ 12 = 3, 108 ÷ 36 = 3 ✓
3 This is a Geometric Sequence with r = 3
