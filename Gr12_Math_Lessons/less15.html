Functions and Graphs

Grade: 12
Week: Term 1 Week 4
Time: 60 minutes
Topic: Functions - Linear, Quadratic, Hyperbolic & Exponential

Master four types of algebraic functions: linear (straight lines), quadratic (parabolas), hyperbolic (hyperbolas), and exponential functions. Understand how parameters transform graphs.

🎯 Lesson Objectives

▼

This lesson explores four types of algebraic functions. By the end of this lesson, you will be able to:

  • Understand the definition of a function and function notation
  • Recognise and sketch linear, quadratic, hyperbolic, and exponential functions
  • Identify the effects of parameters (a, p, q) on each type of graph
  • Apply the dual intercept method for sketching linear functions
  • Determine turning points, axes of symmetry, and asymptotes for various functions
  • Interpret transformations including translations, stretches, and reflections

📈 Linear Functions (Straight Line Graphs)

▼

General Form: y = mx + c or y = ax + q

In linear functions, m (or a) represents the gradient, and c (or q) represents the y-intercept.

↗️
Positive Gradient
y = 2x + 3
a > 0, positive slope
↘️
Negative Gradient
y = -x + 2
a < 0, negative slope
Dual Intercept Method for Sketching
1. X-intercept: Set y = 0, solve for x
2. Y-intercept: Set x = 0, solve for y
3. Plot both points and draw the line
Example 1: Sketch f(x) = 2x - 3
  • X-intercept (y = 0):
    0 = 2x - 3
    2x = 3
    x = 1.5 → Point (1.5, 0)
  • Y-intercept (x = 0):
    y = 2(0) - 3
    y = -3 → Point (0, -3)
  • Sketch:
    Plot (1.5, 0) and (0, -3)
    Draw a straight line through both points

📌 Special Cases: Horizontal and Vertical Lines

Horizontal line: y = k (gradient = 0)

Vertical line: x = k (gradient = undefined)

Example: y = 2 is horizontal, x = 3 is vertical

💡 Effect of Parameters

a (gradient): Controls steepness and direction

q (y-intercept): Controls vertical position

• If q > 0: Graph shifts q units upwards

• If q < 0: Graph shifts |q| units downwards

📊 Quadratic Functions (Parabolas)

▼

Standard Forms

Quadratic functions can be written in several forms:

  • f(x) = ax²
  • f(x) = ax² + q
  • f(x) = a(x - p)² + q
  • f(x) = ax² + bx + c
Shape Condition Description
😊 Happy face a > 0 Minimum turning point (opens upwards)
☹️ Sad face a < 0 Maximum turning point (opens downwards)
Example 2: Sketch f(x) = (x - 2)² - 9
  • Shape:
    a = 1 > 0 → Happy face (minimum)
  • Turning Point:
    From f(x) = a(x - p)² + q
    p = 2, q = -9 → Turning point: (2, -9)
  • X-intercepts (y = 0):
    0 = (x - 2)² - 9
    (x - 2)² = 9
    x - 2 = ±3
    x = 5 or x = -1 → Points (5, 0) and (-1, 0)
  • Y-intercept (x = 0):
    y = (0 - 2)² - 9 = 4 - 9 = -5 → Point (0, -5)
Key Formulas
Axis of symmetry: x = -b/(2a) or x = p
Turning point: (p, q) or (-b/(2a), f(-b/(2a)))
X-intercepts: Solve ax² + bx + c = 0

💡 Parameter Effects

a: Vertical stretch/compression and reflection

p: Horizontal translation (x + p shifts left, x - p shifts right)

q: Vertical translation (up if q > 0, down if q < 0)

🔄 Hyperbolic Functions (Hyperbolas)

▼

Standard Form: f(x) = a/(x + p) + q

Hyperbolic functions have two asymptotes and exist in two branches.

📌 Key Features

Vertical asymptote: x = -p (denominator = 0)

Horizontal asymptote: y = q

Quadrants: a > 0 → 1st & 3rd quadrants; a < 0 → 2nd & 4th quadrants

Example 3: Sketch f(x) = 4/(x + 3) - 2
  • Asymptotes:
    Vertical: x + 3 = 0 → x = -3
    Horizontal: y = -2
  • X-intercept (y = 0):
    0 = 4/(x + 3) - 2
    2 = 4/(x + 3)
    2(x + 3) = 4
    x + 3 = 2 → x = -1 → Point (-1, 0)
  • Y-intercept (x = 0):
    y = 4/(0 + 3) - 2 = 4/3 - 2 = -2/3 → Point (0, -2/3)

💡 Transformation from "Mother" Graph

Starting from y = 1/x (the basic hyperbola):

1. y = 4/x → Vertical stretch by factor 4

2. y = 4/(x + 3) → Shift 3 units left

3. y = 4/(x + 3) - 2 → Shift 2 units down

📈 Exponential Functions

▼

Standard Form: f(x) = ab^(x + p) + q

Exponential functions always have a horizontal asymptote and either increase or decrease.

Base (b) Behavior Graph Type
b > 1 Increasing Growth function
0 < b < 1 Decreasing Decay function
Example 4: Sketch f(x) = 2·2^(x + 1) - 4
  • Behavior:
    a = 2 > 0 → Above asymptote
    b = 2 > 1 → Increasing function
  • Asymptote:
    Horizontal asymptote: y = -4
  • Y-intercept (x = 0):
    y = 2·2^(0 + 1) - 4 = 2·2 - 4 = 0 → Point (0, 0)
  • Reference point movement:
    From (0, 1) in y = 2^x to (-1, 2 - 4) = (-1, -2)
Key Characteristics
• Horizontal asymptote: y = q
• Y-intercept: f(0) = ab^p + q
• Domain: All real numbers
• Range: y > q if a > 0; y < q if a < 0

💡 Important Notes

1. When x = 0, b^0 = 1 (any base to power 0 equals 1)

2. The point (0, 1) in y = b^x moves to (-p, a + q) in the transformed function

3. Exponential functions never touch their asymptotes

✓ Comprehensive Quiz (12 Questions)

▼

Test your understanding of functions and graphs. Select an option and get instant feedback.

Question 1: What is the gradient of the line y = -3x + 5?

A) -3
B) 3
C) 5
D) -5
Explanation: In the form y = mx + c, m is the gradient. Here m = -3.

Question 2: Which function represents a parabola with a minimum turning point?

A) y = -x² + 3
B) y = 2x² - 4
C) y = -3(x - 1)²
D) y = -½x² + 2
Explanation: A parabola has a minimum turning point when a > 0. Only option B has a = 2 > 0.

Question 3: What are the asymptotes of y = 4/(x + 2) - 3?

A) x = 4, y = -3
B) x = -2, y = -3
C) x = 2, y = 3
D) x = -4, y = 3
Explanation: Vertical asymptote: x + 2 = 0 → x = -2. Horizontal asymptote: y = -3.

Question 4: For the exponential function y = 3·2^x, what is the y-intercept?

A) 2
B) 3
C) 6
D) 0
Explanation: When x = 0, y = 3·2⁰ = 3×1 = 3.

Question 5: What is the turning point of y = (x - 3)² + 4?

A) (3, 4)
B) (-3, 4)
C) (3, -4)
D) (-3, -4)
Explanation: In the form y = a(x - p)² + q, the turning point is (p, q). Here p = 3, q = 4.

Question 6: Which function represents exponential decay?

A) y = 3·4^x
B) y = 2·(½)^x
C) y = 5·2^x
D) y = 0.5·3^x
Explanation: Exponential decay occurs when 0 < b < 1. Only option B has b = ½.

Question 7: What is the gradient of a horizontal line?

A) 0
B) 1
C) Undefined
D) ∞
Explanation: Horizontal lines have zero gradient (no vertical change).

Question 8: The graph of y = f(x) + 2 is obtained by:

A) Shifting 2 units left
B) Shifting 2 units right
C) Shifting 2 units up
D) Shifting 2 units down
Explanation: Adding to the function (f(x) + q) causes a vertical shift. q > 0 shifts up.

Question 9: Which is NOT a function?

A) y = 2x + 3
B) y = x²
C) x = y²
D) y = 3^x
Explanation: x = y² is not a function because for some x values (x > 0), there are two y values.

Question 10: What is the axis of symmetry for y = x² - 4x + 3?

A) x = -2
B) x = 2
C) x = 4
D) x = -4
Explanation: Axis of symmetry: x = -b/(2a) = -(-4)/(2×1) = 4/2 = 2.

Question 11: The hyperbola y = -2/(x - 1) is located in which quadrants?

A) 1st and 3rd
B) 2nd and 4th
C) 1st and 2nd
D) 3rd and 4th
Explanation: When a < 0, the hyperbola is in the 2nd and 4th quadrants.

Question 12: What transformation turns y = x² into y = (x + 3)²?

A) Shift 3 units left
B) Shift 3 units right
C) Shift 3 units up
D) Shift 3 units down
Explanation: Replacing x with (x + p) causes horizontal shift. x + 3 means shift 3 units left.
