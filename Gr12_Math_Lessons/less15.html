Introduction to Functions

Relations, Functions & Function Notation

🎯

Learning Objectives

  • Define a function and distinguish it from a relation
  • Identify functions in ordered pairs and from graphs
  • Use the vertical line test and horizontal line test
  • Understand types of notation for functions and use these to determine function values
🔗

Relations and Functions

📌 Relation

A relation is a rule by means of which each element of the first set is associated with at least one element of the second set. Any set of ordered pairs is a relation.

📌 Function

A function is a special type of relation where each element of the first set (domain) is associated with exactly one element of the second set (range). Every input has only ONE output.

Key Difference

All functions are relations, but not all relations are functions!

In a function, an x-value can NEVER be paired with more than one y-value.

Domain and Range

📌 Domain

The domain is the set of all input values (x-values) for which the function is defined. These are the elements of the first set.

📌 Range

The range is the set of all output values (y-values) that result from the function. These are also called the images or function values.

Example: Identify Domain and Range

{(1, 2), (2, 4), (3, 6), (4, 8)}
D Domain: x ∈ {1, 2, 3, 4}
R Range: y ∈ {2, 4, 6, 8}
This is a ONE-TO-ONE FUNCTION ✓

Remember

When working with functions and the domain is not given, assume the domain to be the set of all real numbers: x ∈ ℝ

📐

Vertical & Horizontal Line Tests

📏 Vertical Line Test

Purpose: Determines if a graph is a function

  • Hold a ruler parallel to the y-axis
  • Move it from left to right across the graph
  • If the line ever cuts the graph in MORE than one place → NOT a function
  • If it only cuts in ONE place everywhere → IS a function

📏 Horizontal Line Test

Purpose: Determines the TYPE of function (only after vertical test passes!)

  • Hold a ruler parallel to the x-axis
  • Move it up and down across the graph
  • If line cuts in ONE place → One-to-one function
  • If line cuts in MORE than one place → Many-to-one function

Important Order!

Always apply the Vertical Line Test FIRST to determine if it's a function. Only then use the Horizontal Line Test to determine what type of function it is.

Function Notation

Since functions are special relations, we use specific notation for them:

Mapping Notation

f : x → 2x

"f maps x onto 2x"

If x = 3, then 3 maps to 2(3) = 6

We say 6 is the image of 3

Functional Notation

f(x) = 2x

"f of x equals 2x"

The symbol f(x) denotes the y-value

y = f(x), so if x = 3, then f(3) = 6

Example 1: Evaluate f(x) = x² - 2x + 1

Find: a) f(1)   b) f(-2)   c) f(0)   d) f(a)

a f(1) = (1)² - 2(1) + 1 = 1 - 2 + 1 = 0
b f(-2) = (-2)² - 2(-2) + 1 = 4 + 4 + 1 = 9
c f(0) = (0)² - 2(0) + 1 = 0 - 0 + 1 = 1
d f(a) = (a)² - 2(a) + 1 = a² - 2a + 1

Example 2: If f : x → -2x + 3, find f(1), f(0), f(-½)

1 f(1) = -2(1) + 3 = -2 + 3 = 1
2 f(0) = -2(0) + 3 = 0 + 3 = 3
3 f(-½) = -2(-½) + 3 = 1 + 3 = 4
