🎯 Lesson Objectives

▼

This lesson introduces arithmetic series and their properties. By the end of this lesson, you will be able to:

  • Understand what an arithmetic series is
  • Prove the formula for the sum of the first n terms of an arithmetic sequence
  • Calculate the sum of terms in an arithmetic series using formulas
  • Apply the sum formulas to solve various problems
  • Work with series expressed in terms of variables

Sum Formula 1

Sₙ = n/2 [2a + (n-1)d]
Where: a = first term, d = common difference, n = number of terms

Sum Formula 2

Sₙ = n/2 (a + l)
Where: a = first term, l = last term, n = number of terms

📖 Definition of Arithmetic Series

▼

What is an Arithmetic Series?

An arithmetic series is the sum of an arithmetic sequence. While a sequence lists terms, a series adds them together.

If 5; 7; 9; 11; ... is an arithmetic sequence
Then 5 + 7 + 9 + 11 + ... is an arithmetic series

The sum of the first n terms is denoted by Sₙ:

Sₙ = T₁ + T₂ + T₃ + ... + Tₙ Sₙ represents the sum of the first n terms
Example: Calculating Sₙ directly

For the series: 1 + 4 + 7 + 10 + ...

  • S₃ = 1 + 4 + 7 = 12
  • S₇ = 1 + 4 + 7 + 10 + 13 + 16 + 19 = 70

🧮 Derivation of the Sum Formula

▼

Proving the Formula (Examinable!)

The derivation of the sum formula is important and may be examined. Here's the step-by-step proof:

1
Let Sₙ = a + (a+d) + (a+2d) + ... + [a+(n-2)d] + [a+(n-1)d]
2
Write Sₙ in reverse order: Sₙ = [a+(n-1)d] + [a+(n-2)d] + ... + (a+2d) + (a+d) + a
3
Add the two expressions for Sₙ: 2Sₙ = [2a+(n-1)d] + [2a+(n-1)d] + ... + [2a+(n-1)d]
4
There are n terms in this sum: 2Sₙ = n[2a + (n-1)d]
5
Divide by 2: Sₙ = n/2 [2a + (n-1)d] ✓
Alternative Formula: Sₙ = n/2 (a + l) Where l = last term = a + (n-1)d

Note: This derivation is examinable! Make sure you understand and can reproduce it.

✍️ Worked Examples

▼

Example 1: Using the General Term

Problem: Determine the sum of the first 12 terms of the series with Tₖ = 5k - 3
  • Step 1: Identify terms
    T₁ = 5(1) - 3 = 2
    T₂ = 5(2) - 3 = 7
    T₃ = 5(3) - 3 = 12
    ...
    T₁₂ = 5(12) - 3 = 57
  • Step 2: Series is: 2 + 7 + 12 + ... + 57
  • Step 3: Use Sₙ = n/2 (a + l)
    n = 12, a = 2, l = 57
    S₁₂ = 12/2 (2 + 57) = 6 × 59 = 354
  • Alternative using Sₙ = n/2 [2a + (n-1)d]
    d = 7 - 2 = 5
    S₁₂ = 12/2 [2(2) + (12-1)5] = 6[4 + 55] = 6 × 59 = 354

    • Answer: S₁₂ = 354

    Example 2: Finding S₂₀ for -1 + 3 + 7 + ...

    Problem: Find the sum of the first 20 terms of the series: -1 + 3 + 7 + ...

  • Step 1: Identify parameters
    a = -1
    d = 3 - (-1) = 4
    n = 20
  • Step 2: Apply formula
    Sₙ = n/2 [2a + (n-1)d]
    S₂₀ = 20/2 [2(-1) + (20-1)4]
    S₂₀ = 10[-2 + 19×4]
    S₂₀ = 10[-2 + 76]
    S₂₀ = 10 × 74 = 740

    • Answer: S₂₀ = 740

    Example 3: Finding S₂₀ for (-16) + (-12) + (-8) + ...

    Problem: Find the sum of the first 20 terms of the series: (-16) + (-12) + (-8) + ...

  • Step 1: Identify parameters
    a = -16
    d = (-12) - (-16) = 4
    n = 20
  • Step 2: Apply formula
    Sₙ = n/2 [2a + (n-1)d]
    S₂₀ = 20/2 [2(-16) + (20-1)4]
    S₂₀ = 10[-32 + 19×4]
    S₂₀ = 10[-32 + 76]
    S₂₀ = 10 × 44 = 440

    • Answer: S₂₀ = 440

    📝 Class Work Problems

    Use the arithmetic sequence below: x+1; 3x+2; 5x+5

    a) Find the common difference in terms of x.

    b) Determine in terms of x the 6th term.

    c) Determine in terms of x the sum of the first 8 terms.

    Detailed Solution
  • a) Common difference:
    d = T₂ - T₁ = (3x+2) - (x+1) = 3x+2 - x - 1 = 2x + 1
    Verify: d = T₃ - T₂ = (5x+5) - (3x+2) = 5x+5 - 3x - 2 = 2x + 3
    Wait, there's a problem: 2x+1 ≠ 2x+3. Let's recalculate properly:

    Actually: T₁ = x+1, T₂ = 3x+2, T₃ = 5x+5
    d₁ = T₂ - T₁ = (3x+2) - (x+1) = 2x + 1
    d₂ = T₃ - T₂ = (5x+5) - (3x+2) = 2x + 3
    For arithmetic sequence, d should be constant. There might be an error in the problem.
    Assuming the sequence is arithmetic, let's use d = 2x+1
  • b) 6th term:
    Tₙ = a + (n-1)d
    T₆ = (x+1) + (6-1)(2x+1)
    T₆ = x+1 + 5(2x+1)
    T₆ = x+1 + 10x+5 = 11x + 6
  • c) Sum of first 8 terms:
    Sₙ = n/2 [2a + (n-1)d]
    S₈ = 8/2 [2(x+1) + (8-1)(2x+1)]
    S₈ = 4[2x+2 + 7(2x+1)]
    S₈ = 4[2x+2 + 14x+7]
    S₈ = 4[16x + 9] = 64x + 36

    • Answers: a) d = 2x+1, b) T₆ = 11x+6, c) S₈ = 64x+36

    Note: The given answers in the lesson text appear to have different values. Check calculations carefully.

    Explanation: The formula for the sum of the first n terms of an arithmetic series is Sₙ = n/2 [2a + (n-1)d].

    Question 3: For the series 1 + 4 + 7 + 10, what is S₃?

    A) 10
    B) 11
    C) 12
    D) 13

    A) 720
    B) 730
    C) 740
    D) 750
    Explanation: S₂₀ = 20/2 [2(-1) + (20-1)4] = 10[-2 + 76] = 10 × 74 = 740.

    Question 5: What is the alternative formula for Sₙ?

    A) Sₙ = n(a + d)
    B) Sₙ = n/2 (a + l)
    C) Sₙ = a(1 - rⁿ)/(1 - r)
    D) Sₙ = n²/2
    Explanation: The alternative formula is Sₙ = n/2 (a + l), where l is the last term.

    Question 6: For Tₖ = 5k - 3, what is S₁₂?

    A) 350
    B) 352
    C) 354

    A) 420
    B) 430

    D) 450

    A) First term

    A) -180
    B) -184
    C) -186
    D) -190
    Explanation: a = 12, d = -5, l = -43. First find n: -43 = 12 + (n-1)(-5) → n = 12. S₁₂ = 12/2 (12 + (-43)) = 6 × (-31) = -186.

    Explanation: The derivation starts by writing Sₙ as the sum of terms: Sₙ = a + (a+d) + (a+2d) + ... + [a+(n-1)d].

    Question 11: If S₈ = 64x + 36 for sequence x+1; 3x+2; 5x+5, what is a?

    A) x+1
    B) 3x+2
    C) 5x+5
    D) 2x+1
    Explanation: The first term a is x+1, which is T₁ in the given sequence.
