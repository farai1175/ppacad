Arithmetic Series

Lesson 4: Sum of the First n Terms of an Arithmetic Sequence

🎯

Learning Objectives

By the end of this lesson, you will be able to:

  • Understand what an arithmetic series is and how it differs from a sequence
  • Prove the formula for the sum of the first n terms of an arithmetic sequence
  • Apply the sum formulas Sn = (n/2)[2a + (n−1)d] and Sn = (n/2)[a + l]
  • Calculate the sum of terms in various arithmetic series problems
📊

Sequence vs Series: What's the Difference?

📝 Key Definitions

Arithmetic Sequence: A list of numbers where each term is found by adding a constant (common difference) to the previous term.

Arithmetic Series: The SUM of the terms of an arithmetic sequence.

Concept Sequence (List) Series (Sum)
Notation 5; 7; 9; 11; ... 5 + 7 + 9 + 11 + ...
What we find Individual terms (Tn) Sum of terms (Sn)
Formula Tn = a + (n−1)d Sn = (n/2)[2a + (n−1)d]

💡 Remember

Sn represents the sum of the first n terms:

Sn = T1 + T2 + T3 + ... + Tn

🔢

Understanding Sn Through Examples

Let's start with a simple approach before using the formula. Consider the series: 1 + 4 + 7 + 10 + ...

Example 1 Calculating S3 and S7 by Direct Addition

Series: 1 + 4 + 7 + 10 + 13 + 16 + 19 + ...

Finding S3: Sum of first 3 terms

S3 = 1 + 4 + 7 = 12

Finding S7: Sum of first 7 terms

S7 = 1 + 4 + 7 + 10 + 13 + 16 + 19 = 70

Direct addition works for small n, but what if we need S100 or S1000? We need a formula!

📜

Proving the Sum Formula

There's an elegant proof attributed to the mathematician Carl Friedrich Gauss. The key insight is to write the sum forwards and backwards, then add them together.

🔬 Proof: Deriving Sn = (n/2)[2a + (n−1)d]
1

Write the sum Sn in terms of a and d:

Sn = a + (a+d) + (a+2d) + ... + [a+(n−1)d]

2

Write Sn in reverse order:

Sn = [a+(n−1)d] + [a+(n−2)d] + ... + (a+d) + a

3

Add the two expressions together:

2Sn = [2a+(n−1)d] + [2a+(n−1)d] + ... (n times)

2Sn = n × [2a + (n−1)d]

4

Divide both sides by 2:

Sn = (n/2)[2a + (n−1)d]

The Two Sum Formulas

Sn = (n/2)[2a + (n−1)d]
Sn = sum of n terms
n = number of terms
a = first term
d = common difference

Use this when you know a, d, and n

Sn = (n/2)[a + l]
Sn = sum of n terms
n = number of terms
a = first term
l = last term

Use this when you know the first and last terms

✏️

Worked Examples

Example 2 Finding S20 for a Simple Series

Question: Find the sum of the first 20 terms of the series: −1 + 3 + 7 + 11 + ...

Step 1: Identify a, d, and n

a = −1, d = 3 − (−1) = 4, n = 20

Step 2: Apply the formula Sn = (n/2)[2a + (n−1)d]

S20 = (20/2)[2(−1) + (20−1)(4)]

S20 = 10[−2 + 19(4)]

S20 = 10[−2 + 76]

S20 = 10 × 74

S20 = 740

Example 3 Negative Common Difference

Question: Find the sum of the first 20 terms of the series: (−16) + (−12) + (−8) + ...

Step 1: Identify a, d, and n

a = −16, d = (−12) − (−16) = 4, n = 20

Step 2: Apply the formula

S20 = (20/2)[2(−16) + (20−1)(4)]

S20 = 10[−32 + 76]

S20 = 10 × 44

S20 = 440

Example 4 Using the a + l Formula

Question: Find the sum of the arithmetic series: 12 + 7 + 2 + ... + (−43)

Step 1: Identify a, l, and d

a = 12, l = −43, d = 7 − 12 = −5

Step 2: Find n (number of terms)

l = a + (n−1)d

−43 = 12 + (n−1)(−5)

−55 = (n−1)(−5)

n − 1 = 11

n = 12

Step 3: Apply Sn = (n/2)[a + l]

S12 = (12/2)[12 + (−43)]

S12 = 6 × (−31)

S12 = −186

Example 5 Sigma Notation with Formula

Question: Determine the sum of the first 12 terms if Tk = 5k − 3

Step 1: Find the first few terms

T1 = 5(1) − 3 = 2

T2 = 5(2) − 3 = 7

T12 = 5(12) − 3 = 57

Step 2: Identify a = 2, d = 5, n = 12

Method 1: Using Sn = (n/2)[2a + (n−1)d]

S12 = (12/2)[2(2) + (12−1)(5)]

S12 = 6[4 + 55] = 6 × 59 = 354

Method 2: Using Sn = (n/2)[a + l]

S12 = (12/2)[2 + 57] = 6 × 59 = 354

S12 = 354

Lesson Summary

Key Formulas to Remember

Sn = (n/2)[2a + (n−1)d]

OR

Sn = (n/2)[a + l]

💡 When to Use Each Formula

  • Use Sn = (n/2)[2a + (n−1)d] when you know a, d, and n
  • Use Sn = (n/2)[a + l] when you know the first and last terms
  • Both formulas give the same answer – choose based on available information
