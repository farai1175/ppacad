Lesson Overview

In this lesson, we will focus on calculating the equilibrium constant (Kc) using a systematic approach called the ICE table method. ICE stands for Initial, Change, and Equilibrium. This method helps organize the information given in a problem and systematically solve for unknown concentrations and Kc.

📝 Pre-Knowledge Required:
  • Dynamic equilibrium concepts
  • Le Chatelier's principle and factors affecting equilibrium
  • Equilibrium constant expressions (Kc)
  • Stoichiometry and molar ratios
📋

The ICE Table Method

The ICE table is a systematic way to organize equilibrium calculations. Most Kc problems give you some information (usually moles) and ask you to find missing values and calculate Kc.

📊 Step-by-Step ICE Table Method

I

INITIAL (Start)

Record the moles of the starting substances. Products usually start at 0 unless otherwise stated.

C

CHANGE (Reacted/Formed)

"Reacted" applies to reactants (negative change).
"Formed" applies to products (positive change).
Use molar ratios from the balanced equation in this step!

E

EQUILIBRIUM

Reactants: Initial − Change (moles reacted)
Products: Initial + Change (moles formed)

+

EQUILIBRIUM CONCENTRATION

If values are in moles, calculate concentration using: c = n/V (concentration = moles ÷ volume)

💡 Key Tip: Molar ratios from the balanced equation are used in the Change row, NOT in the Initial row. The coefficients tell you how many moles react or form relative to each other.

Worked Examples

Example 1: SO2 + O2 ⇌ SO3 Equilibrium

2SO2(g) + O2(g) ⇌ 2SO3(g)

Problem: 7 mol SO2 and 6 mol O2 are placed in a container of volume 2 dm³ at 600 K. At equilibrium, 4 mol SO3 have formed. Determine Kc.

1 Analyze the molar ratios:

From the equation: 2 mol SO2 : 1 mol O2 : 2 mol SO3
If 4 mol SO3 forms → 4 mol SO2 reacts → 2 mol O2 reacts

2 Set up the ICE table:
Stage SO2 O2 SO3
Initial (mol) 7 6 0
Change (mol) −4 −2 +4
Equilibrium (mol) 7 − 4 = 3 6 − 2 = 4 4
Concentration (mol·dm−3) 3/2 = 1.5 4/2 = 2 4/2 = 2
3 Calculate Kc:
Kc = [SO3]² / [SO2]²[O2] = (2)² / (1.5)²(2) = 4 / 4.5 = 0.889

Example 2: H2 + I2 ⇌ HI Equilibrium

H2(g) + I2(g) ⇌ 2HI(g)

Problem: 1 mol of H2 and 1 mol of I2 are placed in a 1 dm³ closed container at 30°C. Analysis shows that 0.8 mol of HI are present at equilibrium. Calculate Kc.

1 Analyze the molar ratios:

From the equation: 1 mol H2 : 1 mol I2 : 2 mol HI
If 0.8 mol HI forms → 0.4 mol H2 reacts → 0.4 mol I2 reacts

2 Set up the ICE table:
Stage H2 I2 HI
Initial (mol) 1 1 0
Change (mol) −0.4 −0.4 +0.8
Equilibrium (mol) 0.6 0.6 0.8
Concentration (mol·dm−3) 0.6 0.6 0.8
3 Calculate Kc:
Kc = [HI]² / [H2][I2] = (0.8)² / (0.6)(0.6) = 0.64 / 0.36 = 1.78

Example 3: PCl5 Decomposition

PCl5(g) ⇌ PCl3(g) + Cl2(g)

Problem: 0.375 mol of PCl5 is heated in a closed 1 dm³ container. The equilibrium mixture contains 0.125 mol of chlorine. Calculate Kc.

1 Analyze the molar ratios:

From the equation: 1 mol PCl5 : 1 mol PCl3 : 1 mol Cl2
If 0.125 mol Cl2 forms → 0.125 mol PCl5 decomposes → 0.125 mol PCl3 forms

2 Set up the ICE table:
Stage PCl5 PCl3 Cl2
Initial (mol) 0.375 0 0
Change (mol) −0.125 +0.125 +0.125
Equilibrium (mol) 0.25 0.125 0.125
Concentration (mol·dm−3) 0.25 0.125 0.125
3 Calculate Kc:
Kc = [PCl3][Cl2] / [PCl5] = (0.125)(0.125) / (0.25) = 0.015625 / 0.25 = 6.25 × 10−2

Example 4: Formation of Nitric Oxide

N2(g) + O2(g) ⇌ 2NO(g)

Problem: 1 mol of N2 and 1 mol of O2 are placed in a 2 dm³ closed container at 300 K. At equilibrium, the concentration of NO is 0.1 mol·dm−3. Calculate Kc.

1 First, calculate moles of NO at equilibrium:

nNO = c × V = 0.1 × 2 = 0.2 mol

2 Analyze the molar ratios:

From the equation: 1 mol N2 : 1 mol O2 : 2 mol NO
If 0.2 mol NO forms → 0.1 mol N2 reacts → 0.1 mol O2 reacts

3 Set up the ICE table:
Stage N2 O2 NO
Initial (mol) 1 1 0
Change (mol) −0.1 −0.1 +0.2
Equilibrium (mol) 0.9 0.9 0.2
Concentration (mol·dm−3) 0.9/2 = 0.45 0.9/2 = 0.45 0.1
4 Calculate Kc:
Kc = [NO]² / [N2][O2] = (0.1)² / (0.45)(0.45) = 0.01 / 0.2025 = 0.049
