Lesson Overview

The equilibrium constant (Kc) is a numerical value that describes the ratio of product concentrations to reactant concentrations at equilibrium. This constant is fundamental to understanding the extent to which a reaction proceeds and predicting the direction of chemical reactions.

📝 Pre-Knowledge Required:
  • Chemical equilibrium concepts (from Lesson 1)
  • Factors affecting equilibrium
  • Reversible reactions and dynamic equilibrium
💡

Main Concepts & Principles

📊 The Equilibrium Constant (Kc)

For a general reversible reaction:

aA + bB ⇌ cC + dD

The equilibrium constant expression is:

Equilibrium Constant Formula

Kc = [C]c[D]d[A]a[B]b

Where [X] represents the concentration of substance X in mol·dm-3

🔑 Key Points about Kc

  • High Kc values indicate equilibrium lies far to the right (more products than reactants)
  • Low Kc values indicate equilibrium lies far to the left (more reactants than products)
  • Temperature is the only factor that affects the value of Kc
  • If temperature changes shift equilibrium to the right, Kc increases
  • If temperature changes shift equilibrium to the left, Kc decreases
  • Solids and pure liquids have concentration = 1 and do not appear in Kc expressions
  • Kc has no units (it is dimensionless)
⚠️ Important: Catalysts do NOT affect the value of Kc. They only speed up the rate at which equilibrium is reached.

📈 Interpreting Kc Values

Kc >> 1

📈

Equilibrium favors products

[Products] >> [Reactants]

Example: Kc = 1 × 108

Kc ≈ 1

⚖️

Equilibrium is balanced

[Products] ≈ [Reactants]

Example: Kc = 1

Kc << 1

📉

Equilibrium favors reactants

[Reactants] >> [Products]

Example: Kc = 6 × 10-28

📝 Rules for Writing Kc Expressions

Step-by-Step Guide:
  1. Write products in the numerator (top)
  2. Write reactants in the denominator (bottom)
  3. Raise each concentration to the power of its coefficient
  4. Omit pure solids (s) and pure liquids (l) from the expression
  5. Only include aqueous (aq) and gaseous (g) species

Worked Examples

Example 1: Writing Kc Expressions

Write the equilibrium constant expression for each reaction:

1.1) 2H2O2(aq) ⇌ 2H2O(l) + O2(g)

Solution: Kc = [O2] / [H2O2]2

Note: H2O(l) is a pure liquid, so it's omitted from the expression.

1.2) 2HCl(aq) + CaCO3(s) ⇌ CaCl2(aq) + H2O(l) + CO2(g)

Solution: Kc = [CO2][CaCl2] / [HCl]2

Note: CaCO3(s) and H2O(l) are omitted (solid and pure liquid).

1.3) N2(g) + 3H2(g) ⇌ 2NH3(g)

Solution: Kc = [NH3]2 / [N2][H2]3

Example 2: Calculating Kc (NO2/N2O4 Equilibrium)

2NO2(g) ⇌ N2O4(g)

Given: At equilibrium:

  • [NO2] = 0.013 mol·dm-3
  • [N2O4] = 0.035 mol·dm-3
1 Write the Kc expression:

Kc = [N2O4] / [NO2]2

2 Substitute values:

Kc = (0.035) / (0.013)2

3 Calculate:

Kc = 0.035 / 0.000169 = 207.1

Example 3: Calculating Kc (H2/I2/HI Equilibrium)

H2(g) + I2(g) ⇌ 2HI(g)

Given: At 440°C equilibrium concentrations:

Species Concentration (mol·dm-3)
[H2] 2.06
[I2] 13.4
[HI] 36.98
1 Write the Kc expression:

Kc = [HI]2 / ([H2][I2])

2 Substitute values:

Kc = (36.98)2 / (2.06 × 13.4)

3 Calculate:

Kc = 1367.52 / 27.604 = 49.54

Example 4: Finding Unknown Concentration

SO2(g) + NO2(g) ⇌ NO(g) + SO3(g)

Given: Kc = 4, and at equilibrium:

  • [SO3] = 0.2 mol·dm-3
  • [NO] = 0.4 mol·dm-3
  • [NO2] = 0.1 mol·dm-3
  • [SO2] = ?
1 Write the Kc expression:

Kc = ([NO][SO3]) / ([SO2][NO2])

2 Substitute and rearrange:

4 = (0.4 × 0.2) / ([SO2] × 0.1)

3 Solve for [SO2]:

[SO2] = (0.4 × 0.2) / (4 × 0.1) = 0.08 / 0.4 = 0.2 mol·dm-3

Example 5: Equilibrium with a Solid Reactant

CO2(g) + C(s) ⇌ 2CO(g)

Given: Carbon dioxide reacts with 36 g of graphite in a 1 dm3 container. At equilibrium: n(CO2) = 0.38 mol, n(CO) = 1.24 mol

1 Calculate concentrations (c = n/V):

[CO] = 1.24 mol / 1 dm3 = 1.24 mol·dm-3
[CO2] = 0.38 mol / 1 dm3 = 0.38 mol·dm-3

2 Write Kc expression (omit solid C):

Kc = [CO]2 / [CO2]

3 Calculate:

Kc = (1.24)2 / (0.38) = 1.5376 / 0.38 = 4.046
