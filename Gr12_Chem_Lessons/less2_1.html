🔑 Key Terms Review

Functional Group: A bond or bonds, or an atom or a group of atoms in a molecule that give a molecule its characteristic physical and chemical properties.


Hydrocarbon: A molecule which contains only hydrogen and carbon atoms.


Homologous Series: A series of similar compounds which have the same functional group.

In this lesson, we will explore branched alkanes - a type of alkane where carbon atoms form branches off the main chain. Understanding how to name these compounds correctly is essential for organic chemistry. We'll learn about alkyl groups, IUPAC naming conventions, and practice with various examples.

Alkyl Groups

To name branches in alkanes, we need to identify the alkyl groups. These are named based on the number of carbon atoms they contain. The name always ends in -yl.

Carbon Atoms in Branch Name of Alkyl Group Formula
1 Methyl- -CH₃
2 Ethyl- -C₂H₅
3 Propyl- -C₃H₇
4 Butyl- -C₄H₉

Steps for Naming Branched Alkanes

  1. Find the longest continuous carbon chain (parent chain)
  2. Number the carbons starting from the end nearest to the branch
  3. Identify and name the alkyl groups (branches)
  4. Indicate the position of each branch with a number
  5. Combine: position-alkyl name + parent name

📝 Worked Example

Name the following branched alkane:

✅ Solution

  1. The longest carbon chain contains 4 carbon atoms; therefore the parent chain is butane.
  2. The branch is closest to the right-hand side, so number from right to left.
  3. The branch contains 1 carbon atom, so it is a methyl branch.
  4. The methyl branch is on carbon atom 2, therefore: 2-methyl
  5. Final name: 2-methylbutane

📌 Important Rules

Rule 1: If the same type of branch occurs more than once, indicate:

  • The location of each point where the branch occurs
  • Use prefixes: di- (2), tri- (3), tetra- (4)
  • Example: 2,3-dimethylbutane

Rule 2: If there are two or more different branches:

  • List them in alphabetical order using the base name
  • Ignore prefixes (di, tri) when alphabetizing
  • Example: 3-ethyl-2-methylpentane (ethyl before methyl)
