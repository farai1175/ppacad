Overview

+

This lesson focuses on applying the equations of motion to solve vertical projectile problems. We'll learn to calculate various parameters of projectile motion using mathematical formulas.

Key Equations of Motion

vf = vi + g·Δt
Δy = vi·Δt + ½·g·Δt²
vf² = vi² + 2·g·Δy
Δy = (vf + vi)·Δt / 2

Where g = -9.8 m/s² (when upward is positive)

Important concepts:

  • Gravitational acceleration is constant (9.8 m/s² downward)
  • Velocity is zero at maximum height
  • Time up = Time down (for same height)
  • Choose a consistent positive direction

Main Body

+

Applying Equations of Motion

When solving vertical projectile problems, follow these steps:

  1. Choose a direction as positive (usually upward)
  2. Write down known values: vf, vi, g, Δy, Δt
  3. Identify which equation to use based on known values
  4. Substitute values into the equation
  5. Solve for the unknown variable
  6. Interpret the answer in the context of the problem
Worked Example 1: Ball Thrown Upward

A ball is thrown vertically upward and returns to the thrower's hand 4 seconds later. Calculate:

a) The maximum height reached by the ball

b) The initial velocity of the ball

c) The velocity when it returns to the thrower's hand

Solution:

Time up = Time down = 4s / 2 = 2s

a) At max height: vf = 0, Δt = 2s, g = -9.8 m/s²

Δy = vi·Δt + ½·g·Δt²

We need vi first...

b) vf = vi + g·Δt → 0 = vi + (-9.8)·2 → vi = 19.6 m/s

a) Now: Δy = (19.6)(2) + ½(-9.8)(2)² = 39.2 - 19.6 = 19.6 m

c) By symmetry: vf = -19.6 m/s (downward)

Worked Example 2: Building Height Calculation

A student projects a stone vertically upward from 1.25m above ground and catches it at the same height after 2 seconds. Calculate the building height.

Solution:

Time up = Time down = 2s / 2 = 1s

At max height: vf = 0, Δt = 1s, g = -9.8 m/s²

vf = vi + g·Δt → 0 = vi + (-9.8)(1) → vi = 9.8 m/s

Height above launch: Δy = vi·Δt + ½·g·Δt² = (9.8)(1) + ½(-9.8)(1)² = 4.9 m

Total height = 4.9 m + 1.25 m = 6.15 m

1. A ball is thrown vertically upward with an initial velocity of 25 m/s. What is its maximum height? (g = 9.8 m/s²)
