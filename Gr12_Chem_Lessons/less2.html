🧠

Pre-Knowledge: Hydrocarbons

Before we begin, let's recall what we know about hydrocarbons:

💡 Remember

Hydrocarbons are organic compounds that contain only carbon (C) and hydrogen (H) atoms. They form the backbone of organic chemistry and can be classified based on the types of bonds between carbon atoms.

🔗 Saturated Hydrocarbons

Contain only single bonds between carbon atoms. Example: Alkanes (C-C)

⚡ Unsaturated Hydrocarbons

Contain at least one double or triple bond between carbon atoms. Examples: Alkenes (C=C), Alkynes (C≡C)

📊

Homologous Series

📖 Definition

A homologous series is a family of organic compounds that have the same functional group, the same general formula, and similar chemical properties. Each member differs from the next by a CH₂ unit.

General Formulae of Hydrocarbons

Hydrocarbon General Formula Bond Type Saturation
Alkane CnH2n+2 Single bonds only (C-C) Saturated
Alkene CnH2n At least one double bond (C=C) Unsaturated
Alkyne CnH2n-2 At least one triple bond (C≡C) Unsaturated

⚠️ Important

In these formulas, n represents the number of carbon atoms in the molecule. For example, if n = 4 for an alkane: C₄H₁₀ (butane).

📖 Definition

Carbon Chain Prefixes

The prefix of an organic compound's name indicates the number of carbon atoms in the longest continuous chain:

Number of Carbons Prefix Example (Alkane) Formula
1 Meth- Methane CH₄
2 Eth- Ethane C₂H₆
3 Prop- Propane C₃H₈
4 But- Butane C₄H₁₀
5 Pent- Pentane C₅H₁₂
6 Hex- Hexane C₆H₁₄
7 Hept- Heptane C₇H₁₆
8 Oct- Octane C₈H₁₈
🔀

Alkyl Groups (Branched Chains)

📖 What is an Alkyl Group?

An alkyl group is a hydrocarbon group derived from an alkane by removing one hydrogen atom. When an alkyl group is attached to a main carbon chain, it creates a branched-chain hydrocarbon.

Alkyl Group Structure Name Derived From
CH₃- Methyl Methane (CH₄)
CH₃CH₂- Ethyl Ethane (C₂H₆)
CH₃CH₂CH₂- Propyl Propane (C₃H₈)
CH₃CH₂CH₂CH₂- Butyl Butane (C₄H₁₀)
📝

IUPAC Naming Rules

📋 Steps for Naming Organic Compounds

  1. Identify the functional group - This determines the ending of the name (e.g., -ane, -ene, -ol, -oic acid)
  2. Find the longest continuous carbon chain - This gives the prefix (meth-, eth-, prop-, but-, etc.)
  3. Number the carbon atoms - Start from the end that gives the functional group the lowest number. Double and triple bonds take preference over side chains.
  4. Name and number the branched groups - Give each branch a number based on its position
  5. Use Greek prefixes for multiple branches - di- (2), tri- (3), tetra- (4), penta- (5)
  6. Arrange substituents alphabetically - Ignore prefixes like di-, tri- when alphabetizing

Special Naming Rules

🧪 Halogens

Treated as alkyl groups with prefixes: fluoro-, chloro-, bromo-, iodo-

Example: CCl₄ = tetrachloromethane

🍷 Alcohols

Name ending: -ol

Example: C₂H₅OH = ethanol

🧫 Carboxylic Acids

Name ending: -oic acid

Example: CH₃COOH = ethanoic acid

🌸 Esters

Name ending: -oate

Example: CH₃COOC₂H₅ = ethyl ethanoate

✏️

Worked Examples

✅ Example 1: Naming 2-methylbutane

CH₃ | CH₃-CH-CH₂-CH₃
1 Identify functional group: Only single bonds = alkane (-ane)
2 Find longest chain: 4 carbon atoms = but-
3 Number carbons: Start from the end closest to the branch
4 Name branch: CH₃ group on carbon 2 = 2-methyl
Final Name: 2-methylbutane

✅ Example 2: Naming 2-methylpropan-2-ol

CH₃ | CH₃-C-CH₃ | OH
1 Identify functional group: -OH group = alcohol (-ol)
2 Find longest chain: 3 carbon atoms = prop-
3 Number carbons: -OH on carbon 2 = propan-2-ol
4 Name branch: CH₃ group on carbon 2 = 2-methyl
Final Name: 2-methylpropan-2-ol

✅ Example 3: Drawing propene

1 Prefix "prop-": 3 carbon atoms
2 Suffix "-ene": Contains a double bond
3 Draw the structure:
CH₂=CH-CH₃

✅ Example 4: Drawing but-2-yne

1 Prefix "but-": 4 carbon atoms
2 Suffix "-yne": Contains a triple bond
3 Position "2": Triple bond starts at carbon 2
CH₃-C≡C-CH₃
