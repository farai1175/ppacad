↔️ Relations - The Foundation

▼

What is a Relation?

A relation is a rule that associates each element of a first set (called the domain) with at least one element of a second set (called the range). In simpler terms, it's any set of ordered pairs (x, y).

💡 Key Insight: Ordered Pairs

Every relation can be represented as a set of ordered pairs: {(x₁, y₁), (x₂, y₂), (x₃, y₃), ...}

The domain is the set of all first elements (x-values).

The range is the set of all second elements (y-values or images).

Examples of Different Relations

Relation Ordered Pairs Domain Range Type
Example 1 {(1,2), (2,4), (3,6), (4,8)} {1, 2, 3, 4} {2, 4, 6, 8} One-to-one function
Example 2 {(-1,8), (0,2), (1,2), (2,5)} {-1, 0, 1, 2} {8, 2, 5} Many-to-one function
Example 3 {(1,8), (4,2), (4,6), (2,5)} {1, 4, 2} {8, 2, 6, 5} One-to-many (NOT a function)

⚠️ Important: Relations vs Functions

All functions are relations, but NOT all relations are functions. A function is a special type of relation with an additional restriction.

📈 Functions - Special Relations

▼

What Makes a Relation a Function?

A function is a special relation where each element of the domain is associated with EXACTLY ONE element of the range. In other words, each x-value has only one corresponding y-value.

FUNCTION DEFINITION
A relation is a function if and only if:

No x-value is repeated with different y-values

Types of Functions

1. One-to-One Functions

Each x-value maps to a unique y-value, and each y-value comes from a unique x-value.

  • Example: {(1,2), (2,4), (3,6), (4,8)}
    Domain: {1, 2, 3, 4}
    Range: {2, 4, 6, 8}
    Each x-value has exactly one y-value
2. Many-to-One Functions

Different x-values can map to the same y-value, but each x-value still has only one y-value.

  • Example: {(-1,8), (0,2), (1,2), (2,5)}
    Domain: {-1, 0, 1, 2}
    Range: {8, 2, 5}
    Both x=0 and x=1 map to y=2, but that's allowed!

💡 Memory Tip

Think of a function as a vending machine: You select one button (x-value) and get exactly one item (y-value). You can't get two different items from the same button!

✅ Vertical & Horizontal Line Tests

▼

Vertical Line Test - Is it a Function?

The vertical line test determines whether a graph represents a function. If any vertical line intersects the graph at more than one point, the graph does NOT represent a function.

How to Perform the Vertical Line Test:
  • Step 1: Look at the graph
  • Step 2: Imagine drawing vertical lines (parallel to y-axis) across the entire graph
  • Step 3: If ANY vertical line touches the graph at more than one point → NOT a function
  • Step 4: If EVERY vertical line touches the graph at most once → IT IS a function

✓ Function Examples

• Straight lines (except vertical)

• Parabolas opening up/down

• Sine and cosine curves

• Exponential curves

✗ Non-Function Examples

• Circles

• Ellipses

• Vertical lines

• Some sideways parabolas

Horizontal Line Test - What Type of Function?

The horizontal line test determines whether a function is one-to-one. It only applies AFTER you've confirmed it's a function using the vertical line test.

📌 Important Sequence

1. First use the vertical line test to determine if it's a function

2. Only if it IS a function, use the horizontal line test to determine the type

HORIZONTAL LINE TEST RESULTS

Horizontal line cuts once → ONE-TO-ONE function
Horizontal line cuts more than once → MANY-TO-ONE function

🔣 Function Notation

▼

Different Ways to Write Functions

1. Mapping Notation

f: x → 2x (read as "f maps x onto 2x")

  • Example: If x = 3, then f maps 3 onto 2×3 = 6
    We say: "6 is the image of 3 under f"
2. Function Notation

f(x) = 2x (read as "f of x equals 2x")

  • What f(x) means: The y-value corresponding to the x-value
    f(3) means "the y-value when x = 3"
    f(3) = 2×3 = 6

Worked Examples with Function Notation

Example 1: f(x) = 2x - 3
  • Find f(1):
    f(1) = 2(1) - 3 = 2 - 3 = -1
  • Find f(0):
    f(0) = 2(0) - 3 = 0 - 3 = -3
  • Find f(-½):
    f(-½) = 2(-½) - 3 = -1 - 3 = -4
Example 2: f(x) = x² - 2x + 1
  • Find f(1):
    f(1) = (1)² - 2(1) + 1 = 1 - 2 + 1 = 0
  • Find f(-2):
    f(-2) = (-2)² - 2(-2) + 1 = 4 + 4 + 1 = 9
  • Find f(0):
    f(0) = (0)² - 2(0) + 1 = 0 - 0 + 1 = 1
  • Find f(a):
    f(a) = a² - 2a + 1

📝 Practice Problems

1. If f(x) = 3x + 5, find f(2) and f(-1) (Answer: 11 and 2)

2. If g(x) = x² - 4, find g(3) and g(0) (Answer: 5 and -4)

3. If h(x) = 2x³ - x, find h(2) (Answer: 14)

4. Determine if {(1,1), (2,4), (3,9), (4,16)} is a function (Answer: Yes, one-to-one)

✓ Comprehensive Quiz (12 Questions)

▼

Test your understanding of functions. Select an option and get instant feedback.

Question 1: Which of the following is the definition of a function?

A) Each y-value has exactly one x-value
B) Each x-value has exactly one y-value
C) Each x-value can have multiple y-values
D) Each y-value can have multiple x-values
Explanation: A function requires that each input (x-value) produces exactly one output (y-value).

Question 2: Which set of ordered pairs represents a function?

A) {(1,2), (2,3), (3,4), (4,5)}
B) {(1,2), (1,3), (2,4), (3,5)}
C) {(1,2), (2,2), (3,2), (3,3)}
D) {(1,1), (2,1), (2,2), (1,2)}
Explanation: Option A has no repeated x-values with different y-values. In B, x=1 has two different y-values (2 and 3).

Question 3: What does the vertical line test determine?

A) If a function is one-to-one
B) If a graph represents a function
C) The domain of a function
D) The range of a function
Explanation: The vertical line test checks if any vertical line intersects the graph more than once, which would mean an x-value has multiple y-values.

Question 4: If f(x) = 3x - 2, what is f(4)?

A) 6
B) 8
C) 10
D) 12
Explanation: f(4) = 3(4) - 2 = 12 - 2 = 10.

Question 5: Which graph would FAIL the vertical line test?

A) A straight line with positive slope
B) A parabola opening upward
C) A circle centered at the origin
D) An exponential growth curve
Explanation: A circle fails the vertical line test because vertical lines through it intersect at two points.

Question 6: What is the domain of {(1,5), (2,7), (3,9), (4,11)}?

A) {1, 2, 3, 4}
B) {5, 7, 9, 11}
C) {1, 2, 3, 4, 5, 7, 9, 11}
D) All real numbers
Explanation: The domain is the set of all x-values: 1, 2, 3, and 4.

Question 7: If f(x) = x² + 1 and g(x) = 2x, what is f(g(3))?

A) 10
B) 37
C) 37
D) 100
Explanation: g(3) = 2(3) = 6, then f(6) = 6² + 1 = 36 + 1 = 37.

Question 8: What does the horizontal line test determine?

A) Whether a function is one-to-one
B) Whether a relation is a function
C) The maximum value of a function
D) The minimum value of a function
Explanation: The horizontal line test checks if a function is one-to-one (injective). If any horizontal line intersects more than once, it's many-to-one.

Question 9: Which notation means "f maps x onto 2x"?

A) f(x) = 2x
B) f: x → 2x
C) f(2x) = x
D) 2f(x) = x
Explanation: f: x → 2x is the mapping notation, read as "f maps x onto 2x".

Question 10: For the relation {(1,2), (2,3), (3,2), (4,5)}, what is the range?

A) {1, 2, 3, 4}
B) {2, 3, 5}
C) {1, 2, 3, 4, 5}
D) {2, 3}
Explanation: The range is the set of y-values: 2, 3, and 5. Note that 2 appears twice but we only list it once.

Question 11: If f(x) = 5x - 3, what value of x makes f(x) = 22?

A) 3
B) 4
C) 5
D) 6
Explanation: Set 5x - 3 = 22 → 5x = 25 → x = 5.

Question 12: Which statement about functions is FALSE?

A) All functions are relations
B) Not all relations are functions
C) A function can be many-to-one
D) A function can be one-to-many
Explanation: A function cannot be one-to-many. If one x-value has multiple y-values, it's not a function.
